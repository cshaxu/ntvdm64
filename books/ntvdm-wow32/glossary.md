# Glossary

| Term | Meaning |
| --- | --- |
| **Guest** | Immutable Win16/DOS-side program and system code used as semantic evidence. |
| **Original owner** | The OpenNT body or structure that owns the original policy, ordering, cleanup, or state. |
| **Mirror** | An upstream-relative OpenNT source copy in the product tree. |
| **Adapter** | A named project-owned boundary that supplies a modern-host service unavailable in the original environment. |
| **Seam** | A crossing between Guest/WOW32/NTVDM behavior and a host service or representation. |
| **Projection** | A bounded original-layout view derived from host facts; it is not an independent host authority. |
| **Admission/rundown** | The rule that allows a callback to enter and ensures it cannot use retired task or Guest state. |
| **A/B/C/D/U** | Direct public carrier / complete explicit translation / partial translation / no direct public carrier / insufficient evidence. |
