# 4.8 — Fonts, text, resources, and window presentation

## Scope and audit state

This chapter owns selected font/text conversions, resource/cursor/icon/bitmap aliases, and ordinary window text/state/geometry/property presentation. DIB sections and pixel-memory mapping are deliberately owned by [4.7](4-7.md), so this page does not create a competing DIB authority. Window discovery, visual Z order, activation, and focus transfer to [4.9](4-9.md); message reentry transfers to [4.10](4-10.md).

The evidence baseline is OpenNT commit `5c5b979ec08c17d3ca2eb70e8aad62d26515d01c`. Static source closure does not assert built-image membership or modern runtime equivalence.

## 1. Fonts and text: aliases, wire formats, and callback admission

Selected font routes are in `wgfont.c:26-476` / `wgfont.h:17-40`; selected text bridge sources are `wgtext.c`, `wutext.c`, and their headers. Apply only the compatibility transforms evidenced for the selected LOGFONT path before creating a host font. A host `HFONT` remains opaque: issue a typed alias, preserve current-font query/result rules, and retire it with GDI-object lifetime rather than treating it as a Guest integer.

Font enumeration is a reverse callback wire. Bound its converted callback buffers, retain the task/procedure capability through the call, preserve its `SHORT` continuation/result semantics, and stop admission before task/memory retirement. Test callback stop, Guest mutation of converted structures, retry/failure path, and task teardown.

Text output must validate text length and optional `dx` span before the host call, preserve selected ETO flags, DC-state ordering, high-byte color/metric fields where admitted, and saturating extent/result projection. Test oversized lengths/extents, output-buffer aliases, selected font changes, and nested drawing—not full font-shaping equivalence.

Font-resource add/remove is task-scoped. Preserve selected compatibility-flag policy, track each accepted add, and pair its remove with the same task record. Two tasks adding/removing the same name and failure cleanup are required runtime cases. Host font discovery is never a substitute for Guest module/resource lookup.

## 2. Resources, cursors, icons, and bitmaps: origin and retirement matter

The selected resource registry and native/Guest routing are `wres16.c:71-354` and `wres32.c:17-115`; selected task cleanup is `wkman.c:1465-1510`. Find/load/lock/unlock/free/size are a token lifecycle. Do not `GlobalFree` a LoadResource handle. A copied or aliased view remains tied to the resource token and its explicit retirement; failed load, repeated lock/unlock, and task teardown are separate cases.

Cursor/icon creation/load/set/destroy routes are `wucursor.c:103-397`, `wuser.c:130-223`, and alias lifecycle is `wcuricon.c:118-220,487-595,724-820,942-980`. Track origin—created, resource-backed, or shared—because destruction/retirement differs. Invalidate aliases before releasing Guest shape storage. Selected task cleanup tears down resource registry before cursor/icon aliases (`wkman.c:1490-1505`); this ordering is a compatibility requirement, not an accidental cache detail. Test replacement, shared-resource and stale/reused token paths, cross-window/task teardown, and UI-use callback admission.

Bitmap loading (`wuser.c:2104-2140`, `wutbl2.h:222-225`) converts ID/string/resource-data inputs and projects zero failure. Loader success does not decide DeleteObject or DC-selection ownership; [4.7](4-7.md) owns that lifecycle and rendering boundary.

## 3. Window text, state, and geometry: stage results before Guest writeback

Text slots are `wutbl2.h:57-59`; selected providers and map ordering are `wuwind.c:1882-1933,2735-2767`. Bound output by the supplied WORD capacity and reserve termination semantics. Pair parameter-map creation/removal even when native calls reenter or fail. The Win16 void-like SetWindowText result cannot be inferred from native success.

The selected `WOWCF_DBASEHANDLEBUG` fallback is narrow: it uses a task-held 16-bit token. Do not turn it into a generic native HWND cast; test flag off/on, IDs `7fffh`, `8000h`, `ffffh`, null/non-null target, other task, stale/destroyed control, and alternate writers.

Geometry table slots and selected providers are `wutbl2.h:53-54,81,137,459-460,559`, `wuwind.c:69-145,2184-2227`, `wusercli.c:66-85,381-400`, and `wuser31.c:685-724`. Stage native geometry results first so failed queries do not overwrite Guest RECT. Initialize native `WINDOWPLACEMENT` length and convert fields explicitly. Keep `SetWindowPos`/Z order outside this service. Test invalid/stale HWND, undersized Guest buffer, success/failure query preservation, normal/min/max placement, DBASE branch, reentrant layout messages, DPI/workspace changes.

State routes (`wutbl2.h:52,55-56,65,67,72,341`; `wuwind.c:1050-1064,3019-3033`; `wuser.c:2188-2201`) require generation validation before every native call. Preserve ShowWindow's previous-state return separately from resulting visibility. Enable, visible, iconic, zoomed, first-show, failed mapping, callback reentry, and destruction races remain distinct tests.

## 4. Property maps: keys and values are opaque, callbacks need their own context

Property routes are table-bound at `wutbl2.h:43-46` and implemented in selected `wuser.c:592-623,741-766,1252-1269,2300-2317,2668-2688`. Preserve both atom and bounded text key paths. Property data is opaque; it must not be silently reinterpreted as a host handle. Property enumeration owns an invocation-scoped callback context so nested/concurrent enumeration cannot overwrite another call's procedure/argument state. Test atom/text, absent get/remove, callback stop/result, allocation failure, nested enumeration, destruction during callback, and concurrent sessions.

## What this chapter does not infer

- A host font, resource, cursor, icon, bitmap, HWND, or property value is not a Guest representation.
- A load/create call does not decide later object selection/deletion or callback rundown.
- DIB pointer/selector sharing is not covered here; it belongs to 4.7.
- A native text/window call does not settle Guest capacity, result, or reentry semantics.
- Selected static source does not prove font rendering, DPI, codepage, image, or runtime equivalence.
