# Glossary

**DEM** — the original DOS Emulation Module host service layer. It is not a
generic modern DOS implementation.

**BOP** — a controlled software boundary operation used by the historical
guest/host path. Its number, register protocol, and caller profile matter.

**Guest address** — a DOS segment:offset or other guest-domain address. It is
not automatically a native pointer, and it does not authorize pointer-width
truncation.

**Provider** — the concrete modern or compatibility implementation that serves
an original boundary. Naming an API is not the same as proving a provider.

**Static closure** — every item in a *frozen local source-contract denominator*
has an evidence-backed disposition. It is not build or runtime acceptance.

**Handoff** — a named responsibility transferred to another fixed module; it
prevents duplicate audit and prevents an unowned gap.

**Minimum diff** — the smallest documented change at an unavailable host
boundary that preserves the original observable contract. It is not a licence
to retain accidental undefined behavior or to invent a replacement subsystem.
