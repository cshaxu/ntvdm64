# 4.3 DOS Extender and DPMI Host

## Boundary and result

4.3 treats the DPMI32 host as a finite DOS-extender seam: allocation, selector
and descriptor carriers, interrupt/exception reflection, mode-switch-facing
transitions and their original host dependencies. It does not reintroduce a
kernel VDM, CPU/V86 monitor, or a general protected-mode implementation.

The fixed local denominator is 55 contracts—39 protocols, five structures,
four variants and seven mechanisms—and all are statically closed. Five U-class
items retain expressly bounded uncertainty; provider/ABI/runtime validation is
still zero. Static closure therefore means source responsibilities and modern
constraints are accounted for, not that an extender works.

## Connection rule

Selectors, guest descriptors, exception frames and protected-mode state are
wire contracts. They must not be replaced by native pointers, host exception
objects or a new scheduler. Preserve original layout, transition ordering,
validation and failure rules where they are reached. If an original dependency
is unavailable, isolate a finite facade at that boundary and retain the source
owner; never import a private kernel/CSR shell merely because it contains a
similarly named service.

4.1 owns address leases and 4.2 extended memory. Generic BOP/register ABI is
2.1. Actual selected objects, calling conventions, fault paths, concurrency
and real-program validation belong to Part 8.
