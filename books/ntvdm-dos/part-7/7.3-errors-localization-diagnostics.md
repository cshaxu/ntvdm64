# 7.3 Errors, Localization, and Diagnostics

## Boundary

This module owns hard-error response, DOS/Win32 error conversion, NLS/date/time
and system-query behavior, and VDM debugger/VDD diagnostics at their finite host
boundary. It excludes a private replacement for Windows error UI, full NLS
subsystems, and debugger implementation. Static ledger closure remains a source
contract result, not a claim that all diagnostics execute on Windows 11.

## Semantics to preserve

Return flag, AX/error value, LastError effect, dialog/result mapping, OEM/ANSI/
Unicode conversion and partial state must be retained per source route. An
error-dialog resource elsewhere in the tree, a familiar `GetLocaleInfo` name,
or a modern exception facility does not establish the original behavior. Hard
errors can have a user-visible response protocol; replacing them with a generic
exception, silent retry or process-wide suppression changes the contract.

Locale and date/time presentation have range, code-page and fallback rules.
They must not silently import modern locale normalization into guest-visible
buffers. Debug/VDD diagnostic channels similarly require explicit data width,
loading and lifetime treatment.

## Minimum-diff direction and handoff

Keep source error/response mapping and codepage field policy, then bind the
smallest public leaf or bounded compatibility provider. Path and console
conversions remain 3.1/5.1; native provider selection and build/runtime
evidence remain Part 8. Do not use a diagnostic path to reconstruct private
USER/CSR/NLS internals.
