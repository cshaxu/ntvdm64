# Queue

This is the authoritative ordered queue of unnumbered candidate packages.
Only [Current Work](CURRENT.md) admits an active task. The window-appearance
package is closed; the carrier-visibility package is admitted in Current and absent here. Owner-approved priority is basic
functionality, basic display, comprehensive interaction, comprehensive display,
then comprehensive functionality. Actual proved blockers take priority through
explicit admission, not guessed dependencies. The WOW phases are candidates
1--5, 6--7, 8--12, 13--14 and 15--22 respectively; mixed-family staged completion
follows the [program](../proposals/proposal-wow32-production-completion-002.md#owner-approved-functional-priority-2026-10-12).
SOL and WRITE initialization failures must be repaired in basic functionality
and their normal main interfaces verified in basic display, before advancing
to comprehensive interaction. Historical error-dialog frontiers do not pass
this phase gate; promote actual missing owner dependencies when necessary.
