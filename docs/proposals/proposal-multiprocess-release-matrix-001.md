# Multi-process matrix and product release

## Objective

Prove the brokered multi-process x86-worker profile, the cross-owner DOS/Win16
compatibility matrix, portable media layout, and release package.

## Boundary

Host x64 Windows is an x86-worker acceptance platform, not a native-x64 worker
requirement. This package does not reopen a single-process owner contract.

## Exit evidence

Record the selected matrix results, artifact provenance, supported-host result,
and every remaining explicit limitation.
