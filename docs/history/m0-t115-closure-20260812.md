# M0 T115 closure — 2026-08-12

T115 establishes that reached machine BOP `02h` is outside the adapter
host-service plane: it is the source-backed SoftPC `unexpected_int` machine
operation and requires synchronous Bochs-owned PIC/RAM mechanics. The chosen
placement is a new, narrow machine-composition component, not a selector branch
in Bochs, an adapter service, or revival of the historical SoftPC backend.

The component must be catalogue-driven for the complete historical BIOS BOP
inventory. It may use the single independently proven `unexpected_int` x86
object only through a three-operation, dynamically scoped Bochs mechanics
context. A future source integration requires a new exception-register entry.

T116 is admitted to close that component's bounded `02h` contract and native
handler-island build boundary before any exception-path connection or further
BOP/provider work.
