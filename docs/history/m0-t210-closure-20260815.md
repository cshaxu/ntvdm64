# M0 T210 Closure — CLI host-context owner package

T210 closes the selected-drive/current-directory/environment owner package
shared by DEM and COMMAND. It provides one session-owned adapter context,
explicit public Win32 direct-mode integration, common readonly/overlay/virtual
enforcement, bounded COMMAND projection and whole-family source-built tests.

The closure covers DEM `50:13/18/1A` and COMMAND `54:02/04/0F` as consumers
of the same context. It does not claim complete COMMAND ownership, continuous
native execution or all-BOP completion.
