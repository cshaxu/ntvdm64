# M0 T225 S26 Closure — Guest EXEC Current-Route Reconciliation

## Delivered

S26 closes its owner-scoped source/current-route audit for a guest DOS EXEC
child's lifecycle. It establishes that NTDOS remains the exclusive owner of
EXEC, PSP/arena/JFN/environment setup, guest entry transfer, child teardown,
and saved parent continuation. The completed DEM file/lifecycle packages and
startup-machine package are prerequisites, not substitutes for that guest
behavior.

The audit identifies the only remaining composition boundary: OpenNT COMMAND
parent-return handling at `54:0B` / `cmdReturnExitCode`. The current route can
perform only a limited register resume. Its terminal contract deliberately
accepts only a top-level exit and rejects a DOS exit code, so it cannot publish
an ordinary guest child result or declared re-entry after engine cleanup.
