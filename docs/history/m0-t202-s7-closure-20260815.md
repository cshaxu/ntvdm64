# M0 T202 S7 Closure — COMMAND host-child re-entry admission

S7 closes with a **no-admission** decision for a CLI-owned host-child-to-DOS
re-entry queue.  The complete original `cmdExec32`, `cmdReturnExitCode`, and
`cmdGetNextCmd` map shows that the `CmdSize > 0` branch is owned by the NT4
BaseSrv/CSR VDM command broker, DOS-record state, wait handles, event thread
and Redirector completion—not by a local command list.

The current direct child capability remains a bounded terminal transaction.
It preserves the original `RETURN_ON_NO_COMMAND` form (`CF=0`, low completion
byte) without passing a host handle, pointer, callback, guest address or
Bochs state across the boundary.  The immutable declared DOS launch plan is
not repurposed as a child-completion queue.

Evidence: [S7 admission decision](../etc/research/t202-s7-command-reentry-admission-decision-001.md).

This closure does not claim interactive COMMAND, a BaseSrv replacement,
Redirector pipe completion, VDD console support, or native guest closure.
