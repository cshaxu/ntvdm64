# M0 T103 closure — 2026-08-12

T103 closed the native POST/deferred-startup composition statically.  The
profile's plan and handoff fields are correctly paired, while direct and
deferred entry are mutually exclusive at the compiled consumer mode.  Earlier
native POST evidence already uses `main.o` with direct entry disabled and the
deferred `exception.o` consumer enabled.

The current adapter derivative instead inherits the direct r5 objects.  T104
is admitted to add only a deferred variant of that derivative: it will rebuild
those two existing Bochs objects, retain the current adapter/CLI objects and
all engine archives, then perform one bounded validation run.
