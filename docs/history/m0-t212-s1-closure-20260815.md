# M0 T212 S1 Closure — CLI lifecycle governance map

S1 closes the current lifecycle source/ABI/failure mapping without changing
runtime behavior.

- The one-shot engine produces budget, controlled-terminal, composition and
  machine results, and owns its stage/composition cleanup.
- `ORDINARY_GUEST_COMPLETION` and `HOST_CANCELLATION` are valid enum values
  but have no current engine producer. COMMAND `54:0B` remains package-local.
- Existing Ctrl+C handling applies only to the retained child-process runner;
  it cannot be used as an in-process engine cancellation mechanism.
- The relevant ordinary user-mode Win32 APIs are available. The remaining
  boundary is ownership/composition, not a missing API.

Evidence: [T212 S1 lifecycle map](../etc/research/t212-s1-cli-lifecycle-governance-source-abi-map-001.md).

T212 S2 is admitted to implement only a fixed-width CLI policy/result
classification and in-memory audit ABI. It does not alter the engine contract,
Bochs/mantle, BOP behavior or native execution.
