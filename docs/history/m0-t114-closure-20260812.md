# M0 T114 closure — 2026-08-12

T114 proves the three unresolved original-platform calls have a finite x86 C
ABI and direct native Bochs mechanical equivalents. It does not prove a
linkable product: invoking the original handler remains unowned under the
current Bochs/adapter boundary.

T115 is admitted to decide the placement of a machine-BOP composition
dispatcher. It is a design audit, not approval to implement a dispatcher or
register a Bochs exception.
