# M0 T175 closure — 2026-08-12

T175 audits and rejects immediate CLI exposure of T174 DOS status. The runner and engine only propagate Win32 child exit codes, while the captured status is process-local adapter state inside Bochs. FE exit zero is native controlled-stop success, not normal DOS completion. No DX-to-AL or DOS-to-process-exit mapping is source-backed. A later transport must be a separately admitted, fixed-width engine-owned process-boundary ABI; first priority is proof that a normal guest reaches 54:11 and continues correctly.
