# M0 T216 Closure — declared guest executable-image visibility

T216 restored the provider-owned readonly visibility contract for all declared
guest images: COMMAND.COM, CONFIG.SYS, AUTOEXEC.BAT, first target and optional
terminal target.

- Existing DEM open/seek/read/close/time and readonly-mutation failure rules
  are reused through opaque tokens.
- Pathname and FCB FindFirst merge the declared root snapshot over host entries
  while nonmatching host paths remain host-backed.
- Focused x64 `/MT` provider/search probes pass; the full composition links and
  runs to the unchanged controlled `50:3D` terminal.

This does not claim COMMAND startup. The unchanged terminal shows that DOS
EXEC continuation has separate prerequisites. The next package begins with a
whole source/ABI/failure audit of that continuation, not a `50:3D` patch.
