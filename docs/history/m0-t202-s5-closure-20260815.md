# M0 T202 S5 Closure — COMMAND host-capability admission

S5 maps every callable `54:00..10` COMMAND identity to its original OpenNT
owner, copied ABI, host mutation/profile disposition and one whole-package
implementation or source-shaped deferred path.

Ordinary user-mode APIs for files, paths, environment, console, registry,
streams and processes remain available. The blocking boundaries are instead
raw-handle transport, CCPU/SAS guest-pointer access, VDD/KEYB coupling and the
NT4 child-VDM broker/return lifecycle. The package regression design makes
these boundaries explicit and prohibits endpoint or trace-led work.

Evidence: [source/ABI/mutation map](../etc/research/t202-s5-command-host-capability-source-abi-map-001.md)
and [whole-provider regression design](../etc/operations/t202-s5-command-whole-provider-regression-plan-001.md).

S6 owns the complete source-derived COMMAND provider recovery. It starts with
a session-private capability record and package regression substrate; no raw
handle, host pointer or BOP semantic enters Bochs.
