of the original `GRAPHICS.COM` termination values.  The frozen observation
cannot attribute its final session-dispose reason without changing the
container; no graphics, timer, IRQ, video or BOP leaf repair is authorized by
this package.

If later workload evidence requires it, a separate whole session-lifecycle
package must recover the original-owner cleanup/binding contract before any
diagnostic or repair.  T377 otherwise transfers to the ordered DOS-extender
runtime package.  It does not claim interactive keyboard input, graphics
presentation or universal DOS-device compatibility.
