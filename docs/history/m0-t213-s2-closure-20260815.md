# M0 T213 S2 Closure — one-shot host-terminal package design

S2 closes the complete COMMAND/DEM terminal-state design without
implementation.

- `50:3D` is ambiguous across source-proven top-level and fatal paths, so it
  cannot become ordinary completion by selector, register, or trace heuristic.
- The existing final `54:0B` record is COMMAND-local and neither precedes nor
  authenticates every DEM teardown.
- A future copied terminal record requires a source-proven provenance contract;
  the current profile supplies none.
- Controlled termination remains the only honest current disposition.  No
  unavailable modern Win32 API blocks the work; the unavailable dependency is
  the historical `ExitVDM`/BaseSrv/CSR composition.
