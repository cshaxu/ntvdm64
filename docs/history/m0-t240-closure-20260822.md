# M0 T240 Closure — SoftPC conventional-memory query recovery

## Outcome

T240 makes exact real-mode `C4 C4 12` an active OpenNT-shaped `bx-vdm` route.
The directly mirrored SoftPC `mem_size.c` reads mutable BDA `0040:0013`, writes
low-16-bit AX, and resumes at `RIP+3`.

## Delivered boundary

- `bx-core` and `bx-mantle` are unchanged: the only lower-layer operation is
  their pre-existing selector-blind checked physical-RAM read.
- A private SAS/AX symbol prefix shim is the sole source-composition change;
  it retains the original function body, local data and read-then-AX order.
- The inactive, hard-coded adapter helper and its coupled `15h/AH=88h`
  experiment are removed from source, fixtures and formal membership.

## Verification and limitation

Focused MSVC and formal Ninja fixtures prove little-endian BDA reading,
application-visible mutation, AX-only/RIP+3 output and declared negative
routes. A fresh formal native CLI link completed in 255 edges. The one bounded
native guest run stopped before any BOP (`count=0`, terminal detail 3), so it
does not claim guest continuity or a live BOP-12 hit. See the detailed
[S2 closure evidence](../etc/evidence/m0-t240-s2-softpc-memory-size-closure-001.md).
