# M0 T243 Closure — Headless BOP-5F Source Recovery

## Closed scope

T243 closes one deliberately narrow, source-shaped first-profile contract for
the reached NTIO `BOP 5F`. It recovers the `AX=BEEF` guard, the
`kb_setup_vectors` publication of the `useHostInt10` state byte, and the
original MONITOR CF return to `spckbd.asm`'s `JC isk_int9` branch.

The implementation is confined to bx-vdm source-mirror code plus a named
checked-RAM shim. It makes no Bochs change and adds no selector, DOS, OpenNT
or device vocabulary to bx-core or bx-mantle.

## Explicit transfer

Physical keyboard input, IRQ1/PIC/timer behavior, monitor iret hooks, full
keyboard-table consumption, video/printer behavior and interactive guest
continuity remain with the separately admitted selector-blind PC
keyboard/IVT machine package. T243 neither claims nor substitutes for that
package.
