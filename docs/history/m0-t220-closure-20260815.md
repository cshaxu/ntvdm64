# M0 T220 Closure: DEM process-resource ownership

## Scope and result

T220 audited the process-resource contract that lies between the guest DOS
`$Exec` path and current direct DEM host tokens. It did not implement a
process-lifecycle BOP workaround. The accepted result is a bounded direct
namespace owner transaction plus two explicit rejections: no pre-`DOS_ABORT`
cleanup at `50:3C`, and no adapter-owned JFT/SFT reconstruction.

## Retained limitations and transfer

T220 does not close DEM as a whole, FCB/search/VDD/device ownership, normal
parent return, COMMAND execution, or any BOP-family runtime. Its direct-token
owner field is not a license to use `50:3C` as a global teardown.

The successor **M0 T221** is admitted from this transfer as DEM host namespace
and handle owner-package recovery. Its first S produces the complete package
owner/ABI/failure ledger and shared-profile disposition before any provider
work; trace remains integration evidence only.
