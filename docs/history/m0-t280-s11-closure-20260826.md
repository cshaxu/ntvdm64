# M0 T280 S11 closure — reached NT I/O facade

S11 provides one `adapter-win32` reached NT I/O facade for the original DEM
directory, volume, object and symbolic-link call shapes.  It preserves the
historical x86-sized `IO_STATUS_BLOCK` source contract on both architectures,
using a host-local modern status record only at the dynamic `ntdll` boundary.

The focused fixture parses original `dem.h`, compiles, links and runs on MSVC
x86 and x64.  Missing dynamic exports yield explicit `STATUS_NOT_IMPLEMENTED`.
No DEM body, BOP/provider route, guest pointer or session mapping is enabled.
