# M0 T246 Closure — SoftPC machine interrupt owner package

## Closed scope

T246 recovered the first reached, shared SoftPC machine package behind
historical `BOP 02` and `BOP 06`.  It closes the complete source-defined
non-debug mechanics:

```text
SoftPC bios.c BOP table
  → unexpected_int / illegal_op_int
  → checked saved-frame IP update (06 only)
  → PIC ISR/IMR port operation stream
  → BDA 0040:006B interrupt-cause publication
  → typed RIP+3 resume or controlled stop
```

The implementation is one adapter-owned generic-ingress bridge.  It invokes
the existing source-derived provider and copies its already typed result to
the fixed generic outcome record.  `bx-core` and `bx-mantle` remain
selector-blind and unchanged.

## Explicit transfer

T246 does not claim continuous guest execution.  The native trace later
encounters additional legitimate `06` calls and ends in the existing
`UNEXPECTED_LOOP_RETURN` machine execution state.  The closed ingress no
longer falls through; that later control-flow investigation is not repaired
by extending the `02/06` provider.  It is transferred to the queue's
guest-EXEC/native-continuity and later machine/firmware owner work, where the
tracker can classify the next source-defined package without trace-led leaf
patching.  Active M0 T247 owns the NTDOS/COMMAND guest `EXEC` and parent-return
source/ABI map; its S1 may admit only a source-defined guest lifecycle slice.
