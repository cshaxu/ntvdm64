# M0 T376 closure — Pure DOS external execution and parent return

## Closed result

T376 closes the first bounded original external-DOS execution package on the
formal CPU40/SoftPC product.

- S1 selected source-identical `LOADFIX.COM` and `FASTOPEN.EXE`, recovered the
  original owner chain, and ruled out an app loader.
- S2 revalidated the original DEM open/read/close, guest-memory lease and
  host-resource mapping cohort under the current formal graph.
- S3 made the one frozen `LOADFIX.COM` run and retained original file-service
  plus COMMAND continuation evidence.
- S4 rejected the one alternate-root MZ attempt because it reached no
  source-owned marker; it made no MZ diagnosis and caused no retry.
- S5 added `FASTOPEN.EXE` to the established root only through an
  identity-verifying, mismatch-refusing package update.
- S6 made the one allowed correctly rooted MZ run.  It reached original MZ
  open/seek/close/termination markers and the later original COMMAND
  continuation, then exited the one-shot session cleanly.

## Explicit limits

This is a pair of selected immutable external-DOS workload proofs, not a
general DOS compatibility claim.  It leaves interactive shell continuation,
arbitrary MZ relocation coverage, 32-bit/native child execution, Redirector,
WOW/Win16 and graphics/device work to their separately ordered owner packages.
