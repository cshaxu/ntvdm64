# M0 T257 Closure — DPMI Frame-ABI Admission Rejection

## Result

T257 closes without authoring the proposed typed protected-frame transaction.
Its S1--S4 source, startup/table and protected-frame maps remain valid
evidence, but Td S2 P3--P7 establishes that their prerequisite interface
closure was not sufficient to admit the S5 replacement ABI.

The unresolved items are not generic machine defects: they are OpenNT DOSX
owner-package dependencies for pointer lifetime, locked protected frames and
IRET ordering, process-LDT lifecycle, mode transition, VCD/VDD interaction
and guest-linear memory lifecycle.  A selector-blind frame transaction would
therefore be a project-defined replacement that bypasses the mandatory
source-first recovery order.

## Transfer

T258 is admitted first for the cross-family, synchronous historical
guest-pointer facade recorded as `BOP-DEPENDENCY-118`.  It does not reopen
DPMI or enable `53:xx`.  A later DPMI package must recover the complete
source-first pointer, descriptor, frame/IRET and memory lifecycle together.
