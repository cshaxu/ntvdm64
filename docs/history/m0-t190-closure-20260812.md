# M0 T190 closure — 2026-08-12

T190 restores one coherent source-derived COMMAND bootstrap slice.  Original
`cmdComSpec` / `cmdGetInitEnvironment` host composition cannot link into the
non-invasive CLI because it depends on CCPU/SAS, global NT COMMAND state and
ambient Win32 environment.  The adapter therefore uses a checked 64-byte
guest gather, caches only `COMSPEC=` plus copied OEM text, and preserves the
existing `54:0F` BX capacity/retry/write transition.  It intentionally does
not expose host environment variables.

The source/test closure, three-object derivative, immutable bundle and one
observation are all retained.  The run reaches `54:02` gather, `54:0F` write
and controlled stop.  No Bochs CPU/device/firmware change, new BOP ingress,
DOS implementation or continuous-execution claim is transferred.

The next task is not a one-service patch: it must classify the complete set
of COMMAND-family BOPs reached after bootstrap, their original owners and
their capability/failure disposition before admitting another provider slice.
