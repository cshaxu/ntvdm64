# M0 T225 S28 Closure — Native First-Fault Diagnostic

## Closed Scope

S28 establishes a default-off, selector-blind mechanical diagnostic for the
native repeated segment-limit failure reported by S27.  It does not repair a
guest image, segment descriptor, BIOS, device, BOP, provider, or host
capability.

## Delivered Evidence

- [Source/ABI/failure map](../etc/research/t225-s28-native-segment-fault-diagnostic-source-abi-map-001.md)
  rejects reuse of the #UD/BOP bridge and records the limited BX-TRACE-084
  exception.
- [Focused fixture result](../etc/evidence/t225-s28-first-fault-observation-fixture-result-001.md)
  proves default-off decline plus exactly one test-owned non-UD capture and
  finite stop under formal MSVC x64 `/MT`, CPU5/Pentium-MMX.
- [Native Direct/Readonly result](../etc/evidence/t225-s28-native-first-fault-direct-readonly-result-001.md)
  records identical first facts: `#GP(13)`, error `0`, pre-delivery
  `CS:EIP=0C41:2357`, `EAX=0`, `EFLAGS=0x93`, real-mode value `1`, and the
  distinct machine-failure first-fault terminal.

The implementation is local commit `5571f03b`
(`feat(t225): complete first-fault diagnostic`).  It is pending remote delivery
because the execution environment requires an explicit current confirmation of
the configured remote's ownership before it will transmit repository contents.

## Result And Transfer

The two supported mutation modes have byte-identical stdout and stderr hashes,
so host mutation policy does not explain the failure.  The typed observation
also does not distinguish incorrect source-built guest/startup layout from
Bochs segment-access or exception-delivery mechanics.  Consequently S28 does
not admit a repair.

S29 owns one read-only attribution map: correlate the observed physical
address (`0x0C41 << 4 + 0x2357 = 0xE767`) with the immutable staged-image
layout, original OpenNT source/control-flow evidence, and the exact adopted
Bochs segment-access path.  It must either name the next owner or retain the
ambiguity; no trace-led BOP implementation follows from S28.
