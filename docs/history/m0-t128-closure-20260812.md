# M0 T128 closure — 2026-08-12

The T127 engine was launched through the unchanged T124 shim with the same
fixed bundle contract and 15-second tree watchdog. It still observed only
`50:11` (6,886 times) and recorded zero transaction commits.

Source inspection proves why: `exception.cc` places the generic
`bx_ntvdm_cpu_result_bridge_interceptor` call inside the
`BX_NTVDM_ENABLE_STARTUP_TRANSACTION` block. T127 retained that outer flag at
zero, so enabling the result bridge did not call adapter runtime dispatch.
T129 is limited to enabling that existing selector-blind ingress alongside the
already enabled bridge; no BOP behavior is introduced.
