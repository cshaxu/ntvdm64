# M0 T156 closure — 2026-08-12

T156 closes the source/state audit of the post-fast-read triple fault.  The
log places the last successful EOF FASTREAD 5,696 ticks before the stop; it
does not directly corrupt the later stack state.  Bochs correctly detects a
wrapped real-mode exception-frame stack write at `ffffh` and terminates after
the third unresolved `#SS`.

The missing fact is the first vector/control transfer that reaches
`CS=0000:EIP=019d` and SP=3.  It is an unobserved guest/control-state
predecessor, not evidence for an adapter workaround or Bochs limit change.
A later default-off predecessor trace needs separate admission.
