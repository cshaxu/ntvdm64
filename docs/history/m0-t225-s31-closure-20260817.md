# M0 T225 S31 Closure — DS:FFFF Source/Lifecycle Attribution

## Closed scope

S31 was a read-only source/build/control-flow attribution of S30's native
DS-segment end-of-limit word-read. It made no runtime or source implementation
change.

## Delivered evidence

- [The attribution map](../etc/research/t225-s31-ds-ffff-source-lifecycle-attribution-001.md)
  establishes that `DEVIOCALL2`'s original `MOV AX,[SI.SDEVSTRAT]` at the
  source-built NTDOS file offset `0x2AF7` is the only identified exact
  source/layout candidate for DS offset `FFFF` with a two-byte read.

## Result and transfer

The first native record proves DS `0C41`, not the expected initial NTIO `0070`
device-header segment. The candidate's dynamic execution is intentionally not
claimed: the retained first-fault EIP is not an instruction-boundary witness.

S32 owns the complete original guest bootstrap/device-header lifecycle map,
from formal 50:11 loading through sysinit/DosInit/charinit and DEVIOCALL2
input provenance. It may not repair CPU, guest, device or provider behavior.
