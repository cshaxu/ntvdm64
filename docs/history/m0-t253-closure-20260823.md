# M0 T253 Closure — selector-blind async-pipe completion delivery

## Closed scope

T253 closes the local OpenNT Redirector asynchronous named-pipe completion
slice without turning Bochs into a Redirector/VDM implementation.

- The adopted machine has no new core patch. A project-owned mantle queue
  accepts only a physical 8259 line from a host worker; the existing
  finite-stage timer drains it on the CPU thread and invokes the existing PIC
  request. Native PIC mask, cascade, acknowledgement and vector selection
  remain untouched.
- `57:23` and `57:24` preserve the retained `namepipe.asm` descriptor form,
  `BP:BX` opaque token convention and `MAXIMUM_ASYNC_PIPES` serialized
  lifecycle. Private duplicated handles and buffers never enter guest RAM.
- `57:26` returns the source-defined no-work or async-pipe disposition;
  original `int5c.asm` remains the exclusive owner of guest ANR call, stack
  construction and IRET.

[S3 ingress and completion record](../etc/evidence/m0-t253-s3-async-completion-ingress-audit-001.md)

## Explicit transfer

This closure does not claim NetBIOS/NCB, DLC, remote Redirector protocols,
`57:2F/30` acknowledgements, or source-built guest resident IRQ76/ANR reach.
Those remain the later Redirector owner package. No CCPU, CSR/BaseSrv, raw
guest callback/HANDLE, vector injection or Bochs core semantic change is
admitted by this task.
