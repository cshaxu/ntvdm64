# M0 T306 closure — MVDM external-boundary package selection

## Result

M0 T306/S1 is closed. Its finite direct external frontier contains 7,367
physical call identities. Every identity has one adoption disposition without
merging merely equal spellings or treating a candidate source body as a usable
binding.

## Disposition

- 87 calls return to selected MVDM source closure; two further rows are local
  MVDM debug-macro corrections.
- 76 historical SoftPC calls remain a Bochs-machine boundary: Bochs is the
  sole executor and no second SoftPC executor is admitted.
- 54 calls retain the bounded source-shaped Base VDM local seam; the
  CSRSS-bound BaseClient/BaseSrv product shell is not imported.
- 11 calls select the exact `opennt-host/netapi/netlib/ntstatus.c` mirror
  slice, owned by the Redirector package; four use public Win32 Redirector
  bindings and one remains a downlevel RAP protocol hard boundary.
- 15 calls are public CRT leaves and one is an NTDLL/CSRSS hard boundary.
- The remaining 7,116 calls are caller-owned source-identity holds: 59
  signature/condition-form holds, 3,952 declaration-binding holds and 3,105
  source-absent/macro/import holds. They cannot independently select a source
  import or generic adapter.
