# M0 T212 S4 Closure — cooperative cancellation admission map

S4 closes the read-only admission map for in-process cancellation.

- Direct asynchronous CLI writes to Bochs state, raw handle/pointer transfer,
  host termination and BOP-based cancellation are all rejected.
- A selector-blind mantle-private atomic controller, polled by an existing
  CPU-thread timer callback, is the sole admitted mechanical candidate.
- Existing engine cleanup remains the owner; the pre-existing copied
  `HOST_CANCELLATION` enum is the only permitted eventual engine result.
- Wall-time and resource limits remain deferred; no unavailable Win32 API
  blocks future CLI orchestration.

Evidence: [S4 admission map](../etc/research/t212-s4-cooperative-cancellation-admission-map-001.md).

T212 S5 is admitted to implement the mechanical controller only after its
mantle intrusion exception has been registered. It excludes CLI event/thread
orchestration and all BOP work.
