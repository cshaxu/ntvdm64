# M0 T205 S2 Closure — XMS A20/block/geometry group

S2 closes the admitted non-UMB/non-INT15 XMS group: `52:00..05`, `0A` and
`0B`. One selector-blind mantle capability now owns A20, bounded extended
memory, physical backing-RAM copy and allocator statistics; one bx-vdm XMS
session owns copied record decoding and source-derived registers.

- `00` retains typed A20 set/query translation.
- `01` reads the historical 12-byte `SS:BP-12` record through the existing
  mechanical action and sends only copied physical addresses/count to mantle.
- `02/03/0B` use opaque allocation lifecycle and return source-shaped AX/CX
  failures for safe indeterminate/stale cases.
- `04` returns the normal-user-mode `GetSystemInfo` page-size contract.
- `05` reports declared machine capacity; `0A` reports total/largest free KiB.

Strict MSVC x64 `/MT /W4 /WX` package regression covers every S2 slot through
common ingress, including move mapping and failure paths. Mantle static
boundary checks pass. The broader minimal-machine recipe still fails at its
pre-existing omitted CPU/decode object link closure, so no native machine or
trace claim is made. `06..09` remain explicitly deferred for separate UMB and
INT15 mechanical capability work.
