# M0 T225 S21 Closure — Guest DOS EXEC/PSP/Parent-Return Admission

S21 closes the source and current-route admission for the Guest DOS
multi-program package. It establishes that a declared multi-program sequence
must remain an original NTDOS guest process tree in one VDM. `$Exec`, DOS
arena/PSP/JFN/environment construction, child entry, termination and parent
return remain guest-owned; bx-vdm must not create a DOS process or replace it
with a nested host NTVDM/child process.

The [source/ABI/current-route map](../etc/research/t225-s21-guest-dos-exec-psp-return-source-map-001.md)
records the fixed EXEC parameter and PSP layouts, the `50:11` NTDOS
identity-checked guest-RAM staging seam, and the constrained `50:36`/`50:3C`
DEM notifications. It confirms that the latter do not own PSP state, ordinary
file close, or parent return.

S21 does not claim that an original NTDOS `$Exec` path has executed. The
smallest next closure is continuous native reach from source-built NTIO through
original NTDOS initialization and the original COMMAND handoff. Any observed
missing mechanism is a separately-owned startup, DEM, or bx-core/bx-mantle
question; an adapter loader or host-process substitute remains rejected.
