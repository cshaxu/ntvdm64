## Daily Operation

Read [Status](STATUS.md), then [Queue](QUEUE.md), then [Debt Ledger](TODO.md).
`STATUS.md` is the only active-task and technical-baseline authority;
`QUEUE.md` is the ordered, unnumbered candidate list; and `TODO.md` holds
unplanned debt only.

## Supporting Detail

[etc/README.md](etc/README.md) indexes supporting evidence, research,
provenance, fixtures, operational material, and the incremental migration
inventory. These records cannot override the current authorities above.
