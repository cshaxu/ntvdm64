# Documentation Guide

This is the documentation entry point. Current authorities live in this
topology; retained pre-governance records are indexed supporting evidence.

## Task Reading Set

Read the documents required by your role before changing the repository:

1. Everyone: [this guide](README.md), the active [Status](STATUS.md), and
   [Execution Rules](rules/EXECUTION.md).
2. Planning or coordination: [Queue](QUEUE.md), [Roadmap](design/ROADMAP.md),
   and [Documentation Rules](rules/DOCUMENT.md).
3. Product or implementation work: [Goal](design/GOAL.md),
   [System Architecture](design/ARCHITECTURE.md), [Source Layout](design/CODING.md),
   [Architecture Rules](rules/ARCHITECTURE.md), [Coding Rules](rules/CODING.md),
   and [CONTRIBUTING.md](../CONTRIBUTING.md).
4. Documentation changes: [Documentation Rules](rules/DOCUMENT.md) and every
   authority affected by the change.
5. Source, firmware, guest media, or Microsoft-component work:
   [source policy](etc/operations/policy/source-policy.md) before obtaining,
   importing, deriving, or researching material.

## Daily Operation

[STATUS.md](STATUS.md) contains the one active S packet and the current
technical baseline. [QUEUE.md](QUEUE.md) contains only ordered, unnumbered
candidate T packages. [TODO.md](TODO.md) contains unplanned debt and does not
allocate work. Do not use one file to substitute for another.
