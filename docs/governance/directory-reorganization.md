# Directory Reorganization Ledger

Status: active, incremental migration, 2026-08-07.

## Rules

1. Move only generated files or directories whose source/build dependencies
   have been checked.
2. Move one bounded batch at a time.
3. After every batch, rebuild `ntdos64-run` and run the available default-test
   subset. Record failures before continuing.
4. Preserve historical evidence; move it with a manifest or record rather than
   deleting it.
5. Do not move `src/`, `upstream/`, `tests/`, or `tools/` during the first
   migration waves.

| Current concern | Target location |

**Destination:**

- `artifacts/host-tools/masm386-managed-v1/objects/`

move and checked again at the destination.

**Post-move verification:** rebuild `ntdos64-run` and run the four available
default tests.

**Result:** completed. Moved 32 MASM386 host object files and two command logs.
All 34 destination hashes match the pre-move manifest at
`artifacts/host-tools/masm386-managed-v1/root-migration-manifest.json`.
`ntdos64-run` rebuilt successfully and the four available default tests passed.
