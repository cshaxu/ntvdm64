# T480 S1 任务简报、现状审计与实施规划

## 任务简报

基线为本工作树6850d28a5，产品源码继承主线157c31855。主线继续T479，
本树只进行T480。目标是以实际差异为入口，独立确认哪些修改必要、哪些可以
恢复原版或缩小；不是把T478的功能审计重新做一遍，也不是统计运行时覆盖率。
本轮不改产品源码、版本或发布包，不写O:/winnt，不推送。

范围仅为src/mvdm-host及src/non-mvdm中的宿主C/H文件。guest、固件、独立工具、
汇编和其他非C/H文件不加入差异清理；构建脚本和兼容层仅作为消费者/归属证据。
已批准#error/#line不为了重建原始条件树而恢复；保留必要接线和已证明的原版修复。

## 规划

| 阶段 | 工作与验收 |
| --- | --- |
| S1 当前 | 完成基线、旧候选现状、问题清单与计划；继续生成本树实际构建图、头文件消费者和条件证据，标明connected/unconnected/unresolved。当前只完成源码基线，不宣称接线审计完成。 |
| S2 | 优先复核未接入文件/头/分支的剩余本地改动。检查全部支持配置及消费者后恢复；不动既有批准的#error排除，不恢复已移除的历史测试镜像。无安全候选则不强造改动。 |
| S3 | 对已接入差异按owner做最小化：DOS/COMMAND/XMS/DPMI；SoftPC CPU/设备；WOW32；Redirector/原版网络；non-mvdm服务/声明及VCDEX。必要时拆为顺序子任务，不并行激活。 |
| S4 | 核对反转的旧裁决、差异登记与受影响测试；将跨全项目自主实现的独立问题交给原队列第2项，不在这里扩张。 |
| S5 | 汇总恢复/缩小/必要保留的实际差异，核验产品影响并完成相应构建、测试和本树发布；不把原版覆盖不足当作新增功能任务。 |

当前优先级：消费者证据补齐 → 已有排除之外的明显不必要改动 →
可由更小原版边界替代的已接入改动 → 登记和测试一致性。头文件和改动过的条件
选择器优先核查，因为它们可能影响多个消费者，不能按单个C文件预处理结果删除。

## 本轮证据与限制

命令：python tools/audit/inventory-host-mirror-diffs.py build/t480-s1/census-r2。
首轮PID10700只配对旧1055项；补齐来源后PID40112完整盘点1060项，均exit0。

不是最小diff算法或C语义解析器；同一语义修改可能被拆成多个块。

本轮未运行编译器预处理、链接或产品测试，未修改src或assets。本树没有缓存
不构成阻塞；下一步可正常生成。S1保持活动，不把本轮简报误报为全部T480完成。

本轮交付检查：逐文件/逐块数量、哈希配对、块ID唯一性与汇总一致；src和assets
没有修改。文档治理PID19072 exit0，git diff --check通过。只提交审计工具、
基线和简报规划，不构建或发布产品，不推送。
