# T480 S3 connected host mirror restoration

## Question and boundary

Which connected host C/H changes can be restored to pinned OpenNT without
changing the selected product? The owner also includes unnecessary structure
and symbol naming differences. Guest, excluded configurations, new features,
new tolerance and completed S2 work remain outside this implementation.

S3 closes its bounded conservative review and verified restoration delivery.
This is not a claim that all 5,812 substantive/mixed lexical blocks have
independent semantic proof.
The S1 IDs describe diff blocks, not independent defects. Existing exclusions
and required modern-host bindings are not restoration opportunities merely
because their text differs.

## Confirmed recovery

| Original owner | Change | Verification |
| --- | --- | --- |
| DOS COMMAND cmdexec.c | Original 32-bit command-tail address expression. | Actual x86 COFF comparison; only one equivalent scale-one EDI/EDX SIB ordering differs. |
| DPMI dpmiint.c | Original `#ifndef i386` selector. The actual command does not define `i386`. | Same selected function and identical actual object code/data/relocations/symbols. |
| CCPU fpu.c | Original compound-assignment expression, removing a redundant IU32 cast. | Identical actual x86 object contract. |
| Eight host files | Ten original spelling/comment fragments outside S2's resolved IDs. | All thirteen actual consumers preserve tokens and logical locations. |
| RTL time.c | Original SecondsToStartOf1970, ConvertSecondsTo100ns and complete RtlSecondsSince1970ToTime body. | Actual production object linked to a seven-case calendar fixture, including ULONG maximum and output guards. |
| Base client vdm.c | Original structure, comments and declarations of BaseCreateVDMEnvironment, BaseDestroyVDMEnvironment and BaseGetEnvNameType_U. | All six actual x86/x64 consumers preserve code/data/relocations/symbols. Keep OPENNT-HOST-065 native-width byte distance. |

The time conversion retains its existing selected subset and unsupported
profile errors; it does not import the remainder of the RTL time unit. Its
multiply provider is the existing declared NTDLL RtlExtendedIntegerMultiply.
The Base environment restoration likewise preserves component selection,
call order and error behavior; it does not introduce new environment handling.

## Reproducible focused checks

Run through the repository's owned background execution policy, with fresh
output roots and the matching Visual Studio developer environment:

- `python tools/audit/capture-t480-s3-objects.py <phase>` captures the three
  frozen S1 expression consumers before and after the exact restoration.
- `python tests/build/verify-t480-s3-restoration.py build/t480-s3` checks those
  objects and the thirteen spelling consumer receipts.
- `python tests/build/verify-t480-s3-time.py --output build/t480-s3/<fresh-name>`
  builds the actual selected time source and runs the independent FILETIME
  calendar cases; it does not substitute a test implementation.
- `python tools/audit/capture-t480-s3-environment.py x86 before` (and x64,
  after/final) captures the six Base client objects.
- `python tests/build/verify-t480-s3-environment.py build/t480-s3 final` compares the
  six before/after contracts, including actual source hashes.

COFF timestamp, CodeView object-path records and compiler section checksums
are not executable semantics. Other code, data, relocations, symbols and
string-table contents are compared. The only permitted instruction rewrite
is the specifically asserted cmdexec scale-one SIB permutation.

The initial spelling comparison used strict preprocessor text and failed on
internal whitespace. It was replaced by a token comparison that still preserves
literal contents and logical file/line positions. Both attempts are retained.
The first temporary time fixture link invocation incorrectly passed object and
library inputs to `/TC`; correcting the `/link` boundary passed, and the checked-in
runner independently passed. Neither failed attempt is reported as a pass.

## Structure and naming retention checks

- WOW's renamed original callback, hook and timer implementations have real
  wrappers under wow32-dll. Those wrappers own callback scopes, nested execution
  and cleanup. Restoring just the names would collide with or bypass them.
- CCPU exception-hook braces contain the required fault-state reset before
  c_cpu_continue; they are not redundant single-statement braces.
- CCPU debug-pending state, atomic event consumption, big-stack updates,
  protected-address translation and FPU status corrections preserve prior
  recovered semantics. Textual similarity is not reason to undo those fixes.
- Redirector async records, guest-copy boundaries and ownership cleanup remain
  required. Original durable guest pointers cannot replace them.
- Native USER identity, dialog procedure/result ownership and callback destruction
  checks remain modern-host bindings. Restoring NT4 private object access would
  change the product's ownership and lifetime contracts.

## Delivery result

Both coherent architecture builds and the final affected-image rebuild passed.
Final package-r2 passed all 16 Full gates and the WINMINE flag/counter, reset,
open-cell, WM_CLOSE and launcher-completion test. All 11 tested image hashes
match this worktree assets/release after publication. Existing DOS4GW/NESticle
exclusion remains explicit; it is not counted as a pass. No guest source was
modified, no O:/winnt publication occurred and no push is authorized.

The final diff review removed an accidental whole-file CRLF conversion from
vdm.c. Bytes outside the restored environment owner now exactly match the
baseline. All six actual consumers were compiled again from the final LF file
and retain the same before/after COFF contract. Thus the tested package's
compiled semantics remain valid; a newline-only correction is not represented
as a newly linked package. The correction and both capture sets are retained.

`artifacts/mvdm-audit/t480-s3-delivery.json` records run IDs, results, package
hashes and the sealed `t480-s3-verification.zip` identity. The archive includes
before/after/final objects, exact commands, focused results, both Full attempts
and publication receipts. The corrected final review passed documentation
governance and git diff checking. The first review's EOF whitespace failure is
preserved alongside its passing successor.

This is one local S3 P delivery. T480 is not closed; the planned S4 registration
reconciliation and S5 aggregate review remain unadmitted. They must preserve the
proof limits below rather than convert conservative retention into a claim that
all mirror differences are necessary.

## Finite disposition and interpretation

The machine-readable [S3 dispositions](../../../artifacts/mvdm-audit/t480-s3-dispositions.json.gz)
cover exactly the 5,812 frozen S1 substantive/mixed IDs, excluding S2's 146 IDs.
Each row retains its original range/hash, current source hash, actual object
consumers, prior evidence and file-level registration references. Reproduce
with `python tools/audit/classify-t480-s3-dispositions.py` after restoring the
sealed receipt inputs beneath build/t480-s3.

| Disposition | Lexical blocks | Meaning |
| --- | ---: | --- |
| Existing exclusion/layout retained | 2,142 | Changed-side slice contains only diagnostic directives or no content; do not restore the excluded original body. |
| Reviewed fragment restored | 13 | Three expressions and ten comment/spelling fragments, with focused compiler evidence. |
| RTL owner minimized | 8 | Blocks belonging to the selected time owner, including retained exclusions; not eight independent fixes. |
| Base environment owner minimized | 8 | Blocks overlapping the restored environment owner; other content in a mixed block remains governed by its existing boundary. |
| No further safe reversion proved | 3,641 | Conservative retention after owner-group review; not a semantic-equivalence PASS or proof of global minimality. |

The last category is deliberately weaker than "all differences necessary".
Neither a registration ID, a linked consumer nor a passing product suite proves
that an arbitrary source edit can be reverted. No additional edit is authorized
by this ledger alone. The finite review found no further **proved safe** change;
it does not establish a mathematical minimum diff or independently re-prove
all inherited adaptations. Mixed blocks frequently align an excluded function
against a relocated selected function; their line additions are not counts of
new algorithms.

| Reviewed owner | Retention decision and counterexample to blind restoration |
| --- | --- |
| DOS/COMMAND/DPMI/XMS | Keep guest-memory leases, detached native-child copies, CPU40 stack publication and source-owned register results. A durable original host pointer cannot replace the bounded guest mapping. Original selector/address spelling was restored only for the measured consumers. |
| CCPU, device and host paths | Keep atomic pending-event consumption, debug/fault state, stack/address-size corrections, FPU bit/status fixes, typed CPU40 video writers and keyboard/EOI sequencing. Earlier repairs are not reopened. Device diagnostic hooks are not proved redundant merely because they are optional. |
| WOW32 | Keep callback scopes, resource/alias ownership, async cancellation retirement and existing T478 cleanup/result fixes. Renamed original implementations have active wrappers; simply restoring names would bypass those owners or collide. |
| Redirector/network | Keep asynchronous completion ownership, guest copy boundaries and native encoding/call ABI. Original durable guest pointers and narrower host carriers cannot be substituted without changing lifetime or ABI. |
| Base/RTL/network services | Restore the original time and environment owners as measured. Keep native-width CSR tables and pointer distances, selected service entrypoints and header cohorts. Reintroducing the whole NT4 Base/CSR shell is outside the product. |
| USER headers/client/kernel subsets | Keep explicit task context, native HWND/private identity bridges, callback destruction checks and modern SDK declaration selection. Apparent duplicate dialog checks surround an intervening callback. Selected original functions moved under component selectors are not new local algorithms. No general reordering of those multipass owners is proved safe. |

## Observed non-passing runtime attempt

The first package Full run failed at same-console relaunch. Its first DOS MEM
and native VER succeeded; the second scripted run16 command lost its opening
characters, and the following MEM ran in the outer native CMD, displaying
Windows' unsupported-16-bit-application dialog. The observer timed out with
33 scripted characters remaining. This is the observed failure mechanism, not
a proven cause or a pass. Preserve full-r1/cooked-return receipts and rerun the
complete suite on the final package. The final run passed this unchanged
assertion and 12 immediate relaunch pairs. No product workaround or assertion
relaxation was added; the intermittent cause has not been independently proved.
