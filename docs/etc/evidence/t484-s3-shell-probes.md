# T484 S3 P49: native shell and hook producers

B0051 formerly invoked NASM and generated two compiler batch files in its
PowerShell runtime runner. Native targets now own all42 guest variants and
the caret/OLE native peers. The runner selects an already-built variant and
retains its private-desktop, package identity, provider hash and runtime checks.
Its compiler-environment option remains accepted for compatibility, but no
longer controls a compiler invocation.

The42 variants include six ordinary NE probes, the shell child, installed-hook
variant, isolated VDD probe, five clipboard formats, two OLE variants and all26
optical-drive selections. Every output matches the previous assembler command
bytewise. Both81920-byte native DLLs differ only in two actual PE timestamp
bytes. The caret command retains its original implicit CRT selection; the OLE
command retains explicit /MT. No product ABI or guest binary is changed.

The native OLE target derives RVA477472 from the current WOW32 map, matching
the original runner computation. The map is a configure dependency; the image,
map and source are build dependencies. The runner still rejects an image whose
input hash differs from the selected package. It does not replace that check
with a path or filename assumption.
