# T485 S3 H019 SoftPC support

The seven inventory entries comprise get_env.c (identical upstream), four merged units (ios.c, main.c, terminat.c and time_day.c), and the two old root build files. The worker now reads the XP Daytona sources.inc. The three-way merge preserves the selected product configuration and adopts the XP undefined-port retry and sound termination path.

The port dispatcher requires the original host VDD loader. Port 0x201 loads the project-built x86 VJOY.DLL. Its XP implementation uses the PIT latch and parameter operations from nt_vdm.c. The batch therefore includes the required timer, host VDD, public header, export and packaging changes. H020 will review the rest of the timer directory. These companion changes count toward H019 only.

The cached host build linked VJOY.DLL. A standalone DOS COM test sampled the DOS clock before and after IN/OUT on port 0x201. The isolated worker initially had no VJOY module, subsequently loaded the DLL from its own system32, and the program exited with code zero. This verifies on-demand loading. Physical joystick input was not tested. See build/t485-s3-h019/joy-result.txt and joy-report.txt. DOS4GW also reached the NESticle menu and Escape hid and restored it (build/t485-s2-h008-three-way/dos4gw-product31).
