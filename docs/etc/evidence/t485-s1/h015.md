# T485 S3 H015 disks

The twelve local paths comprise seven C files with upstream and local edits, three with local adaptations to unchanged upstream code, and two old build files. All ten production C sources now come from the XP Daytona sources.inc selection. The Daytona makefile and sources replace the old root pair. The seven source merges preserve normal PC behavior and the prior product exclusions. The SP1 code explicitly narrows the disk geometry, CMOS values and floppy controller register writes at their destination widths. NEC-98-only branches remain excluded.

The cached x86/x64 build passed (build/t485-s3-h015/product.log). On a private desktop a DOS test issued INT 13h with AH=08h and DL=FFh. The nonexistent drive returned carry set, and the test exited zero (build/t485-s3-h015/geometry.txt). This is a read-only geometry error-path test. It does not exercise transfers to a physical disk. The DOS4GW PIF reached the NESticle menu and Escape hid and restored it (build/t485-s2-h008-three-way/dos4gw-product27).
