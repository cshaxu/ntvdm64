# T485 S3 H020 system and H021 unix

H020 reconciled 14 original entries. Nine C sources changed on both sides. The XP changes include DMA, interrupt controller and timer handling. H019 had already delivered the joystick latch in timer.c. The XP repair to the CPU_40_STYLE conditional in illegalp.c selects the original host_error call in the production build. The timer uses the worker-relative VDM state when checking the protected-mode timer hook.

The XP and OpenNT blobs for dummy_nt.c and qevnt.c match, so their existing project adaptations carry forward. The obsolete ica.old has no XP counterpart. Daytona manifests replace the legacy makefile and sources. The worker uses the eleven PC sources. The extra system.c listed by XP contains only NEC_98 code. Neither cmos.c nor quick_ev.c belongs to the selected Daytona source list.

H021 contains only makefile and sources in both trees. Both differed solely in line endings. Both now match the pinned XP blobs byte for byte. Neither is an input to the product build.
