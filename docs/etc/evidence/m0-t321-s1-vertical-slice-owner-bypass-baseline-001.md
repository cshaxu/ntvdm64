# M0 T321 S1 — First vertical-slice owner and bypass baseline

## Selected product closure

The selected product is the original `CPU_40_STYLE`/CCPU40 graph generated by
`tools/build/New-T310OriginalSoftpcNinja.ps1`.  Its normal process link takes
the original CPU40, BIOS, keyboard, system, disk, video, C-VID, comms, DOS,
DEM and COMMAND archives with the bounded original-shaped host bindings.  The
link recipe names neither a Bochs object nor `src.old`.

## Ownership chain

1. Original `obj.vdm/ntvdm.c::main` calls original
   `base/support/main.c::host_main`.
2. Original `host/src/nt_msscs.c::InitialiseDosEmulation` runs reset,
   `SetupInstallableVDD`, `scs_init`, and loads immutable `dos/NTIO.SYS` into
   SoftPC SAS; it then sets the original NTIO CS:IP.
3. Original `host/src/nt_cpu.c::host_start_cpu` enters original
   `base/ccpu386/c_main.c::c_cpu_simulate`.
4. Original CPU40 BOP dispatch selects `base/bios/bios.c::MS_bop_0`; original
   `host/src/nt_bop.c` calls the original DEM dispatcher.  `SVC_DEMLOADDOS`
   selects original `dos/dem/demmisc.c::demLoadDos`, which loads immutable
   `dos/NTDOS.SYS` using the shared synchronous mapping lease.
5. The resulting DOS/COMMAND guest path owns `EXEC`, PSP, arena, JFN,
   environment and parent restore; original COMMAND consumes the matching
   `54:0B` result route.  This is the frozen T318 contract, not an app-owned
   implementation.

## Boundary and negative sweep

- `app-machine-shell.lib` owns only executable-relative media selection and
  startup composition.  It is not linked as a substitute BOP/DEM/COMMAND/DOS
  provider.
- `softpc-bindings`, `softpc-win32-bindings`, `basesrv-bindings`,
  `monitor-bindings`, `debugger-bindings` and `session` are link boundaries
  for historical forms.  They do not replace the original owner call order.
- T319 restored the original ROM loader; T320 proves default FDC `wait_int`
  and INT15 ROM entries are now resident.  The open edge is therefore exactly
  original `floppy.c::wait_int -> host_simulate -> c_cpu_simulate` together
  with FDC/ICA event scheduling—not a missing media file, BOP provider,
  app fallback or guest edit.
- The static sweep found no selected process-link edge to retired Bochs or
  `src.old`.

## S1 disposition

The first slice has one continuous original owner path through guest load;
there is no discovered bypass to remove.  Runtime continuity remains blocked
only by the already-recorded CPU40 recursive execution/device-event contract.
T321/S2 may run the fixed x86/x64 integration matrix against this exact graph;
it must not repair that CPU40 edge by inventing a device completion.
