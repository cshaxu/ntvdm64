# M0 T451 S3 — mutation, destruction and copied-state closure

## Delivered boundary

S3 closes the finite R05, R09 and R10 rows from the T451 S1 contract ledger.
The delivery retains the existing original USER16/WOW32 algorithms and the S2
page-domain/window-word copied-view owner. It introduces no guest change,
private NT4 USER layout interpretation, second window registry, synthetic
destruction engine, or release-image change.

R05's host-originated scalar and geometry updates use the one established
post-native-return publication transaction. R09's terminal route retains the
exact enrolled generation through downstream hook reentry, invokes original
control/dialog finalization, and withdraws the copied identity only after that
original cleanup. R10 keeps original `xxxInitTask` as the producer of task
compatibility state and projects only its required values into the explicit
project carrier.

The modern host does not expose NT4's private `WFDESTROYED` destruction
transaction. The public return-hook/WinEvent/CBT investigation proves that no
small public replacement is semantically equivalent for every root, child and
failure path. This is a documented host boundary, not a second implementation
or a waived reachable failure: the selected actual adapter lifecycle is covered
by the complete acceptance group below. A later task may only revisit it if a
concrete observable discrepancy is demonstrated.
