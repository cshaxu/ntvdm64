## Finding and change

B0060 generated C/header projections, queried retired Ninja object names,
rewrote CL/LINK commands and compiled its unit from PowerShell. Two old
instrumentation targets no longer existed in the source: capture/normalize
had moved into the shared window-capture provider.

The native graph-cost target now instruments the current graph transaction:
refresh/project wrappers, its four capture calls, normalization call and
publication call. Shared capture/normalize implementations are unchanged;
only this graph transaction's calls are timed. The existing five inclusive
counter kinds and concurrency-refusal ABI remain. This is an updated
diagnostic boundary, not evidence of unchanged historical timing values.

Native CMake verifies exact source boundaries and inverse transformations.
The diagnostic uses the production object's compile profile and replaces one
member of the actual WOW link list. The header's module/concurrency checks are
also generated natively. The standalone graph counter fixture uses the CMD
fixture entry. No production code, mirror or original guest was changed.
