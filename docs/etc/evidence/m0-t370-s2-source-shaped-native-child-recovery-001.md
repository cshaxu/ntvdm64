# M0 T370 S2 — source-shaped native-child recovery

## Result

S2 closes the finite local COMMAND native-child cohort.  The result is not a
general CSR/CSRSS broker, Redirector completion path, WOW lifecycle, or DOS
EXEC/PSP return claim.

## Original source contract retained

- `cmddisp.c` continues to route `54:08`, `54:0A` and `54:0B` to
  `cmdExec`, `cmdExecComspec32` and `cmdReturnExitCode`.
- The mirrored `cmdExec32` still blocks the event thread, adjusts the original
  shell count, creates the original `cmdCreateProcess` worker, and asks the
  Base VDM client for `RETURN_ON_NO_COMMAND`.
- The mirrored worker still increments re-entry before source environment,
  current-directory, `CreateProcess`, resume, wait and exit-code work; it
  decrements re-entry only after its original completion path.
- `54:0B` remains the separate original DOS child-return route.  S2 does not
  substitute a host child completion for guest PSP or parent return semantics.

## Bounded divergences

- `MVDM-HOST-DIV-196` replaces only durable NT4 `GetVDMAddr` aliases that
  would cross into the detached worker.  The session-owned adapter snapshots
  the bounded command tail, double-NUL environment and three 32-bit stream
  identities before worker creation.  It preserves the original command-tail
  CR-to-NUL guest write and exposes no guest pointer to the worker.
- `MVDM-HOST-DIV-197` restores the historical BaseSrv relation during the
  narrow thread-create-to-re-entry-increment interval.  The local Base VDM
  binding waits for the source worker's increment/decrement or a new record;
  it does not fabricate a command or alter `VDMINFO` states.
- `ADAPTER-SOFTPC-043` records the session-owned lifetime seam.  Host stream
  resources stay opaque 32-bit identities and are resolved through the
  existing standard-stream adapter; no raw host handle enters guest state.

## Focused proof

The generated x86 fixture `command_native_child_fixture.exe` passed after
building with the formal MSVC environment.  It proves all of the following in
one bound session:

- capture of a guest command tail, environment and three stream identities;
- original observable CR-to-NUL command-tail update;
- rejection-free bounded snapshot consumption and teardown;
- `RETURN_ON_NO_COMMAND` waits while a native child launch/re-entry is active;
- the wait completes after worker-side re-entry decrement without delivering a
  synthetic command;
- child state is cleared after completion.

The fixture is generated by
`tools/build/New-T370CommandNativeChildNinja.mjs` and its source is
`tests/adapter-mvdm-host-out/basesrv/t370_native_child_lifecycle_fixture.c`.
