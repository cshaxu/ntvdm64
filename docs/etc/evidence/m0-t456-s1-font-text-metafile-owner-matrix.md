# M0 T456 S1 — font, text and metafile owner matrix

**Status:** closed source/build audit. This record fixes the selected owners and the finite S2 repair boundary; it does not claim that the W08 family has passed guest content acceptance.

## Question, inputs and method

The question is whether the selected WOW32 font, text and metafile routes are original providers with bounded host seams, or whether a project replacement silently owns one of their algorithms. Inputs were the current formal x86 graph `build/.ninja/msvc-x86-release/wow32/build.ninja`, the selected original MVDM files below `src/mvdm/wow32/`, the linked `src/wow32-dll/source/wow_public_user_facade.c`, dispatch table `wgtbl2.h`, and the retained T420 and replacement-audit evidence. `rg` caller searches covered the facade exports, task teardown and focused fixtures. No guest image was changed, rebuilt or run.

The formal graph compiles `wgfont.c`, `wgtext.c`, `wgmeta.c` and the facade into the same `wow32.dll`; this is the production selection, not an archive. There is no current `wow32_public_api_adapters.c` path in the tree or graph. The older audit's duplicate-file observation is historical and must not be counted as a second live provider.

## Missing-private-edge decision

`GetGlyphOutlineInternalA` and its `gre/ttgdi.cxx` font-transform machinery are not present in the selected mirror and depend on private GDI engine state; a direct import would violate the finite-host-boundary rule. The source-visible contract is nonetheless small: when the selected font has nonzero escapement or orientation, the WOW query must obtain the same outline as that font with those two `LOGFONT` fields ignored, while preserving the caller's DC, `MAT2`, buffer/result and error contracts.

S2 is therefore bounded to a temporary public-font selection seam: query the selected `LOGFONT`, create an otherwise identical zero-rotation font only when needed, select it for the single public glyph query, and restore/delete it on every exit. It must preserve the current public call unchanged when rotation is already zero and must not create a font cache, replace text drawing, or claim private GDI equivalence beyond the source-proven two-field policy. A focused fixture must prove (a) rotated source font differs under the raw public call, (b) the seam matches an explicitly unrotated equivalent font, and (c) failed create/select/query restores the original selected font without leaked GDI objects. This is an adapter repair, not a guest or original-MVDM edit.

## Evidence, confidence and handoff

The existing `wow_gdi_etm_fixture.c` and `wow_font_tracking_fixture.c` compile the linked facade body and have durable T420 positive/negative evidence. They prove their narrow seam contracts, not guest text/metafile content. Static confidence is high for graph selection and one-owner classification; runtime confidence remains intentionally open for S2 text and S3 metafile content.

S2 owns only the glyph-outline seam and guest text/font lifetime acceptance. S3 owns metafile acceptance. Neither stage may introduce a generic renderer, font registry, guest-root merge or a private GDI import. Guest media remains immutable.
