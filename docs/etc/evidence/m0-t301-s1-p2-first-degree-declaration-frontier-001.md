# M0 T301 S1 P2 — First-Degree Declaration Frontier

The approved original-header closure from P1 was token-scanned only for the
frozen T300 target spellings. This yielded 14,905 caller-to-header token rows:
6,133 physical call occurrences and 766 spellings have a same-named token in
their physical caller include closure.

The largest declaration-carrier groups remain original MVDM headers. That is
not evidence of an MVDM implementation: a declaration-only historical
SoftPC/monitor interface may legitimately cross the MVDM boundary. T301 P3
must search source bodies only in the declaration-authorized packages and
record whether each such item is an MVDM zero-closure anomaly, a non-MVDM
original body, or a declared adapter/hard boundary.

The remaining boundary calls have no matching token in their original include
closure. They stay explicit; P3 must classify them separately as public CRT,
macro/assembly/indirect, private boundary or source-unavailable. No second
degree body was read and no provider was selected.
