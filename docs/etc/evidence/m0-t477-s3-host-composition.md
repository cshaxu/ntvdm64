# T477 S3 host composition evidence

## Scope and implementation review

The [S3 design](../operations/m0-t477-s3-vm-frontends-design.md) defines the
host boundary. NTVDM owns payload/VM/incarnation and copied provider state;
NTSRV owns authenticated instance keys, attachment and retirement. The adapter
composes existing frontend-base service and pipe mechanics directly. Neither
worker-base nor NTCON acquires a reverse dependency. The existing original
host exit authorization seam joins registered frontend work before host
resource release; no new mirror hook is introduced.

VM-handle reuse obtains a new process-lifetime incarnation. Worker-local
payload tokens are generated by the worker host, not guessed guest identities.
Registration rollback retains the broker key and borrowed context until
retirement succeeds. Service loss cancels serving I/O before release. A local
join error after whole-worker exit authorization fails the process without
freeing storage under a live callback. This is not a retry or recovery engine.

Control is serialized by the host lock; provider callbacks cannot reenter
control. Active sibling I/O does not take that lock. Admission closes before
terminal retirement, and the host object remains alive until control callers
have stopped. The adapter validates channel generation, version, sequence and
opcode before dispatch, and stamps reply identity itself. Operation-specific
payload validation belongs to the provider.
