# M0 T255 S2 — Generic Context Resume Closure

## Delivered seam

The existing selector-blind #UD bridge now has a versioned v2 outcome beside,
not in place of, v1.  The copied result admits only:

- an unchanged, real, or protected execution-mode target;
- masked 32-bit general-register values;
- masked segment selectors;
- a bounded native FLAGS mask; and
- a copied resume RIP.

The adopted core applies each accepted field through existing native CPU
methods.  It accepts no CR0 payload, pointer, descriptor cache, guest-memory
action, allocation, service identifier, or provider-specific branch.

## Native CS correction

The first fixture exposed an upstream rule rather than a missing capability:
`load_seg_reg` intentionally rejects CS while protected mode is active.
The final result therefore applies data/stack selector values with that native
loader, and applies a requested protected CS through the existing native
`jump_protected` validation/branch path.  The fixture supplies a local GDT so
that Bochs, not project code, parses and validates the descriptors.

## Remaining boundary

This closes only context expression and native application.  It does not yet
provide fault-contained protected selector:offset read/write or guest-linear
mapping identity, so no DPMI source provider is admitted by this result.
