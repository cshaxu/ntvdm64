# Superseded NT BOP wrappers

These former project-named `MS_bop_0` and `MS_bop_4` wrappers are retained for
Git/provenance review only. Their source-ordered bodies now reside in the
original-name `src/opennt-bop/softpc/nt_bop.c` translation unit, so these files
are not a production include, formal Ninja input, runtime route or current
test input.

The archival move preserves the final pre-folding working-tree content; it is
not an alternate provider. `BOP-DIV-097` and `BOP-DIV-099` register the active
minimal source subsets and their same-shaped adapter dependencies.
