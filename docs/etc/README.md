# Supporting Material Index

This directory contains evidence and operational detail. It cannot define a
competing current architecture, rule, roadmap, queue, or status.

| Area | Contents | Current authority |
| --- | --- | --- |
| `operations/` | Governance migration, policy, and retained task-supporting plans | `../rules/` and `../states/CURRENT.md` |
| `research/` | Source, ABI, build, and compatibility observations | `../states/CURRENT.md` and `../design/` |
| `architecture/` | Retained architecture supporting records | `../design/ARCHITECTURE.md` |
| `evidence/` | Closure records, fixtures, and retained detailed status ledgers | `../rules/EXECUTION.md` |
| `archive/` | Superseded queues and retained planning indexes | Current authority documents above |

Pre-governance records remain in the direct legacy tree until a manifest-backed
batch moves them here. The migration inventory is
[governance-migration.md](operations/governance-migration.md).
The exact-file, SHA-256 snapshot covering every Markdown document is
[document-inventory.md](operations/document-inventory.md); regenerate it with
the documented exporter whenever a governed document changes.
Large operations ledgers are governed by the
[ledger retention register](operations/ledger-retention-register.md) and its
per-file [TSV manifest](../../artifacts/documentation-archive/20260910/etc/operations/ledgers/ledger-retention-register.tsv).
The identifier and execution model is
[task-identifier-governance.md](operations/task-identifier-governance.md).
The plans and ledgers below are retained historical supporting material; they
do not admit or describe a current active packet. The closed T95 plan and
retained chronology remain
[m0-t95-subtask-plan.md](operations/m0-t95-subtask-plan.md) and
[m0-t95-status-ledger-20260811.md](../../artifacts/documentation-archive/20260910/etc/evidence/m0-t95-status-ledger-20260811.md).
