# M0 T305 S1 — DEM/COMMAND vertical-slice source recovery

## Objective

Recover the first source-shaped DEM/COMMAND vertical slice from the selected
`mvdm-host` mirror.  The work begins with the exact original dispatcher,
Base-VDM command and machine-facing contracts, then selects the smallest
original translation-unit closure that can be composed through existing named
adapters.

## Required work

1. Map reached selector families `50:xx` and `54:xx` to their original
   dispatcher/source-owner files, rather than treating an ingress callback as a
   provider.
2. Reconcile the original callers with the closed Base VDM local protocol
   (`adapter-mvdm-host-out/basesrv`), the `adapter-mvdm-host-out/softpc`
   mapping/finite-resume forms, and T304's copied machine-event ingress.
3. Attempt the smallest original-source compilation closure for the selected
   bootstrap/command-get path; retain original ordering, data layout and
   failure behavior.  Missing historical imports must receive one named
   same-shaped adapter disposition before any new logic is authored.
4. Add an x86/x64 focused local proof for the admitted original-source path,
   or record the exact compilation/link blocker and the next bounded source
   recovery P.

## Non-goals

No trace-selected BOP implementation, full DEM file/redirector behavior,
child-process product shell, CSR/CSRSS reconstruction, WOW, XMS, DPMI,
machine/device expansion, guest execution claim, or new app-owned command
provider.

## Exit

The first vertical source slice has an original-owner map, an attempted
source-shaped closure, one owner for each reached boundary, and a focused
x86/x64 local result.  Any remaining body work is explicitly limited to the
next sequential P of this same S.
