## Governance correction

T176 is the current single medium-sized package for the complete observed
normal-return path: its lifecycle/COMMAND handoff, the source-owned machine
BOPs reached after that handoff, and the resulting bounded continuation or
terminal-result decision. It is not a per-selector repair programme and does
not reopen the already closed, holistic adapter BOP host-service plane (T96).
Historical files
and directories named `t177` through `t182`, including an earlier pre-repair

later current T, reopen a closed package, or displace T176.

The package contains the granular source, controller, provider, link, trace
and mechanics steps below. Its expected outcome is either (a) a bounded,
source-owned route through the original machine handler and native Bochs
mechanics with a proven next COMMAND continuation, or (b) an evidence-backed
T176 closure that names the exact unresolved owner boundary. A trace, BOP
selector, object link or diagnostic is an S-sized unit of evidence, never its
own T.
