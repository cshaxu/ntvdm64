# M0 T301 S1 P20 — `one-ledger1` Physical Signature/Condition Gate

P20 consumes only P19's 310 unique-candidate, reachable-declaration rows. It
compares the direct call expression, original header declaration and original
definition signature arity, and records caller/definition preprocessor context.
It may read only the bounded declaration/signature regions needed for that
comparison; it must not scan a candidate body or derive second-degree calls.

A passing row becomes a future body-expansion seed, not an imported package or
runtime provider. Every mismatch or historical syntax failure remains an
explicit one-degree row.
