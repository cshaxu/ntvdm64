# Operations Ledger Retention Register

## Scope

This register governs every `*.tsv` file directly under `docs/etc/operations/`.
The generated companion manifest, `ledger-retention-register.tsv`, records one
row per ledger with its size and SHA-256 digest. It is regenerated by
`tools/governance/Export-OperationsLedgerRetentionRegister.ps1`.

## Retention contract

| Field | Value |
| --- | --- |
| Owner | Project documentation governance owner |
| Purpose | Deterministic, machine-readable ledgers supporting source, boundary, migration, and conformance evidence. |
| Current placement | `docs/etc/operations/`, because these are support artifacts rather than direct-control documents. |
| Review cadence | Review during closure of the associated packet and during any documentation-topology review. |
| Retirement trigger | A reviewed closure identifies a durable historical replacement: retain the ledger's path, digest, schema, and closure reference in the manifest; then move the raw ledger to an explicitly named archive location or remove it only with owner approval. |
| Prohibition | Do not delete or overwrite a ledger merely to reduce workspace size. |

The manifest's `retention_disposition` and `retirement_trigger` fields apply
the contract to each individual ledger. This makes the large retained evidence
auditable without treating it as live project control.
