# M0 T237 — OpenNT XMS owner-package completion plan

## Boundary

T237 owns the complete 52:xx XMS package for one declared profile. OpenNT
owns XMS policy; bx-core/bx-mantle retain CPU, RAM, A20, BIOS and device
mechanics. bx-vdm may carry only fixed-width routing and checked results.

## S sequence

| S | Objective | Exit |
| --- | --- | --- |
| S1 | Map every 52:xx endpoint, source owner, ABI, A20/UMB/INT15 prerequisite and failure rule. | A complete source/owner/ABI/failure ledger; no route is assumed implemented. |
| S2 | Recover the complete declared XMS provider through admitted native mechanics. | Each ledger item is direct source, smallest compatible seam, or explicit source-defined unavailable. |
| S3 | Run XMS allocation/move/lock/A20/UMB/failure regression and one bounded integration observation. | Declared profile regression and owner-transfer record pass without adapter-owned allocator or BIOS behavior. |

## Non-goals

No new Bochs device, BIOS, CPU, allocator or adapter-owned XMS behavior is
admitted merely because a 52:xx endpoint is observed.
