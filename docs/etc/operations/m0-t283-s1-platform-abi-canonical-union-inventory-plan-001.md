# M0 T283 S1 — platform-ABI canonical-union inventory

## Objective

Inventory every current `opennt-platform-abi` path and its OpenNT/OpenNT-4.5
candidate declarations before any source move. Give each logical header one
candidate class: identical dual-source, one-sided, conflicting, generated or
non-mirror.

## Scope

This is evidence only. It creates no hybrid declaration, changes no include
root, moves no source and enables no behavior. Every row records source path,
hash, selected/rejected status, original consumer and selection rationale.

## Exit

A machine-checkable full inventory proves the denominator and identifies every
conflict needing a single source choice. The next S may re-root only files
with a complete recorded disposition.
