## Global guardrails

- BOP host-service recovery remains a separately closed T96 architecture; no
  new per-selector T or S is created from this return-path work.
- Bochs owns CPU, reset, exception/vector, RAM and device mechanics. The
  adapter owns only copied BOP ingress, bounded host-service composition and
  typed result transition; it does not gain DOS, BIOS, IRQ or stack semantics.
- A fault after an accepted BOP is not proof that the BOP provider is wrong.
  Source and trace must identify the first bad transition before any patch,
  device enablement or host-capability expansion is considered.
- S10/S11 are conditional work, not currently approved implementation.
