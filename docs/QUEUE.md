# Queue

This is the ordered, unnumbered candidate queue. It does not activate work, assign an identifier, or define the technical baseline. Approved work enters [STATUS.md](STATUS.md) under [Execution Rules](rules/EXECUTION.md).

1. Complete the S5 complete-`BIOS[]` static/dynamic owner-seam disposition.
1. If caller evidence admits it, recover the smallest original-owner SoftPC semantic gap with a fail-closed focused fixture.
1. Attempt the fixed-profile NTIO/NTDOS smoke only after the historical software-monitor chain reaches its documented bootstrap boundary.
1. Reconcile retained evidence families against the current authority map; migrate one bounded documentation batch at a time.

External wrappers, alternative cores, mantles, and execution backends are not queue items. See [the roadmap](design/ROADMAP.md) and `etc/operations/governance-migration.md`.
