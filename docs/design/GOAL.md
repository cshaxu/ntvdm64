# Project Goal

Reconstruct an independently buildable, non-invasive, command-line invocable
NT 4-era `ntvdm.exe` research path from the OpenNT SoftPC/CCPU, BIOS/BOP, DEM,
and NTDOS ownership chain. The project must preserve provenance, fail closed
outside supported evidence, and never turn comparison projects into runtime
dependencies.

The immediate goal is a bounded, evidence-backed historical execution slice,
not a general PC emulator, DOS replacement, or external-backend integration.
