# BaseSrv family

This family supplies only the reached local BaseClient/BaseSrv VDM command
protocol. It is neither a CSRSS replacement nor a generic CSR transport.

## Registered divergences

| ID | Original purpose | Reason | Implementation | Files |
| --- | --- | --- | --- | --- |
| ADAPTER-BASESRV-001 | BaseSrv stores DOS command records, checks buffer capacities, copies `VDMINFO` fields, publishes a no-command wait object and accepts a second request after wake. | The original `BaseSrvGetNextVDMCommand` is coupled to CSRSS console/DOS/WOW records and remote duplicated handles, which cannot enter the non-intrusive host process. | `base_vdm_local.c` preserves the reached DOS-only copy, capacity, environment/no-command, pending/wake and second-request status order in one copied session-owned record. Its host `CurDirectory` carrier follows original COMMAND's `MAX_PATH + 1` request capacity; it is not truncated to a guest component limit. WOW, PIF, child, global and cross-process paths remain unavailable. | `include/base_vdm_local.h`, `source/base_vdm_local.c` |
| ADAPTER-BASESRV-002 | BaseClient exposes `GetNextVDMCommand(VDMINFO *)` and retries a signalled wait request. | The original client path relies on private CSR capture/transport and the prior monitor callback was a project-defined parallel protocol. | The historical public spelling owns a caller-local `VDMINFO` request/result snapshot, waits only on its session-local notification, reconstructs that capture for the second request, and never retains a caller pointer after return. | `include/base_vdm_local.h`, `source/base_vdm_client.c`, `source/base_vdm_local.c` |
| ADAPTER-BASESRV-003 | BaseSrv exposes `BaseSrvIsFirstVDM`, plus set/get current-directory records for a DOS console. | The originals store global/console state behind CSRSS; the product intentionally has one local session and no CSRSS console record. | The bound `base_vdm_local` record retains query-and-clear first-VDM state and one-shot copied directory `MULTI_SZ` ownership. | `include/base_vdm_local.h`, `source/base_vdm_local.c`, `source/base_vdm_client.c` |
