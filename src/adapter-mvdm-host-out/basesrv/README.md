# BaseSrv family

This family supplies only the reached local BaseClient/BaseSrv VDM command
protocol. It is neither a CSRSS replacement nor a generic CSR transport.

## Registered divergences

| ID | Original purpose | Reason | Implementation | Files |
| --- | --- | --- | --- | --- |
| ADAPTER-BASESRV-001 | BaseSrv stores DOS/WOW command records, checks buffer capacities, copies `VDMINFO` fields, publishes a DOS no-command wait object and accepts a second request after wake. | The original `BaseSrvGetNextVDMCommand` is coupled to CSRSS console/DOS/WOW records and remote duplicated handles, which cannot enter the non-intrusive host process. | `base_vdm_local.c` preserves the reached source distinction between a DOS record (pending/wake) and a WOW record (empty queue = successful zero-length nonblocking result), as well as capacity/environment/copy order. One copied session record is selected by `command_owner`; PIF, separate-WOW, child, global, WOWEXEC notification and cross-process paths remain unavailable. Its host `CurDirectory` carrier follows original COMMAND's `MAX_PATH + 1` request capacity; it is not truncated to a guest component limit. | `include/base_vdm_local.h`, `source/base_vdm_local.c` |
| ADAPTER-BASESRV-002 | BaseClient exposes `GetNextVDMCommand(VDMINFO *)` and retries a signalled wait request. | The original client path relies on private CSR capture/transport and the prior monitor callback was a project-defined parallel protocol. | The historical public spelling owns a caller-local `VDMINFO` request/result snapshot, waits only on its session-local notification, reconstructs that capture for the second request, and never retains a caller pointer after return. | `include/base_vdm_local.h`, `source/base_vdm_client.c`, `source/base_vdm_local.c` |
| ADAPTER-BASESRV-003 | BaseSrv exposes `BaseSrvIsFirstVDM`, plus set/get current-directory records for a DOS console. | The originals store global/console state behind CSRSS; the product intentionally has one local session and no CSRSS console record. | The bound `base_vdm_local` record retains query-and-clear first-VDM state and one-shot copied directory `MULTI_SZ` ownership. | `include/base_vdm_local.h`, `source/base_vdm_local.c`, `source/base_vdm_client.c` |
| ADAPTER-BASESRV-004 | BaseClient `ExitVDM(FALSE, ...)` tells BaseSrv to terminate the DOS VDM. | BaseSrv's console/process termination path is a CSRSS product shell and must not terminate the modern host process. | The same public spelling completes only the bound DOS session through its typed session lifecycle. WOW task exit is deliberately unavailable. | `include/base_vdm_local.h`, `source/base_vdm_local.c`, `source/base_vdm_client.c` |
| ADAPTER-BASESRV-007 | BaseSrv keeps an ordinary DOS VDM waiting after COMMAND consumes a command and asks for another. | The app's explicitly declared one-shot CLI command has no CSRSS console command producer; adding a synthetic guest command or modifying COMMAND would change the original DOS path. | An app-only flag is armed before startup. Only after the copied DOS record is consumed and original COMMAND makes the next BaseVDM request does `base_vdm_local` take the existing typed session-termination escape. Ordinary, WOW, initial and `RETURN_ON_NO_COMMAND` requests retain their source-shaped behavior. | `include/base_vdm_local.h`, `source/base_vdm_local.c`, `src/app/launch_declaration.c` |
| ADAPTER-BASESRV-008 | BaseSrv uses one `hWaitForVDM` object for both a newly available DOS record and a re-entry-count transition. | The former local seam used two events and initialised the re-entry event signalled, so an ordinary no-command wait could wake before a producer existed. | Retain one manual-reset `wake_event`: publishing a DOS record and reaching a zero re-entry count signal it; the BaseClient path waits only on that counterpart and then retries its original request. | `include/base_vdm_local.h`, `source/base_vdm_local.c` |
| ADAPTER-BASESRV-006 | BaseClient/BaseSrv exchange a captured `VDMINFO` record and consume it only after the destination accepts the normal command result. | CSR capture buffers, server records and duplicated wait handles cannot cross the modern product boundary, while a direct app-to-local write would bypass the selected broker contract. | `base_vdm_broker` copies the DOS subset into `broker`'s fixed-width record, peeks it, copies into the existing local source-shaped record, then consumes only after that copy succeeds.
