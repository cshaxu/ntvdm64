# opennt-utils

Selected reusable original OpenNT utility packages.  A utility enters this
component only after the MVDM owner census proves it is neither guest image,
BOP provider, independently composable host product capability nor SoftPC
machine contract.  This is deliberately not a generic project `common` root.

Utilities retain their original upstream-relative paths and filenames after
re-rooting.  They may be compiled only when an admitted original caller
requires them; this empty skeleton is not a build target.
