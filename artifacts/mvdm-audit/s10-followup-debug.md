# S10 debug and VDMDBG pending-file follow-up

Scope is the eight pending C files under `softpc.new/base/debug` and `vdmdbg`; this is a read-only source/profile review, not a debugger execution test or a shared-ledger update. The DOS16 source catalogue records all eight as `not_reviewed`; the WOW32 catalogue records each original edition as `pending_boundary_scan`. Neither catalogue establishes a capability disposition. The current files' SHA-256 values match both frozen OpenNT editions. Source identity is not evidence of execution.

The original `base/debug/sources:55-64` selects the seven SoftPC files (dasm is i386-specific). The captured current x86 worker graph compiles all seven into `original-softpc-base-trace.lib`. The inspected prior object/map reports identify a PROD build without PIG, PROFILE, EGG or YODA; archive membership is not link extraction or runtime operation. These conclusions are bounded to that observed profile, and do not discard debug capabilities or alternate builds.

| File | Original role, current consumer and bounded physical role | S17 functional follow-up |

| `btrace.c` | Backtrace buffering, output and disassembly are `!PROD` (`:46`); the observed PROD object has no ordinary executable body. **Inactive in observed profile; pending feature scope.** | Determine selected debug profile and verify trace creation, output, disassembly and shutdown. |
| `dasm.c` | x86 debugger disassembler, whole body `!PROD` (`:34-2947`); backtrace/YODA are its diagnostic consumers. **Inactive in observed profile; pending feature scope.** | Verify instruction decoding, consumers and memory bounds in a real debug profile. |
