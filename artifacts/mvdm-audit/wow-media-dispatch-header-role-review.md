# WOW32 multimedia and dispatch declaration roles

Four byte-identical original headers are dependencies of selected WOW32
compilation and remain partial. The [multimedia and message review](shard-2/wow32-media-message-review.md)
distinguishes the project wrapper from the original body; the [dispatch review](shard-2/wow32-dispatch-header-review.md)
retains guest table ordering and ABI boundaries. The three legacy table
declarations with unconfirmed consumers remain pending.

Selected headers and map symbols do not prove table relocation, guest calls,
callbacks, error paths or object lifetime. No guest or product was modified.
