# MVDM audit shard 1 — initial source and owner review

Input: `../frozen-file-reconciliation.csv`, SHA-256
`F73FFD45DFF44FCA4ECEFC49EF769BEAB5C085542CD04FFE4D6A7B5F942E3196`.
This shard is precisely paths where unsigned big-endian SHA-256 first eight
bytes of UTF-8 `relative_path` modulo four equals one. All input and original
identities were rehashed with no mismatch at this review.

- 1,182 unique paths: 48 mirror differences reported partial, 13 retired
  CPU30 executor paths excluded under source policy, and 1,121 pending.
- `file-audit.csv` records every row, source/build identity, source roles,
  old evidence and missing proof. Its matching-line measure is not an
  executable-code restoration or behavioral acceptance percentage.
- `owner-review.csv` covers all 48 different paths at initial owner/source
  level, including 32 selected product sources and 16 declaration, guest or
  other roles. It cites historical evidence and specifically names remaining
  proof; this is not final semantic or runtime review of every hunk.
- `unselected-source-review.csv` traces 34 unselected original host-source
  paths to known manifest roles and explicit missing capability decisions;
  no path is excluded simply because it is not currently built.
- `wowfax-trace.md` distinguishes the selected WOW32 registry client from
  original unselected fax driver/UI targets and records the concrete
  consumer/deployment gap and one unproven source-level suspect.
- `audit.py` regenerates initial `file-audit.csv` and `summary.json` from the
  frozen source, original local source trees and current files. It does not
  write source diffs or import source; `owner-review.csv` and the unselected
  review contain independent manual evidence and are not generated by it.

All external-source and historical fixture reports remain evidence with their
original limitations. No fresh product test, guest rebuild, runtime image
modification or complete source-classification claim is made by this shard.
Further work must reconcile each original caller and profile, source hunks,
actual link/dispatch, failure/teardown and test identity. Current guest-role
rows are excluded only as host link inputs, not as proved guest functionality.

Consistency checks: 48 owner-review paths equal exactly the 48 initial partial
paths; 34 unselected-review paths equal exactly the 34 frozen unselected-host
source paths; all 1,182 paths obey the shard function. No source identities
changed since freeze.
