# Guest declaration and resource roles — shard 1

`guest-declaration-resource-owner-review.csv` lists every one of the 94 current pending rows in the requested exact extension/path/SHA shard cohort, with current verified SHA, exact original path/edition, role, proposed status, concrete edge when established, host boundary and remaining limits. All 94 current bytes match both frozen OpenNT and OpenNT-4.5 original identities. Twenty-three rows have evidence-backed excluded **file-role proposals**; 71 remain pending. This is not a change to the ledger or a claim of restored/removed guest capabilities, guest execution or exact current image lineage.

Positive chains include debug.skl and default USA-MS message → debug.ctl → debmes.obj → DEBUG.EXE; actual original GRAPHICS source includes → linked GRCTRL/GRINST objects; KEYBCMD actual includes → linked KB16; COUNTRY.ASM's actual code-page includes → COUNTRY.SYS; MSDOSME → DOSMES → DIVMES → NTDOS; and selected Win16 DEF/RC/RCV resources through original link16/RC16 targets. USA MMTASK and WRITE entries explicitly require !LANG default; other DOS locale MSG roots remain pending because `make.inc` changes the message directory when COUNTRY is explicitly supplied. Original source conditions are not proof a given installed guest uses the file.

To avoid misclassifying host/shared interfaces, the previous exact VALID dependency edges were checked and 1,431 MVDM host-side source/header files were searched for literal same-basename include directives. Seventeen rows have such textual host-tree candidates, recorded individually; they remain pending because actual include resolution, selected build flags and host consumers require separate proof. A same-basename include is not asserted to resolve to this guest copy. An especially concrete collision is `cmd/keyb/keybshar.inc`: original local and `dos/v86/inc` copies have different SHA-256 values while the makefile names the shared copy, so assembler search order and actual consumer must be resolved. No candidate exclusion rests on the absence of a cached host include alone.

Remaining rows need exact include/RC path, localization condition or artifact role; no full/partial behavioral restoration is inferred. Original and current files, other shards, products and guest were not modified and no tests or binaries were run.
