The retained module's entry then uses the null-module form, for which current `wkman.c` parses the stored native process handle, waits via USER message-aware wait, reads exit status, removes the WOA association and closes the handle. These are source/linked-code observations, not proof a current guest executed this chain. Ownership of actual guest module search and runtime lifecycle remains with the existing kernel/WOW implementation, not a newly inferred product manager.
