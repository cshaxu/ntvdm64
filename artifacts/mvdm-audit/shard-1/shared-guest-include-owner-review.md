# Shared DOS/WOW16 include ownership — shard 1

`shared-guest-include-owner-review.csv` is the exact current pending partition of 34 `.h`/`.inc`/`.mac` files under the three requested shared roots. Actual current and both pinned original edition hashes were verified against the frozen ledger. Eleven rows have a positive historical guest input role and are proposed `excluded` only for that file's host compilation role; 23 remain pending with exact sample consumer or a bounded path/guard question. No guest capability, installed image lineage or functional behavior is excluded.

The DOS `make.inc` explicitly sets MASM `-I. -I../../inc` and CL16 `-I. -I../../h`. Actual selected target consumers establish SETVER `<io.h>`, MEM's `string.h`, `stdlib.h` and explicitly-dependent `version.h`, COMMAND `dirent.inc`, KEYB `dseg.inc`, and NTIO `umb.inc`; relevant local shadow files were checked absent. `umb.inc` is additionally named by a separate SoftPC historical BIOS assembler source, not automatically a modern host C input. In WOW16, kernel31 `atom.asm`/MASM uses shared `gpfix.inc`, MMSYSTEM `joy.c` uses shared `mmddk.h`, and its debug-only `mmsex.c` uses `cpl.h`; USER's `wsprintf.c` uses `winexp.h` in the default CINCS setup, but externally supplied INCLUDE can select a different path. Each of these routes lists source/recipe line numbers and target in the CSV.

Fresh read-only `ninja -t deps` snapshots for current x86 worker and WOW32 were used for exact-path VALID/STALE consumers, together with the earlier host-side same-basename include scan. Names such as io.h, stdarg.h, stdlib.h and mmddk.h are also used by modern host code; a same spelling is not sufficient to say it resolved to the guest header. Each proposed classification relies on a positive guest chain plus absence of the exact path in these snapshots, not on snapshot absence alone. The 23 unresolved entries require a selected original source/macro consumer, include-search-path resolution, guard or resource identity rather than a directory-based conclusion.

No historical compiler, test, product or guest was executed or modified; no ledger or other artifact was changed. Cached dependency snapshots have their own build identity and do not demonstrate every possible host configuration.
