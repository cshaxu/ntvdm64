The original `print.c` entrypoints are deliberately unsupported print-manager extension functions, not a print queue implementation. They set vLastCall to LOCAL and WN_NOT_SUPPORTED, with return forms appropriate to each signature: e.g. enum/change-menu/command return SetLastError, ExtHelp returns FALSE, MoveJob returns 0 after setting the error, and void notifications return normally. Returning 0 for MoveJob is not a success witness without its documented contract. This is an original capability boundary; do not replace with fabricated print success or infer all printing is absent.
