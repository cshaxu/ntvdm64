# BOP 59 diagnostic guest reads: source-level mismatch

Frozen reconciliation SHA-256 F73FFD45DFF44FCA4ECEFC49EF769BEAB5C085542CD04FFE4D6A7B5F942E3196. `softpc.new/host/src/nt_bop.c` remains partial-mirror-diff; no product or guest was modified.

Original OpenNT `MS_bop_9` only invokes `host_direct_access_error((ULONG)getAX())`. Current `nt_bop.c:699-743` computes effective SS:SP and unconditionally calls `sas_w_at` at offsets 0, 2, 4, 6 both before and after that call, a total of eight word accesses when the call returns. Each word can become two byte reads across a page boundary (`base/ccpu386/ccpusas4.c:771`). It submits these values to `mvdm_softpc_report_setup_hardware_probe`; only inside that function (`ntvdm-exe/softpc/mvdm_softpc_termination.c:106`) is the `MVDM_WIN31_SETUP_HARDWARE_TRACE_PATH` checked. Thus disabling the output does not disable the preceding reads. The previous DIV-258 description claimed only already-live scalars were copied; the registry now records the actual source behavior.

Extra guest reads are an actual source-level deviation from original BOP semantics; this review has not established that an ordinary reachable guest stack maps to an adverse device, faults, or causes a crash. The observer test `tests/observation/softpc_observer_error_probe.c` checks reporter failure and last-error preservation directly, and does not invoke `MS_bop_9` or detect guest reads. Historical T436 S4 shows the original path was reached, not that disabled-mode reads are harmless.

Minimal candidate: remove the four stack-read observations on each side (and corresponding diagnostics) if they have no admitted operational requirement; preserve original `host_direct_access_error` call and any needed scalar-only reporting. If observation is retained, gate it before all guest-memory reads and provide a non-intrusive bounded read appropriate for CPU and memory context; a gate alone does not prove enabled tracing is safe. DIV-258 has been corrected to describe the current behavior. Verify the eventual repair with a source-linked BOP test that disabled reporting performs zero guest reads and calls the original handler exactly once with AX, including normal and handler-return cases; separately test any retained enabled observation and its failed access without changing guest execution.
