# SoftPC native pending owner review — shard 1

`native-pending-owner-review.csv` enumerates the exact 164 current pending C/header/ASM/INC paths under `softpc.new/base` and `softpc.new/host` belonging to this shard. All current bytes and both actual original edition hashes match their frozen identities. Forty-six current worker Ninja object edges and 58 paths with cached VALID dependency consumers are recorded by exact object/path; five C sources have no direct object edge in this graph. These figures are source-selection observations, not proof of reachable functions or permitted exclusions. `function_indicators` are literal source declarations, not a claim of the selected preprocessed definition. Historical map/test references retain their own snapshot identities, not automatically the package-c binary.

The stage owner column is an initial finite routing: 56 CCPU/memory paths to S11, 65 I/O/device/video paths to S13 and 43 shared/other paths to S17; the main audit must refine shared-header ownership by actual consumers before implementation. This inventory does not establish all 164 leaf contracts, and none is promoted from pending in this pass. Each row carries the prior per-path source/owner review and remaining evidence; generated C-VID files explicitly require per-vector, mode and latch dispatch coverage, not just presence in a map.

Priority state/lifetime findings: `ios.c` registers callback arrays and dispatches inb/outb through per-port owner tables; registration, multiwidth and disconnect/reset concurrency remain to verify. `c_intr.c` and `c_stack.c` are execution/privilege/fault/lifecycle foundations; S11 must test nested interrupt and return state rather than treating static `_do_intrupt`/`_GetStackPointer` as full. `floppy_i.c::diskette_int` goes through I/O, EOI and host simulation; an old no-media reset test cannot prove actual media I/O. `gvi.c` owns adapter initialization/teardown around configuration and soft reset; `video_io.c` is BOP 10 AH dispatch, while EGA has separate routes. `ega_dmmy.c` is the EGA switch-sense dummy, not proof the VGA default handler exercises it. `nt_sas.c` graph selection does not prove guarded HOST_SAS/SUN_VA bodies are active or own CPU40 allocation and teardown; inspect actual preprocessing and provider before assigning authority. `cmos.c` is an alternate CMOS source whose register/reset/persistence contract must be compared with selected cmosnt; omission from the graph cannot by itself exclude its capabilities. Existing details are in the per-path cited shard review documents.

Direct evidence examples: AAA/AAS source-selected objects had an offline native x86 oracle over 524,288 defined AX/AF/CF cases; that does not prove guest decoding, other flags or exception behavior. BSF has a 65,568-case extracted-source fixture rather than a linked-object or guest witness. T420 C-VID vector publication and historic video mode/resize evidence do not cover each generated VGA function. These evidence limits are recorded in individual rows. The remaining rows retain their prior finite review action; many shared headers still need exact consumer/preprocessor branches and should not be marked full based on identical bytes.

No guest, product, ledger or existing artifact was changed, and no build or runtime was launched. S10 remains open; neither this triage nor any source-map observation is an end-to-end behavioral acceptance.
