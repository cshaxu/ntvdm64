| `tests/ddestrs/globals.h` | Stress-program declarations included by `ddestrs.h`, which is a dependency of its source objects. This is an include-chain observation, not a build receipt. |
| `tests/ddestrs/mk4dos.cmd` | Historical build/cleanup wrapper that calls `nmake -f makefile.dos` with no argument; never executed in this audit. |
| `tests/src/client/ddemlcl.h` | Original DDE client-test declarations, referenced by its client source/object rules and `ddemlcl.rc`; that test makefile links `ddemlcl.exe` against DDEML. |

They are therefore candidates for historical guest library-build or test-only input classification **only with respect to those checked host targets**. Historical test source is not proof the test ran; excluding these paths from host build inputs does not remove or establish DDEML functionality.

These limited path checks do not establish absence on other guest media or future packages.
