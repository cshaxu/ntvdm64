# WOW16 support guest owner review — shard 1

`guest-support-owner-review.csv` covers all 47 pending paths in these five support families. It retains frozen/current and both frozen/actual original hashes, exact historical guest source/object/link/resource edge where proven, build conditions and unresolved limits. There are 27 source-file-only candidates, one guest-library artifact candidate and 19 pending. No source was classified by filename or lack of host selection alone; all candidate original source hashes match both editions and current bytes.

DDEML explicitly compiles OBJ1/OBJ2 via CL16 into its 16-bit DLL; USA dialog/RC copy and resource processing apply under !LANG. The separately classified DDEML.LIB has an original implib recipe; prior `guest-library-role-review.csv` records OMF framing but does not prove that the checked-in library was generated from that recipe. Original tests under ddeml/tests remain pending: their exact test owner/target and source role are not inferred from the product makefile.

WIN87EM combines explicit EMASM dependencies and actual `emulator.asm` includes with its MASM object and DLL link. `emfprem`/`emfsqrt` require !SMALL_EMULATOR; `emthread` is under MTHREAD and traced to the separate EMMT.LIB target, not default WIN87EM.DLL. `emu8087`/`emoem` correspond to historical DOS 87.LIB, `wfpinit` and `win87em.def` to the Windows import library, and `emoemwin` to the DLL. Original build flags/variants are recorded rather than assuming every file enters every image.

REGEDIT distinguishes normal REGEDT16 from the explicit REGLOAD variant and USA resource build. SHERLOCK's cited sources and DEF belong to historical DRWATSON.EXE. CTL3DV2 files, generated images and symbols, ancillary docs, unverified original source variants and test files remain pending; the absence of a direct link in this review is not a functionality exclusion. All candidates are file roles, not proof of current image derivation or guest functionality. No source, guest, existing ledger or other artifact was modified; no execution/build was done.
