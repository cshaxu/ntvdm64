# WOW16 guest extension owner review — shard 1

`guest-extension-owner-review.csv` is the exact disjoint list of 55 currently pending paths in this shard under `wow16/inc`, `commdlg`, `shell`, `toolhelp`, `ole` and `ole2`. It preserves frozen and actual current hashes, both frozen original edition hashes and independently read actual original hashes, selected original source/link/include/resource edge and condition. There were no pending `ole2` paths in this shard. Twenty-nine rows have candidate historical guest-build-source-file-only roles; 26 remain pending. No row is classified solely because its filename occurs near a makefile or because it is missing from a host graph.

Original linked guest source owners are COMMDLG (`start`, `commdlg`, `parse`, `font`, `dlgs` with CL16/MASM/link16), SHELL (`shell`, `dragdrop`), TOOLHELP (its explicit OBJS response and link16), OLECLI (LE_OBJ/PICT_OBJ, CL16 and historical linker), and OLESVR (SRVR_OBJ and CL16 inference/link16). Guest declarations require a literal include from one of these selected linked translation units; actual local-vs-shared include resolution is checked. Resource candidates name actual RC lines or target recipe: the USA FindText source requires default !LANG; PRNSETUP root copy has the same bytes as default USA and make may overwrite it with selected localized source. Exact observed `common.ver` chain is commdlg.rcv:24 and commdlg.res dependency. TOOLHELP's original RC16 applies toolhelp.rcv directly after link.

Pending rows include ambiguous same-name headers, unproven bitmap references and prebuilt RES images. They need actual include path/condition, resource consumer, or produced/packaged image ownership; matching a basename is not sufficient. The supplemental provenance inventory was checked; no third-source-only row was promoted in this group. Do not infer an installed guest image was built from any exact historic source, do not infer observable guest behavior, and do not eliminate host implementation obligations on that basis. Main ledger, other shards, product and guest were not changed; no runtime or build was run.
