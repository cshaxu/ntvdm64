Two original DEBUG configuration variants and three historical WRITE
build/input files are reconciled as file roles only. Four current host build
graphs and dependency logs do not name these inputs. This does not remove or
prove DEBUG or WRITE capabilities, or prove either DEBUG variant was used.

The source-tree WRITE executables do not match the archive and installed
WRITE.EXE; both retained identities remain pending rather than being treated
as the deployed executable. DOS message skeletons remain pending. Guest image
provenance and actual feature, error and lifecycle behavior remain open.
No product or guest image was built, executed or modified.
