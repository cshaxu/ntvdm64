# S12: unselected platform alternatives

Under the same observed build conditions documented in `s12-platforms.md`,
ten SFELLOW or Macintosh alternatives to selected non-platform branches were
replaced with markers; the original conditionals remain. The companion JSONL
records their original hashes and locations.

Independent reconstruction from `590d11b1d` verified all ten body hashes and
all eight resulting files. Cached x86/x64 product builds and documentation
governance passed. All ten product images matched the previous release exactly
or differed only by four PE linker timestamp bytes. No runtime tests or
republication were repeated for equivalent images.
