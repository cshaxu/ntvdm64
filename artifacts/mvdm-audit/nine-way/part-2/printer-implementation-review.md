# Part 2: 488 external printer implementation and support files

The companion CSV covers each of the 488 owned external keys outside `rasprint/mini/` and `psprint/ppd/` (including the two independently discussed in `fax-boundary-review.md`). It records exact path/edition, verified frozen Git blob, raw SHA-256, size, file-type role, same-directory source/RC/INF/DEF/makefile filename references with line and text, and captured archive basename observation. These keys span distinct PSCRIPT, PSUI, RASDD, RASDDUI and printer support/font code; they are not one subsystem or one relevance decision.

Of these 488, 106 have a literal same-directory recipe/resource reference in the inspected files; zero have matching basenames in `assets/winnt.zip`. Neither count proves that a particular source was linked, installed, or invoked. Lack of a same-directory reference leaves cross-directory includes, generated rules and other configurations unsearched. The archive may contain linked resources or use system drivers rather than loose source files. The related WOWFAX/host print seam must be established before deciding whether any given separate driver implementation should be reused, adapted or left outside the project.
