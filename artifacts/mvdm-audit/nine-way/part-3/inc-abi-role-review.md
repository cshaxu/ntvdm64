# Part 3 shared MVDM ABI include inventory

`inc-abi-observations.json` enumerates each of the 59 owned `inc/` keys, SHA-256 across the current and two original trees, and individual textual include candidate sites under `src/mvdm`. Reproduce with `python artifacts/mvdm-audit/nine-way/part-3/inc-abi-observer.py`. Each observed current file equals every original edition where that named file is present. `vdmtb.inc` and `VDMTIB.INC` are absent in the OpenNT comparison tree and match OpenNT-4.5; `VDMTIB.INC.old` matches OpenNT and is absent in OpenNT-4.5. Missing comparison files are not differences in the current content.

The entries cover distinct interfaces, not a single disposable header set. In particular `BOP.INC`, `CMDSVC.INC`, `DOSSVC.INC`, `DPMI.INC`, `RDRSVC.INC`, and `XMSSVC.INC` are referenced from original guest service/dispatcher inputs; `TDB16.INC`/`tdb16.h`, `VINT.INC`/`vint.h`, and `WOW*.INC`/`wow*.h` describe task, interrupt and WOW call interfaces. For example `dpmi/dxfunc.asm` includes `DPMI.INC` and `BOP.INC`, `dos/command` includes `CMDSVC.INC`, and `wow32/precomp.h` includes `tdb16.h` and `doswow.h`. The multimedia subset has additional provider-specific analysis in `multimedia-abi-role-review.md`.

Disposition recommendation for every enumerated key: preserve its original ABI/source role until its exact producer/consumer configuration is checked; do not infer runtime coverage from a textual include. Includes are filename-matched candidates and can resolve another same-named file, disabled conditional branches or historical build configurations; the report does not resolve compiler include search order. The lack of a textual include in `enumapis.h`, `wowexp.h`, `wowint.h`, `x86def.h`, or `VDMTIB.INC.old` is not proof of non-use. `.old` is a historical comparison input with no observed direct include, not an automatically selected runtime object. No compilation, guest rebuild, deployed binary comparison, ABI layout verification, or runtime tests were performed for these records. Numeric restoration and behavior classifications remain pending where no stronger prior evidence exists.
