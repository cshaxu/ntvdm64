# S10 nine-way part 3: IEU/VDD debugger extension family

Owned MVDM keys only: 15 `ieuvddex/*` records in `ieuvddex-observations.json` (generated by `ieuvddex-observer.py` from the frozen nine-way table). This is a read-only review; no debugger, guest or product execution. All dispositions are proposed; the coordinator alone updates shared ledgers.

Original `ieuvddex/sources` builds a separate debugger-extension DLL called `ntvdm` from data/help/pmode/procdep/system/trace and resource; `ntvdm.def` exports debugger commands. `i386/sources` adds five x86-specific modules, while `ppc/sources` selects a separate PPC help module. This DLL is not the NTVDM worker executable despite sharing the name. Inspected current worker/WOW Ninja graphs have no `ieuvddex` source. Do not infer debugger functionality is unnecessary or recovered merely from graph absence; required external tooling scope and any compatible caller remain undecided.

| Owned file | Concrete role and status |
|---|---|
| `data.c` | Stores supplied debugger APIs and mode state; extension-only state carrier. Pending debugger contract. |
| `help.c` | Exported help entry and debugger API initialization; calls `helpp`. Pending callable/tool identity. |
| `i386/helpp.c` | i386-specific command help, listed in i386/sources. Alternate processor-specific diagnostic input, runtime untested. |
| `i386/profile.c` | DPMI profiling commands read/write target symbols/flags through debugger memory API. Pending compatibility and cleanup. |
| `i386/reflect.c` | `Erp`/`Drp` reflection-control code reads/writes target state. Pending target-layout and write semantics. |
| `i386/regs.c` | `IntelRegistersp`/`PrintContext` diagnostic context readers. Pending current context compatibility. |
| `i386/vdmtib.c` | `VdmTibp`/`EventInfop` read target structures. Pending exact layout and symbol compatibility. |
| `ieuvddex.h` | Extension API declarations and target types shared by the extension. Pending ABI/layout review. |
| `ntvdm.def` | Exports extension entrypoints, not product worker exports. Historical extension build descriptor; no inferred debugger functionality. |
| `pmode.c` | `Selp` and descriptor formatting read target LDT via debugger service. Pending selector and private-state compatibility. |
| `ppc/helpp.c` | PPC help implementation is empty; `ppc/sources` selects it for the PPC extension profile. Alternate architecture file role only, not evidence x86 extension is absent. |
| `procdep.c` | Command dispatch and Read/WriteProcessMem selection between WinDbg-provided and process APIs. Pending caller identity and lifecycle. |
| `system.c` | `DumpICA` reads `ntvdm!VirtualIca` state; source symbol alone does not prove current runtime layout. Pending. |
| `trace.c` | Trace commands read DPMI trace symbols and can update control variables. Pending target-state/lifetime and explicit debugging use. |
| `vdmdll.rc` | Version resource for external extension DLL. Historical build input; exact compiled resource identity not proven. |
