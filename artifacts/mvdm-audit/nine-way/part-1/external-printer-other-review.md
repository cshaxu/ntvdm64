# Part 1 external: plotter, printer UI and other driver providers

Scope comprises 440 assigned OpenNT-4.5 external SRC keys under `ntgdi/printers/` outside the separately audited hprasdd and psprint groups. Per-key path, SHA-256, size, provisional role, exact normalized four-graph VALID deps and ZIP basename check are in `external-printer-other-evidence.json`; replay `PYTHONDONTWRITEBYTECODE=1 python -B artifacts/mvdm-audit/nine-way/part-1/external-printer-other-observer.py`. All paths exist: assigned membership is 177 msplot, 134 compstui, 70 cheetah, 34 ps50 and 25 printer-lib records. The observer groups 109 C code, 67 headers and 264 other build/resource/model-data candidates; these are extension-based provisional types, not proof of each feature or model. Each key stays `pending-specific-provider-semantics`.

The original msplot dirs enumerates tools, lib, plotter and plotui, while ps50 dirs selects lib/pscript/ui with optional test/PPD/font. Model-specific device control, printer forms, UI and font resources may be visible to a guest via the host provider. Product WOW32 owns Win16 conversion and calls real host WINSPOOL, HDC and common-dialog facilities; original device-provider internals are not automatically a project execution dependency. Existing `shard-1/external-printer-provider-review.md` and T468 Print-to-PDF witness are limited to named provider behavior and do not validate plotters, legacy printer configuration, compound UI or device-specific errors.

No exact external source path occurs in the four current VALID dep sets, and none of these basenames appears in the ZIP. This does not establish currently installed printer providers or whether a particular device/format is requested; no physical printer, device UI, callback, resource lifetime or guest execution was tested. For each key, connect the specific host provider and observable guest API/model before deciding whether an adaptation is required. Do not exclude the family merely by its path, import an entire old provider, or infer equivalence from a different PDF printer. No shared ledger, product, guest or build tree was changed.
