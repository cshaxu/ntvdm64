# Part 1 external: native NT display-driver source family

Scope is exactly 604 assigned OpenNT-4.5 SRC keys under `nt/private/ntos/w32/ntgdi/displays/`. `external-display-evidence.json` records each key, path, original SHA-256, size, extension, provisional file role and exact four-graph normalized VALID dependency/ZIP basename observations; replay `PYTHONDONTWRITEBYTECODE=1 python -B artifacts/mvdm-audit/nine-way/part-1/external-display-observer.py`. All original files exist. The bounded scan yields 391 C/ASM/S code files, 131 header/include files and 82 resource/build/data candidates, spread across TGA, VGA, MGA, S3, ATI, VGA256 and other model subtrees. These are per-file provisional types, not a finding that their runtime semantics are interchangeable or irrelevant. All retain `pending-specific-provider-semantics`.

The original `displays/vga/sources` calls its target `vga`, type `GDI_DRIVER`; other models have separate device-specific resources, accelerations and memory paths. This native NT display-provider family is distinct from SoftPC's guest Video7 adapter and embedded guest ROM. In the current source, `wow32/wgdi.c:106-124,3613-3647,3883-3963` translates selected guest GDI operations and calls host BitBlt/SetDIBitsToDevice/StretchDIBits; `mvdm_softpc_firmware.c:106-119` instead supplies the guest Video7 ROM. Actual host GPU/display driver selection is a modern Windows resource owner. A DOS VGA frame or Win16 GDI operation therefore cannot be attributed to an old NT VGA driver simply by a shared name.

Zero exact source paths were present in four current VALID dependency sets, and no corresponding basename was found in assets/winnt.zip. These are bounded source/package observations: they neither identify the current desktop display driver nor prove rendering, palette, raster, memory mapping, clipping, device reset or accelerated variants are compatible. Prior `shard-1/rom-cmos-family-review.md` binds embedded V7 ROM content in built/published/installed NTVDM, not its execution. For each key, first establish a concrete observable Win16 or frame operation and actual provider; preserve original thunk behavior and test relevant failure/lifetime before any disposition. Do not import all NT4 display drivers or exclude them wholesale by directory.

No guest, display provider, product or external code was executed, modified or installed; no shared ledger or build tree changed.
