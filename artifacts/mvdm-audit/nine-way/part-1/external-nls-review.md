The 308 assigned OpenNT `base/win32/winnls/` SRC keys are individually enumerated in `external-nls-evidence.json`. Each row retains source hash, four-graph exact VALID dependency result and ZIP basename observation from `external-remaining-evidence.json`, plus a bounded source-derived role and an explicit CODEPAGE number if a header was found. Replay `external-remaining-observer.py` first, then `PYTHONDONTWRITEBYTECODE=1 python -B artifacts/mvdm-audit/nine-way/part-1/external-nls-observer.py`. Of these, 83 declare a CODEPAGE (including 437, 850, 932 and 1252), 65 are font-support source/input candidates, 24 test-source/input candidates, and 136 other NLS code/build/data candidates. A missing header is not proof the file has no locale relevance. Every row remains `pending-specific-codepage-and-provider-semantics`.

Original `winnls/ansi.c` implements ANSI NLS functions; the 1252 text file explicitly supplies a CODEPAGE header and translation table. Current `wow_class_words_binding.c:482-484` uses WideCharToMultiByte(CP_ACP), `ntuser_rtl_compat.c:15-20` queries keyboard locale and may fall back to CP_ACP, while `mvdm_softpc_firmware.c:308-311` converts OEM-to-wide-to-ACP. Modern Windows owns the live NLS services, tables and configured codepages; project adapters still own exact input lengths, encoding choices, failure and guest buffer lifetime. This is a concrete dependency family, not grounds to import an entire old NLS implementation or discard its codepage-specific obligations.

Four current VALID dependency sets show no exact external source path; ZIP basename matches were not found in the upstream census. Neither observation measures process/thread locale, CP_ACP/CP_OEMCP, DBCS lead bytes, replacement behavior, locale change, a named table's live selection, font rasterization or guest-visible strings. `external-crt-review.md` separately records original C-locale versus non-C case mapping and does not claim runtime locale. Each codepage/font/source/test key requires a concrete consumer and version-aware behavior witness before disposition; preserve DBCS and non-ASCII as unverified.
