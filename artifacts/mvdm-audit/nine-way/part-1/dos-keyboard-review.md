# Part 1 MVDM: DOS guest keyboard layout family

The 26 assigned `dos/v86/dev/keyboard/*` keys are covered individually below. `dos-keyboard-evidence.json` contains each full source/reference SHA-256, original makefile matches (including comments), exact object-name link-list search, public declaration lines, ZIP matches and exact system32 hash; replay with `PYTHONDONTWRITEBYTECODE=1 python -B artifacts/mvdm-audit/nine-way/part-1/dos-keyboard-observer.py`. All 24 ASM files match both primary reference editions. Absence of an exact object name in this one `keyboard.lnk` is not proof language or layout functionality is absent, interchangeability with similarly named variants, or no other original build includes it; source names and `PUBLIC` lines do not prove a binary was built from them.

Original keyboard makefile and `keyboard.lnk` select specific layout objects such as KDFBR275, KDFIT141/142, KDFRU091, KDFPL1 and KDFUK166 and attach the resulting EXS to SYS via original rules. Existing shard-2 `keyboard-variant-link-review.md` and shard-3 `dos-keyboard-variants-role-review.md` compare several non-interchangeable symbol sets. No guest compilation or keyboard/locale behavior was tested.
