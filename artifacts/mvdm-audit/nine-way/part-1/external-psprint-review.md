# Part 1 external: PostScript printer-provider source family

Scope is exactly the 481 `OpenNT-4.5` external SRC keys under `nt/private/ntos/w32/ntgdi/printers/psprint/` assigned to part 1. `external-psprint-evidence.json` contains **each key**, path, exact original SHA-256, size, type, a parsed PPD ModelName where available, per-key exact normalized VALID dependency hits in four current host graphs, ZIP basename observation, and a provisional role. Replay `PYTHONDONTWRITEBYTECODE=1 python -B artifacts/mvdm-audit/nine-way/part-1/external-psprint-observer.py`. All 481 files exist; 437 are PPD files, 19 C files, 12 headers, one .inc and 12 extensionless build carriers. 415 PPDs yielded ModelName; the remaining 22 retain null and must not be assigned an invented printer identity. No exact paths appear in the four scanned VALID dep sets or by basename in assets/winnt.zip. This does not establish what installed host providers load, nor does it exclude legacy printer behavior.

Original `psprint/dirs` selects lib, pscript and psui subprojects, with optional font conversion; `lib/ppd.c` is the original PPD parsing interface and describes generated binary data. The per-key C/header/build-carrier roles are provider-side candidates, not proof these exact files are used by a chosen modern provider. The 437 PPDs are individual model-description candidates, identified separately by key/hash/model in the JSON, not interchangeable just because they reside in one directory. Each retains `pending-specific-provider-semantics`: establish whether its printer/model, private escape, forms, metrics or resource behavior is within the requested compatibility contract, and identify its actual provider before classifying it. A null model requires further inspection.

There is demonstrated indirect product relevance: original selected `wow32/wgdi.c:678-717` has legacy PSCRIPT driver-name compatibility handling, `wow32fax.c:900,931` uses WINSPOOL.DRV and AddPrinterDriver, and WOW32 printing thunks call the host spooler. Existing `shard-1/external-printer-provider-review.md` and T468 named Microsoft Print to PDF witnesses establish bounded printing paths, not every legacy model or external PPD. The host spooler/provider owns real printer devices and settings; an old provider source file must not be imported wholesale or automatically excluded solely because it is external.

No legacy provider, physical printer, model, PPD parser, guest, external source or product was executed, installed or changed. To resolve a key, bind a concrete guest API/request to a model/provider, compare the provider's relevant format/behavior, and test success, errors and lifecycle; otherwise retain it pending. No shared ledger or build tree modified.
