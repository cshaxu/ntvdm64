# Part 1 external: raster printer provider and HP 5Si source family

Scope consists of exactly 1,077 OpenNT-4.5 external SRC keys under `nt/private/ntos/w32/ntgdi/printers/hprasdd/` assigned to part 1. `external-hprasdd-evidence.json` records every key, exact original source hash, size, extension, provisional file role, four normalized current VALID dependency searches and ZIP basename observation; replay `PYTHONDONTWRITEBYTECODE=1 python -B artifacts/mvdm-audit/nine-way/part-1/external-hprasdd-observer.py`. All original files exist. They include 919 hp5si model subtree records, 67 rasdd, 41 rasddui, 36 lib, 13 inc and one top-level dirs record. Per-file type counts are 393 `.ifi`/`.pfm`/`.ctt` font/character table candidates, 100 C sources, 74 headers, and 510 other model-data/resources/build candidates. The type is a provisional observation, not a claim that every file's semantics or dependency is known. Each individual JSON row remains `pending-specific-provider-semantics`.

Original `hprasdd/dirs` selects lib, rasdd, rasddui and mini provider groups; `hp5si/dirs` names UI and GPC; `hp5si/gpc/code.c` registers OEM device lifecycle and configuration callbacks. Different model resources, downloadable fonts, metrics, devmode and callback code cannot be declared interchangeable or irrelevant solely from directory membership. All 1,077 exact source paths had zero matches in the four observed host VALID dependency sets and no identical ZIP basename. This does not show which modern Windows printer provider, driver package, font data or optional provider is installed, nor that any named printer will behave as the original. It also does not prove these exact files were used by a historical release.

The product has a real indirect boundary: `wow32fax.c:771` explicitly discusses RASDD x/y DPI behavior; selected WOW32 print thunks invoke host printing APIs. The existing `shard-1/external-printer-provider-review.md` and T468 Print-to-PDF witness support only their named paths. Real device state, registration and scheduling belong to the host provider; original Win16/WOW translations and their error/ownership boundaries remain in this project. A specific guest call/model/driver capability must be bound and tested before deciding whether any old behavior needs a small adaptation. Do not import the whole provider or categorically exclude the 1,077 rows.

No real printer, guest, provider binary or external code was executed, installed or modified. Further bounded evidence includes per-model capability and font format consumers, provider-selected path, callback/resource lifetime, error and cancellation. No shared ledger or build tree modified.
