This review examines two currently pending host C source paths, not all C-VID/SAS behavior. It compares source, cached worker selection and already retained fixture scope; no runtime test or product/guest/ledger change was performed.

Further audit should trace exact selector bindings and original behavior rather than choose an arbitrary same-name source.
