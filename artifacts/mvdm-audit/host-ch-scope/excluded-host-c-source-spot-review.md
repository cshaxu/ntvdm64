# Excluded host C source: independent scope and provider spot-check

The current four shard ledgers were joined by physical `relative_path`, retaining `excluded`/`整体排除` rows with `.c` suffix outside `wow16/` and `dos/v86/`. This produces 50 rows at this checkpoint: 36 nonempty current files, 12 missing mirror files and two zero-byte files. Fresh SHA-256 of all 36 nonempty files matches at least one original-edition hash recorded in `frozen-file-reconciliation.csv`, so none of those 36 violates the rule that a mirror-different file must be partial. This is an identity check, not proof that all 36 exclusions are functionally justified. Seven CPU30 monitor/scaffold paths were independently reviewed in `../cross-369/shard3-excluded-current-c-source-recheck.md`.
