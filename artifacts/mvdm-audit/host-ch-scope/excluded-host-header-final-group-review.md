# Remaining excluded host headers: production and original-profile reconciliation

This review covers the eleven non-generated host header roles that remained excluded after the PIG, EGA trace and HUNTER consistency corrections. It does not modify the shared ledger, product or guest and does not claim any execution or compatibility test.

| Original physical header(s) | Actual source relationship and selected-profile distinction | Recommendation |
| --- | --- | --- |
| `softpc.new/base/inc/swinmgre.h` | Declares original SoftWindows CPU segment/compiled-fragment interfaces including `ApiDisable`; original `base/bios/reset.c:1026-1029` calls that API under `SOFTWIN_API`. Original `bios.c:465-476` dispatches SoftWindows BOPs 9C–9E under `SOFTWIN_API`/`SWIN_HFX`. Current selected PROD NT profile does not enable this branch, and no actual `ApiDisable` provider was identified in the inspected trees. | **Reopen pending:** determine whether this original host capability belongs to the approved goal and resolve its provider/guest dependency closure. Do not import a separate SoftWindows product or change the guest; an alternate profile alone is not evidence of completion or irrelevance. |
| `softpc.new/base/inc/hg_stat.h` | Original `PC_S_INC` and counters target non-PROD GISP CPU statistics. The selected profile has PROD and searches of the inspected source did not find a consumer beyond the header itself. GISP and diagnostic profile applicability remain unresolved. | **Reopen pending as a profile-scope consistency item:** establish whether GISP diagnostic statistics are in scope and find an original consumer before choosing a final file role; do not infer active profiling. |
| `softpc.new/base/inc/swinhelp.h` | Historical SoftWindows HyperHelp context identifiers; no direct current host include was found. | Retain the bounded alternate host/resource role exclusion. Actual selected guest help and resource behavior remain separate. |
| `softpc.new/base/inc/unix_asy.h` | Unix async constants and handler declarations; a different original `host/inc/hostsync.h` has similar declarations and is included in cached `nt_lpt.obj`, but no matching async function call was found in `nt_lpt.c`. | Retain alternate Unix physical role only; selected Windows printer/COM I/O, cancellation, errors and handle retirement are not proven by similar declarations. |
| `softpc.new/base/inc/unix_loc.h` | Unix host/stat lookup declaration; similar `host_get_hostname_from_stat` declaration also appears in original `base/inc/lock.h`, which is a VALID dependency of `nt_rflop.obj`; no use of that exact function was found in `nt_rflop.c`. | Retain alternate Unix physical role only; actual selected media/file locking and teardown remain separate. |
| `softpc.new/base/inc/host_fio.h`, `unix_cnf.h` | Unix file macros and Unix configuration definitions; no exact include found in inspected selected sources. Original NT file/handle and config owners have independent traces. | Retain scoped alternate host exclusions; do not treat file operations, config input, errors or lifecycle as verified. |
| `softpc.new/base/inc/host_hun.h`, `host_cfg.h` | Respectively a plain-text rename marker and a guard-only header; their exact original/current identities and selected source relationships are independently recorded. | Retain physical no-implementation exclusions; Hunter and NT configuration functionality remain independent. |
| `softpc.new/host/inc/monsim32.h` | Original `host/inc/sim32.h` selects this header only under `MONITOR`; CPU40 selected product is governed by the non-MONITOR mapping route. | Retain monitor-profile physical exclusion under current source policy; guest mapping, flush, retirement and failure remain required. |
| `wow32/wgman.h` | Comment-only file, included by WOW precompiled header but with no declaration or macro. | Retain physical no-implementation exclusion; GDI thunk behavior remains independent. |

A similar HUNTER consistency decision is recorded separately in `hunter-provider-reopen-review.md`. No proposal above claims NTVDM currently fails; all need current-ledger and source identity review before integration.

Coordinator: hg_stat.h is reopened pending with the unresolved GISP diagnostic profile. swinmgre.h remains excluded as a SoftWindows-specific physical interface outside the current NTVDM/CPU40 product profile; the NT reset and BIOS paths still require their own behavior evidence. This does not establish SoftWindows API equivalence.
