# CCPU memory bit-index shared path

This is a source reconciliation for the S11 failure already documented in [the CCPU review](../ccpu-header-macro-review.md); no new product or guest execution was performed. The existing native/guest differential proves the BTC word-memory case with address size 32 and index `FFFF`, not every instruction or addressing mode.

`c_main.c` defines `FIX_BT_BUG`. Register-index BT uses `BT_OPSw`/`BT_OPSd` and the read path; BTS, BTR and BTC use the same operand macros through `TYPE0FAB` and the write path. Their common memory branch uses unsigned `ops[1].sng >> 3` to adjust the effective address. A negative 16-bit index is therefore treated as a positive displacement in the recorded counterexample. Register destinations instead mask the index to operand width. The `0F BA` immediate group uses ordinary `D_Ew`/`D_Ed` and its separate decoder path; its immediate encoding must not be silently changed to signed-register bit-string semantics.

The smallest candidate is to correct signed register-index displacement in the two shared memory branches while preserving segment limit, page permission, read/write and fault/commit ordering. Use defined integer operations for 16- and 32-bit signed interpretation; do not rely on implementation-defined signed shifts or overflow. `c_addr.c::address_add` already applies address-size wrapping. The [native x86 wrap oracle](ccpu-bit-address16-oracle-review.md) now confirms 16-bit effective-address wrapping for four BT word/dword memory accesses, supporting its consideration at this point; segment-limit ordering and the selected decoder still require independent verification. No source change or completed fix is claimed.

S11 acceptance must cover BT/BTS/BTR/BTC, 16/32-bit operand and address sizes, memory versus register destinations, register versus immediate index, positive/negative boundaries, read-only and cross-page behavior, and faults before mutation. Preserve the existing hardware and real-guest BTC differential as an independent baseline; the expanded group requires its own real object/decoder evidence.
