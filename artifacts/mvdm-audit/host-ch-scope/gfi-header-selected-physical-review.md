# GFI original header roles against selected provider

This read-only review covers the still-pending physical `softpc.new/base/inc/gfirflop.h` and `gfisflop.h` files. It separately identifies the original real-drive and remote-controller consumers, actual selected provider declarations and existing object tests. It does not change the shared ledger, product or guest, run a guest, or access any medium.

| Physical path | Original/current consumer and evidence | Supported classification |
| --- | --- | --- |
| `gfirflop.h` | Original header describes real-diskette declarations for a Sun-specific `sun3_wang.c` variant. Its seven prototypes include `_active`, `_valid`, `_change` plus attach/detach/init/term. Repository source search finds no exact include. Selected original `gfi.c:300,314,325` uses the former three through the different, actual `base/inc/gfi.h` declarations (`gfi.h:583-593`), and `nt_rflop.c:385,423,463` supplies the NT-specific functions. Captured VALID dependencies of `gfi.obj` and `nt_rflop.obj` do not list this physical header. Current/original header SHA `9E033D9D00AFA92AA71B157B043DF550F5BB1D62AED97AA8D77E29C46E3372EC`. | **Excluded candidate for this physical historical declaration in the observed NT product profile** if the ledger permits bounded scope. This is not an exclusion of real floppy read/write, attachment or lifecycle. S13 retains actual media and `nt_rflop` failure/retirement. If exclusion is global, retain pending. |
| `gfisflop.h` | Original serial remote-PC protocol declarations (including login/logout/FDC/DMA IDs and `/dev/ttya` default) are included by `gfi_ibm.c` and `gfi_sflp.c` only in `SLAVEPC`. Observed PROD objects compile without those bodies; their alternate transport differs from the selected NT real-media provider. Current/original SHA `43FC7ED066C97D1C0264E08B6BCB1B3A8445F000D5A2132DCC415EBF1B0C88C4`. | **Pending** until S13 determines whether the original remote serial/controller profile and guest-visible protocol are applicable.
