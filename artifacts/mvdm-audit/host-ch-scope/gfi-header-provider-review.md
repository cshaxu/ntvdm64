# Original GFI headers: host provider and alternate profile

This is a bounded review of three pending `softpc.new/base/inc/*.h` physical source roles; no shared ledger, product, guest or test was modified. Current source and `O:/repos.external/OpenNT/base/mvdm` source hash identically for each header and the selected `gfi_mpty.c` body. Recorded header SHA-256 values: `gfiempty.h` `2990b990982a7381bb75662cf11c2378b958a912d188b4544d88be93cf9e6d0d`; `gfisflop.h` `43fc7ed066c97d1c0264e08b6bcb1b3a8445f000d5a2132dcc415ebf1b0c88c4`; `gfirflop.h` `9e033d9d00afa92aa71b157b043df550f5bb1d62aed97aa8d77e29c46e3372ec`.

| Header | Original role and source/object boundary | Remaining decision |
| --- | --- | --- |
| `gfiempty.h` | Original declares `gfi_empty_*` as external. The matching original `gfi_mpty.c:64-78,117-138` instead declares/defines its active provider helpers `LOCAL` and installs their addresses into `gfi_function_table`; `gfi.c` uses exported `gfi_empty_active` via `gfi.h`. Repository source searches find no include of this exact header. Current VALID `gfi.obj` and `gfi_mpty.obj` Ninja dependency output does not list it. | Do not mistake this stale alternative declaration for the actual linked helper ABI. Per-file role can be scoped to unselected declaration after checking non-product consumers; selected empty-provider behavior and no-media errors remain separate. |
| `gfisflop.h` | Defines serial slave-PC RPC commands, statuses, FDC and DMA constants. Original `gfi_ibm.c` and `gfi_sflp.c` include it only within `SLAVEPC`; the current PROD selected object files contain no executable bodies. Their VALID dependency outputs do not list it. See `gfi-alternative-provider-review.md`. | Keep pending until scope of original remote-controller capability and its dependent external device/protocol is determined; do not infer it works from the header or objects. |
| `gfirflop.h` | Declares seven legacy real-floppy entry points. Selected `gfi.c` imports three through `gfi.h`; actual `nt_rflop.c` defines `host_gfi_rdiskette_active`, `_valid` and `_change`. Repository search finds the remaining attach/detach/init/term names only in this header. VALID dependencies for `gfi.obj` and `nt_rflop.obj` do not list this header. | A historical interface alone does not establish the seven implementations or media operation. Keep per-file scope under review; real-media read/write/format, hot-unplug, rollback and provider retirement remain separate S13 obligations. |

The existing `tests/mvdm-host/gfi_object_contract_fixture.c` uses actual `gfi.obj`/`gfi_mpty.obj` with recording seams, and covers empty slots and dispatch; it does not execute attached hardware. Historical no-media INT13 reset is not attached-media proof. See `../nine-way/part-4/gfi-real-floppy-provider-review.md` for the independently recorded map and bounded evidence. This review itself performs no new runtime test; the object/dependency view is the cached x86 configuration, not all possible host architectures.
