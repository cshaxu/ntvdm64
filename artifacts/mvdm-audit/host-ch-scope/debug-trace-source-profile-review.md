# SoftPC original debug and trace source profile

This bounded audit reviews four currently pending original `softpc.new/base/debug/*.c` physical roles against the cached x86 worker graph, `PROD` compiler setting, object symbols and map. It does not run the debugger, change source, classify a guest, or prove installed-binary behavior.

| Source | Selected original body/data and provider evidence | Recommended decision and missing boundary |
| --- | --- | --- |
| `trace.c` | Original defines `io_verbose` and `sub_io_verbose` initialized to zero outside the non-PROD blocks. Cached worker map attributes both data symbols to `original-softpc-base-trace:trace.obj`. Production source uses trace-control expressions, but many `NON_PROD` call sites are compiled out; map attribution does not establish their dynamic use. | **Partial:** the original data owner is incorporated. Original trace output, categories, live control, exceptional paths and lifecycle are not proved; link-visible state is not an active debugger test. |
| `btrace.c` | Original back-trace buffer, printing, file-writing and disassembly calls are under `#ifndef PROD`. Cached `btrace.obj` has no ordinary executable function section/symbol in this selected profile, although Ninja includes it in the archive. | **Pending** original diagnostic capability and profile scope. Object existence does not implement backtrace; preserve original source rather than counting the inactive profile as functioning. |
| `debuggng.c` | Original `mode_strings` debug display table is guarded by `!PROD` and `EGG`. Cached `debuggng.obj` has only metadata/directive sections, no executable or data provider in the selected profile. | **Pending** debug-profile relevance; neither source nor empty object proves original mode diagnostics. |
| `profile.c` | Original `PROFILE` branch owns event/timing/profiling behavior. Under current no-`PROFILE` branch it builds three empty functions (`EnableAllEOIs`, `DisableAllEOIs`, `ProcessProfBuffer`) in `profile.obj`; their symbols are not listed in the captured worker map. | **Pending** profiling provider/caller and requirement. A compiled no-op is not profiling; lack of a map line is not proof of all possible link extraction or alternate builds. |

`original-softpc-base-trace.lib` in the Ninja graph contains the objects, but archive membership is not runtime reachability. Related original YODA and CCPU debugging paths have separate owners and tests. Recheck source/current hashes, profile flags, object symbols and release identity before applying this recommendation to a later baseline.
