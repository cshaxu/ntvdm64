# Excluded host C roles: UI, video scaffolds and helper inputs

This independently checks additional nonempty excluded physical C roles from the 50-file host census in `excluded-host-c-source-spot-review.md`. It relies on source/recipe and existing selected-owner evidence; no runtime, guest, product or ledger change was made. The exclusion judgment applies to the physical role, not blanket feature completeness.

| Physical source | Original and current owner evidence | Remaining boundary |
| --- | --- | --- |
| `softpc.new/host/src/stf_conf.c` | Original generic `SoftPC.rez` configuration/UI provider; the NT source recipe instead selects original `config.c`. The existing `../retired-host-role-review.md` records common API owner and source/selection evidence. | Runtime NT configuration, PIF/environment, failures and retirement remain selected-owner obligations; the generic panel itself is not asserted equivalent. |
| `softpc.new/host/src/nt_smenu.c` | Historical `DosBox` modal settings/kill dialog, omitted from original NT recipe. Existing retired-host review checks the named dialog and its lack of selected source/resource references. | NTSRV/NTCON management and frontend/window lifecycle remain independent; absence of the old template does not prove user-visible controls all work. |
| `softpc.new/host/src/nt_hfx.c` | Original source describes HFX stubs and several file functions return zero or do nothing; the selected NT file/directory owner is DEM, documented in retired-host review. | Never promote stubbed success to file functionality. Original optional HFX profile and DOS/redirector file semantics, failures and handles remain separate. |
| `softpc.new/base/cpu/src/evid/ev_stubs.c`, `softpc.new/base/cvidc/ev_stubs.c` | Both original physical files define empty `setup_vga_globals` and a `setup_global_data_ptr` with no returned value. These empty placeholders cannot certify video setup. |
| `wow32/wgman.c` | The whole source consists of precompiled-header inclusion and `MODNAME`; there are no manually coded GDI thunk bodies in this physical source. | The other GDI thunks, metafile/palette/guest semantics and their existing test gaps remain separate. |
| `wow32/wctlm32.c` | The physical source begins with bare message `case` fragments without a surrounding function, and is absent from the current WOW32 graph; it is not an independently executable translation unit as stored. | Do not mark control message conversion complete or delete its real providers/guest functionality; trace those existing owner entries separately. |
| `softpc.new/base/dasm386/{build,dasm386,decode}.c` | Original `dasm386/sources` lists these under PPC/ALPHA/MIPS and has empty i386 source list; this identifies an alternate original disassembler profile. | Debugger and disassembly behavior are not proven by excluding this physical provider. |
| `softpc.new/convert/convert.c` | Original `convert/sources` defines a standalone PROGRAM target, not a worker library. | Any generated-output consumers need separate ownership and identity proof; no conversion behavior is inferred. |
| `ieuvddex/mips/helpp.c` | Original processor-specific help entry is empty and resides in a MIPS debugger extension path. | An empty MIPS help file is not proof of current debugger or other processor extension behavior. |
