# WOW32: three bounded physical-file decisions

These are proposed **physical file exclusions for the inspected original/current build profile**, with feature ownership retained. They are not authorization to remove source and not proof of unrelated profiles or full feature fidelity. A ledger that cannot express profile and feature boundaries must leave the rows pending instead of applying a misleading whole-product exclusion.

No actual behavior was newly tested; cached object identity is not a fresh source-bound release. No product, guest or shared ledger changed.
