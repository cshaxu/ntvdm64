## Feasible noninteractive integration witnesses

Use independently authored test-owned NE probes and the existing isolated runtime stage; do not alter or rebuild any supplied guest image. Extend a copy of the controls probe: create a multiline EDIT as a child with a unique nonzero control ID in its `hMenu` argument, then call USER ordinal 101 with parent, ID, old Win16 `0x041b`, count and 16:16 array. A second case obtains the native EDIT's saved procedure with `GetWindowLong(hwnd, GWL_WNDPROC)` ordinal 135 and passes that thunk and the EDIT hwnd to ordinal 122 with the same message and array. The existing button path demonstrates how to request the native procedure, but the EDIT test must assert the returned carrier is the native-proc route, not merely any guest procedure. Record each guest result, phase and error, separate stops/reset and preserve a real word-break callback identity before/after.

The existing [snapshot runner](../shard-2/tabstop-snapshot-run.ps1) creates a fresh isolated stage and checks staged module path and process identity, uses gates and ReadProcessMemory before/after, records hashes and cleans its own stage. Its hard-coded base DLL/map identity and RVA are deliberate guards: for a candidate build derive its own `W32WordBreakProc` RVA from that exact map, validate staged image and section identity, and record both; do not bypass the guard or reuse a stale offset. It accepts a supplied probe binary and output directory but its fixed gates/phase interpretation must be adapted for each distinct route. Such owned fixture binaries are new test inputs; original KRNL386/USER16 and other supplied guest binaries remain byte-identical.

Snapshots provide process state, not entry proof. For reliable **entry-specific** acceptance, pair them with a controlled exact-object route fixture or non-invasive entry tracing that binds actual target function and invocation order, since USER16 could short-circuit or call another thunk. Verify native success/failure, heap/stack conversion, rollback, legitimate word-break state and task cleanup using the finite [repair matrix](wow-edit-tabstop-repair-design.md). No new guest run or product change was performed in this review.
