# WOW32 bounded excluded-file candidates

These are **physical-role candidates for the observed x86 release only**, not source deletion or functional acceptance. They require coordinator confirmation against the current ledger and a fresh source-bound build; no unobserved configuration, external binary or generated caller is ruled out. They all retain their original source files.

| Candidate | No observed active consumer / independent owner | Evidence and remaining feature obligation |
| --- | --- | --- |
| `wow32/wowdde.h` | Duplicate DDE structures; no include found; selected `wdde.h`/`wdde.c` own classic DDE conversion. | [Bounded DDE header report](../cross-369/dde-header-disposition.md): real classic DDE witness is bounded. S14 still needs cross-task, callback, peer loss and cleanup, and DDEML is a separate route. |
| `wow32/wowtable.h` | No exact observed include; `wowtbl.h` carries the selected `aw32WOW` declaration and `wowtbl.c` its table. | [Table recheck](wow-three-table-structure-recheck.md); preserve dispatch ordering, all ordinals, DEBUG/profile semantics and alternate consumers. |
| `wow32/winspldl.h` | Old individual spooler pointer declarations have no observed host consumer; selected `wspool.h`/`wgprnset.c` provide `spoolerapis`. | [Spool owner](wow-witbl-winspldl-roles-review.md); S16 must test real printing, failure and resource lifecycle. |
| `wow32/wkglobal.h` | Its old host Global thunk provider is not selected; selected original `wktbl2.h` marks common operations `LOCALAPI`, retaining guest ownership. | [Global declaration review](wow-wcurcash-wkglobal-roles-review.md); still verify immutable guest Global allocation, failure, lock and retirement. |
| `wow32/wklocal.h` | Header is included through precomp but its old `WK32Local*` provider is not selected; `wktbl2.h` selects guest local operations and `wcall16`/`wcall32`/`walloc16` separately supply cross-boundary/heap behavior. | [Local memory owner](../cross-369/local-memory-header-disposition.md); retain S14/S15 local heap mapping, allocation failures, nested callbacks and retirement. |

Do **not** yet put `wcurcash.c/.h`, `wctlm32.h`, old DDEML provider/table or `wmmalias.c/.h`, `wmmedia2.c`, `wmmstru2.c`, `wmmstruc.h` in this safe set: their distinct cache, reverse-conversion, guest DDEML or multimedia provider semantics and real reachability have not been fully reconciled with the selected alternative, despite their observed nonselection or disabled bodies. `witbl.h` also remains pending until its particular internal-table replacement/consumers are explicitly bounded. This is conservative physical classification, not a proposal to add duplicate engines or suppress features. See [33-file ownership table](wow-fax-redir-debug-pending-owner-table.md) and [three multimedia recheck](wow-three-table-structure-recheck.md).
