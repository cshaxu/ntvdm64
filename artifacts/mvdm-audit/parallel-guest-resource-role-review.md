# Guest build input file roles

Seven exact original file roles are reconciled using the independently
replayed OLE client, REGEDIT and driver resource observations. The per-file
edges and preserved boundaries are listed in the companion dispositions CSV.
These are historical guest build inputs, a build script or a commented
template; this file-role exclusion is not an exclusion of OLE, registry,
display or keyboard capabilities. No guest image was built or modified.

`sdkreged.def`, `REGEDT16.EXE` and `config.LST` remain pending because their
consumer or provenance was not established. Packaged-image identity does not
prove source-to-binary provenance or live guest behavior. Runtime, failure and
lifecycle acceptance remains in the recovery stages.
