The [observer](sinit012-image-observer.py) and its
[result](sinit012-image-observations.json) verify the current file and both
original edition bytes, one DOS and two WOW catalog IDs, original selected
object and valid Ninja dependency, archive membership, and 33 mapped function
bodies against the current released NTVDM image. COFF relocation words are
masked: matching is not a proof of their call targets. Original source text
retention is 100%; a restored behavior percentage is not measurable here.

setter wrappers for video globals. `setup_vga_globals` invokes the project
binding before initializing VGA global and trace-ring state; the binding copies
`C_Video` into `Video`. The current graph has project accessor adaptations and
the existing object fixture tests selected accessors; however, this observation
does not prove each SINIT012 body is reached through a real VGA workload or
that every table slot retains its initial value after runtime publication.

initialization, the shared generated scratch/register behavior under nested
