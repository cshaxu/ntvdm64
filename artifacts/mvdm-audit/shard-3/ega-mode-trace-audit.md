# EGA mode selection and diagnostic trace review

Scope: shard-3 `softpc.new/base/video/ega_mode.c` and `ega_trcr.c`, frozen byte-identical OpenNT; source/previous evidence only, no new execution or product/guest edits.

The original `ega_mode.c` is compiled with the C-VID rule; the current NTVDM product map contains `_ega_mode_init`, `_choose_ega_display_mode` and `_choose_mode` from `original-softpc-video:ega_mode.obj`. Original `ega_prts.c` initializes EGA mode and calls the chooser when display state changes; `vga_prts.c` also calls `ega_mode_init`. The chooser derives effective line offset, wrap and split-screen state, selects a table entry, sets screen pointers and asks the host paint routine to change; it requests a full refresh. Under NTVDM, however, its `set_update_routine` switch body is compiled out (`#ifndef NTVDM`), so do not infer from comments that it installs those original non-NTVDM update callbacks. Actual VGA-path provider selection must be traced separately through `vga_mode.c` and its selected profile.

`ega_trcr.c` is an EGA access trace/dump provider, not a display timing-register implementation: it writes port and memory access records to a file and can replace video write handlers while tracing. The entire body is guarded by both `!NTVDM || !X86GFX` and `EGA_DUMP`. Its selected `cc_cvidc_rule` explicitly has NTVDM and X86GFX and does not define EGA_DUMP; thus this particular object has no active dump body in this profile, despite appearing in the Ninja graph/archive. Tracer consumers in `ios.c`, `gvi.c`, and debug code are themselves EGA_DUMP-gated. This is a profile-specific inactive tracing facility, not evidence that video mode or rendering is absent. It remains pending until the T-wide authority explicitly disposes historical diagnostic capability and non-selected profiles.

Historical T420 S23 exercised mode-3 guest text direct VRAM and mode-13 graphics VRAM read/write followed by mode-3 recovery; its then-current console boundary did not assert graphics presentation. These results belong to their historical package and `vga_mode.c` path, and do not separately prove `choose_ega_display_mode`, nonstandard wrap/split modes, mode reset timing or current package. T473 device and caret evidence must likewise not be substituted for this chooser. Verify a controlled actual-source table/paint boundary and mode reset with a current isolated package before claiming those cases. Both rows remain pending; no unsupported defect is asserted.
