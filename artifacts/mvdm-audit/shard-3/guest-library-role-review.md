# Historical Win16 OMF import/static libraries — shard 3

`guest-library-role-review.csv` contains the eight pending library rows. Every file has a full SHA match to its frozen row, an OMF LIBHDR 0xF0 with 16-byte header and in-bounds dictionary offset/block span, plus a named original 16-bit build production or use edge. `wow16/lib/makefile` invokes `implib` for kernel, system and user against their guest DEFs and constructs libw from import libraries; it also invokes implib for sound. `commdlg/makefile` produces its local commdlg.lib through implib; WRITE's real link response names mlibcew, olecli and commdlg libraries; the HELLO test recipe names slibcew. Exact referenced lines and formats are retained per row.

These are candidate historical guest-link carrier roles only. A header and bounded dictionary check is not a complete member parser, source-to-current-binary proof, functional pass, nor permission to consume old binary libraries in host builds. Producer/consumer lines do not prove the frozen artifact is the one that a particular historical build used. No product or guest changed, built or executed; original immutable runtime binaries and user capabilities stay separately audited.
