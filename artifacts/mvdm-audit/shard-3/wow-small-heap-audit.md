# WOW small-heap ownership and bounded behavior

`wow32/wheap.c` and `wheap.h` are byte-identical to the pinned original. Current `wow32.dll.map` shows CreateSmallHeap, malloc_w_small and free_w_small attributed to `wheap.obj` (lines 1226–1228); header inclusion alone does not prove behavior. The original `wow32.c` creates the small heap before its general heap on DLL process attach. Its consumers include accelerator aliases (`waccel.c`), cursor/icon aliases (`wcuricon.c`), DC cache (`wreldc.c`), with original accelerator task cleanup reached from `wkman.c:1540`. The Win32 heap owns its memory; each alias list owns publication and the corresponding element's cleanup. Small heap uses `HEAP_NO_SERIALIZE`; external scheduling/locking guarantees must be proven at actual call sites, not inferred from allocator source.

Independent `wow-small-heap-probe.c` SHA-256 `802217ED969A0086A4F5FF2736C3B09B63B4FFCBA48E507809EC8636F1083020` linked actual current x86 `wheap.obj` SHA-256 `9DB934418EEB86C0D2D41CED1A9FDE27A6B921C35B495D0010F47D98BD1A4A94`, using the object's actual x86 __stdcall decoration. Built with `/MT /W4 /WX` through the existing x86 wrapper. Single-threaded creation, one-byte and 8192-byte allocations, HeapValidate, both frees and final test-owned HeapDestroy passed (`WHEAP production object allocation/free/growth pass=1`, exit 0). The initial __fastcall harness declaration was corrected after the linker proved the selected object's symbols are `_...@N`; that failed build is not counted.

Actual `wow32.c` process-detach destroys `hWOWHeap` but not `hWOWHeapSmall`; the pinned original has the same shape. OS process termination releases process memory, but explicit DLL unload/reload and attach failure after small-heap creation are not proven by this allocator microtest. The fixture itself destroys only its own heap, not evidence of production teardown. No guest/task alias lifecycle, allocator failure injection or concurrent use was tested. `wheap.c` and `wheap.h` remain pending, without asserting a product leak from static evidence alone.
