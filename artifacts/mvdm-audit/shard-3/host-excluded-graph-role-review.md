Captured results are in `host-excluded-graph-observations.json`. No product, guest, shared ledger or build state was changed. The retained command snapshot and present objects/map are individually identified; this recheck does not assert they all belong to the newest published package.

All three sources match both originals. The retained compile commands include each source with NTVDM, CPU_40_STYLE, CCPU, C_VID, SPC386 and PROD; they do not explicitly define HOST_SAS, SUN_VA, X86GFX or YODA.
