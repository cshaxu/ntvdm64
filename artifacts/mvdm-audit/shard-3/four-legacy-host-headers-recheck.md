# Four legacy host header roles

Static, exact-path recheck of the captured x86 CPU40 NTVDM profile; no new runtime test. All recommendations below are **physical file roles in this profile**, not claims of complete behavior equivalence or authority to remove the source files.

| File | Exact consumer and present owner | Decision / preserved obligation |
|---|---|---|
| `host/inc/hosttyps.h` | Its only operative content includes `<sys/types.h>`. Bounded source search found no exact include and captured worker dependencies do not identify this path. Active providers use their actual configured system/type headers. | Exclude this wrapper as a physical input to the captured worker. Preserve S11 ABI and type-layout verification; same system-header name does not prove all historical platform types equivalent. |
| `host/inc/hostgrph.h` | Declares legacy `pcwindow`, `terminal_type`, terminal and attribute constants. Selected `base/video/gfx_updt.c` includes `host/inc/host_gfx.h`, defines/uses `terminal_type`; this distinct selected header declares it and matching terminal constants. The captured dependency lists `host_gfx.h`, not `hostgrph.h`. | Exclude this physical header in captured profile. Only overlapping terminal declarations are demonstrated, not all old `pcwindow` or terminal behavior; selected rendering and other profile semantics remain S13 work. |
| `host/inc/nt_smenu.h` | Included by original `host/src/nt_smenu.c` for its `DosBox` settings dialog. Original NT host `sources` and captured worker graph omit that C file. `../retired-host-role-review.md` and `../nine-way/part-1/retired-host-exclusion-recheck.md` separately check original recipe, resource and callers. Other NT UI has different IDs; no byte-for-byte equivalence is claimed. | Exclude this physical header with its unselected old dialog role in the captured profile. NTSRV/NTCON management, user-visible controls and any requirement for the old dialog remain separately assessed; not proven by absence. |
| `base/inc/host_uis.h` | Declares X `XtAppContext`/`Widget`/`XmString` and UI functions. No exact consumer/dependency found in the bounded NT worker search; the captured worker includes distinct `host/inc/nt_uis.h`. The latter is a Windows host UI interface, not proof of semantic equivalence to every X dialog. See `../host-ch-scope/terminal-x-host-provider-review.md`. | Exclude this physical X-profile header from captured NT worker; preserve independent visible dialog semantics and alternate X-profile applicability for S17. |

These are bounded exclusions, not proof that every original UI/video feature is satisfied. No shared ledger, product or guest was modified.
