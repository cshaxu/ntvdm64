## Decoder-to-object confirmation and finite guest witness (CLC/CMC/CLD)

For the selected original x86 CCPU `c_main.c`, opcode F5 directly calls CMC at line 4105; F8 calls CLC at line 4261; FC calls CLD at line 4292. This is not merely an inline implementation that happens to share a name. Cached selected `c_main.obj` SHA256 `6FF59175D530E65B489B2C1BACB93B7C5AC459E049FE75B28EC0372AFA1C5986` has actual REL32 relocations `_CMC` at 0xB897, `_CLC` at 0xC570, `_CLD` at 0xC5A7; current NTVDM map attributes those symbols to the respective original instruction objects. This proves selected compiled call linkage, not execution of every opcode in a guest or even the branch's dynamic reachability.

Each complete source-level contract is small: CLC writes CF=0, CMC writes logical inverse of canonical CF, CLD writes DF=0; all other CCPU flag slots are untouched. The direct original-object differential above compares both starting binary values to native and checks unrelated fixture-owned slots. It does not exercise `PUSHF/POPF`, CPU dispatch or full guest flag materialization.

Minimum useful additional witness: one independent new DOS guest executed through a hash-pinned current package, with F8/F5/FC actually present in guest instruction stream, test both initial CF inputs for CLC and CMC, and both initial DF inputs for CLD; use PUSHF/POP and masks to check the affected bit and a controlled set of unaffected defined status bits. Capture flags immediately, then issue CLD before any DOS call even on failure. Report a distinct result per case and require marker plus clean guest exit. Verify actual loaded worker/object build identity, and inspect decoded bytes so the test does not substitute compiler/helper emulation. Together with source identity, relocation and direct-object test this can support full file-scope classification for canonical single-thread register semantics; it still does not prove concurrent interrupt timing, unusual noncanonical internal flags, other CPU profiles or platform behavior. No new guest or product modification/run was made by this shard.
