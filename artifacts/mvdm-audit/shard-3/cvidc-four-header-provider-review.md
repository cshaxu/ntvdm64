# Four C-VID generated headers: exact-path evidence

Static verification only; no tests were run. These are four separate files in `base/cvidc`, not their same-named `base/inc` or `host/inc/mips/prod` copies. All four match `O:/repos.external/OpenNT/base/mvdm/softpc.new/base/cvidc` byte-for-byte. The recorded x86 worker dependency snapshot and a fresh `ninja -C build/.ninja/msvc-x86-release/worker -t deps` search did not show these four exact names; a repository source search found no direct include spelling. This does **not** disprove generated, alternate-profile or assembly use and does not justify claiming these particular paths are selected. It is also not evidence that their associated CPU/VGA behavior is missing.
