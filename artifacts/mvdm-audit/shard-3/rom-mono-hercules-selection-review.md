# ROM map, monochrome and Hercules declarations

Static review of the captured x86 worker profile; no device/guest test was run. `rommap.h`, `mda.h`, and `herc.h` are byte-identical to their counterparts under `O:/repos.external/OpenNT/base/mvdm/softpc.new/base/inc`. See also `../host-ch-scope/disk-geometry-rommap-provider-review.md` and `../host-ch-scope/display-profile-interface-review.md`; the latter correctly keeps original adapter applicability separate from current VGA support.

| Header | Original behavior and current selection | Bounded disposition / remaining evidence |
|---|---|---|
| `rommap.h` | Defines the full-screen host ROM map and initial IVT representation. Exact type names occur only in the header in current and compared SoftPC source; no matching captured dependency. | Header is not selected in the captured profile. Keep the original full-screen mapping capability pending until its provider and applicability are established; current ROM boot/firmware code does not by itself prove equivalence. |
| `mda.h` | Declares a dedicated monochrome adapter's initialization, teardown and port I/O. `gvi.c` references `mda_init/term` only under `DUMB_TERMINAL`; its `case MDA` in `gvi_set_mode` outside that gate sets geometry/selection and is **not** proof of a complete MDA device. No implementation file was found by name in this tree. | Dedicated MDA provider remains unselected/unverified for this profile; do not claim VGA monochrome text equals its port semantics. Determine original provider and whether the current project must support this configuration before closing the capability. |
| `herc.h` | Declares Hercules adapter and scanline size. `gvi.c` includes it and dispatches init/term only under `HERC`; Hercules update code in `gfx_updt.c` is similarly gated. Captured x86 commands lack `HERC`; `nm` of `worker/obj/video/gvi.obj` shows unresolved `cga_init` and `vga_init`, not `herc_init` or `mda_init`. | Dedicated Hercules path is not shown selected. Preserve its capability as pending until original provider, supported scope and Hercules graphics/ports are established; VGA output and successful monochrome text do not constitute that proof. |
