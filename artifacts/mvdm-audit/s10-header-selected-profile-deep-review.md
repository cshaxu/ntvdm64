# S10: bounded physical header decisions for the selected x86 worker

This follow-up independently checked the current files and the captured `build/.ninja/msvc-x86-release/worker` graph. It is an audit of exact `softpc.new/base/inc` header paths, not a proposal to delete files or exclude their guest-visible capabilities. The 61-file initial inventory, original byte comparisons and all remaining per-file findings are in [s10-followup-headers](s10-followup-headers.md). Original source was unchanged; mirror diff attributable to this review is zero. No runtime test was performed.

On 2026-10-28, Ninja 1.13.2 `-t commands obj/video/gvi.obj` showed `WINNT`, `NTVDM`, `CPU_40_STYLE`, `CCPU`, `C_VID`, `SPC386`, `V7VGA` and `PROD`. The command did not supply `HERC`, `DUMB_TERMINAL`, `SLAVEPC` or `MOUSE_16_BIT`; command-line absence by itself does not rule out definitions in headers. The records below use the existing valid dependency and source gate evidence as well. This observation does not cover other configurations, generated inputs outside this graph or original DOS guest code.
