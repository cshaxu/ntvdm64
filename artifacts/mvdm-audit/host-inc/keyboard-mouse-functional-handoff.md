# Alternate input headers and actual keyboard/mouse owners

This handoff complements `keyboard-mouse-alternate-header-review.md`; no original guest or runtime source was changed. Four pending C headers belong to distinct historical profiles: `keycaps.h` is UIF_TEST keycap text, `m_keybdp.h` is an X-host keysym matrix, `kybdmtx.h` declares an older keyboard-matrix interface, and `mouse16b.h` is the MOUSE_16_BIT interface. The captured CPU40/NTVDM graph does not establish these alternate interfaces as active; do not add an X mapping or synthetic success provider to claim restoration. Their precise profile support and consumer dispositions remain open.

The selected path is different: original `nt_reset.c` chooses NT keyboard host functions; original `keyba.c` handles keyboard data/queue and registers port and PIC EOI behavior. `mouse_io.c` owns the original INT33 and video BOP entrypoints, and `bios.c` registers mouse BOP slots BD/BE; project host input/presentation code carries actual host events, not a second guest mouse behavior engine. User-observed V7VGA mouse behavior and older Win3.x results are independent package-specific evidence, not proof all INT33 states or modes work.
