# DDEML and WFWNET historical inputs

The companion dispositions reconcile six original DDEML import/test inputs,
five WFWNET guest build inputs, and one DOS editor-state file. The original
recipes and included files are recorded in the associated observations; four
current host build graphs and dependency logs do not name these exact inputs.
These exclusions apply only to file roles, not DDE, network, printing,
localization or their failures and callbacks.

The WFWNET source tree, archive and installed driver match, but that identity
does not prove which source built it or that guest applications loaded it.
The exact DDEML archive and installed paths checked were absent; other media
or paths were not ruled out. The alternate-language catalogs remain pending.
No guest or product image was modified, built or run.
