# Two original COUNTRY.SYS data sets

The [observer](country-bin86-identity-observer.py) and [receipt](country-bin86-identity-observations.json) compare the retained OpenNT-4.5 `bin86/country.sys` with the source-tree `dos/v86/dev/country/COUNTRY.SYS`, ZIP member and installed System32 copy. The first is 17,069 bytes and matches its OpenNT-4.5 reference; the latter three are identical at 27,097 bytes and match the separately recorded original COUNTRY.EXE payload. The primary OpenNT `bin86` path was absent in the frozen inventory. The original `bin86/makefile` does not list COUNTRY.SYS, while the country-device makefile binplaces its separately built SYS.

Following the original `mkcntry.inc` header and 14-byte `CTRYSTR` layout, the retained file contains 60 entries and 60 distinct country/code-page pairs; the installed file contains 128 entries and 126 distinct pairs. They share 59 pairs. The retained index alone contains `(82, 934)`; the installed index alone contains 67 pairs. Installed `(61, 437)` and `(61, 850)` each occur twice. The complete indices and offsets are retained in the receipt. The observer checks signatures, entry size and in-file data offsets; it does not compare the actual country data payloads or interpret duplicate-entry selection.

This is a concrete original data-version difference, not proof of a user-visible failure or an instruction to replace installed data. Verify actual DOS country/NLSFUNC loading, pair selection and error behavior, including the retained-only combination and duplicates, against applicable immutable guest media. The `bin86` file remains pending until its profile and required semantics are determined. No guest, configuration, installed file or product was modified.
