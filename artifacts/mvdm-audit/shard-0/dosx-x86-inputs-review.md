# DOSX x86 historical guest-build input cohort

The [observer](dosx-x86-inputs-observer.py) and [receipt](dosx-x86-inputs-observations.json) check 12 original files, both source editions and the historical x86 DOSX makefile/response file. Nine assembler inputs have actual `ASM486` commands and matching `dosxi.lnk` object entries: `486/dxfunc.asm`, `486/dxint31.asm`, `486/dxmain.asm`, `486/dxstrt.asm`, `dxdma.asm`, `dxemm.asm`, `dxemm2.asm`, `dxfind.asm` and `dxmsg.asm`. `cmacros.inc`, `interupt.inc` and `pmdefs.inc` are named guest-build dependencies. The copied default USA message file matches the retained root `dxmsg.asm` bytes.

The `dxmain` rule names the root prerequisite but its assembly command explicitly selects `486/dxmain`; this distinction is preserved rather than inferred away. The ZIP, source-tree and installed DOSX.EXE bytes match, but that does not establish these inputs produced the image. The twelve are classified only as historical **guest build-file roles**, consistent with the earlier DOSX cohort; protected-mode transitions, interrupts, DMA, EMS, errors and lifecycle remain required S12 behavior. Alternate root sources and profiles not covered by this cohort stay pending. No guest or product was rebuilt or modified.
