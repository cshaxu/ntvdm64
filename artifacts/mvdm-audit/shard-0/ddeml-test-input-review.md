# Original DDEML test and sample input roles

Fourteen shard-0 files belong to the original DDESTRS stress application,
DDEML client/server samples or DDEMO sample. The [observer](ddeml-test-input-observer.py)
checks both original editions, frozen catalog identities, the original named
test/sample targets and source/header relationships, and the current worker
and WOW32 Ninja inputs. Their DOS build scripts are read as evidence only:
they contain deletion commands and were not executed. The selected host build
does not name these individual source inputs.

The proposed file-only exclusions are not deletion instructions and do not
exclude DDE/DDEML functionality, live Win16 application execution, callbacks,
conversation ownership or tests that may be needed later. They do not claim
the historical samples were built, delivered, or run. `ddesorg.ico` is left
pending because its exact consumer was not established. The [receipt](ddeml-test-input-observations.json)
records source and input hashes; all fourteen file bytes match both original
editions. No guest or product was modified.
