It is incorrect if the ledger uses `excluded` to mean “not built”, “not linked”, or “feature irrelevant”. If the shared ledger cannot express that distinction, change these rows to a status that can (for example partial) and retain the narrower facts below. This is a recommendation; this review did not change the shared ledger.

This is a release-build snapshot, not an assertion about every debug/profile configuration.
