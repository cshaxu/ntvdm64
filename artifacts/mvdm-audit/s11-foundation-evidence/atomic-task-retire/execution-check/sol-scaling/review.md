# Current candidate SOL window-count probe

The `atomic-execution-retire-package` ran the existing isolated SOL Options test with one baseline round, one round while 150 test-owned external windows existed, and one after their removal. All completed including parent recovery. Open times were 2641, 2031, 2078 ms; close/recovery 2297, 2219, 2157 ms respectively. See probe.txt. This single ordered run does not show an increase for this set of external windows; it does not establish that all windows were present in every captured guest graph, exclude effects for other window types or counts, resolve seconds-long latency, or demonstrate a specific code change improved performance. No Winmine was launched.

The first invocation requested one round and was rejected by the test harness before runtime staging because its external-window design requires three; it is a harness non-pass, not a product result.

A repeated run added a probe-side traversal of the native desktop child/next chain after creation. It found all 150 owned windows in a chain of 422 before round two. The three interactions passed; open times 2547/2016/2141 ms, close/recovery 2219/2250/2156 ms. Probe source SHA-256: 93D64350252BAE6467B8E622716075A11C3B84DF5A0772E5877AAEB7A41F9BEA. This confirms desktop-chain presence on the probe desktop at that instant; it does not observe each row actually committed into the worker's graph. The repeated ordered sample still shows no increase for these windows, while all interactions remain around two seconds.

Source follow-up: `wow_user_window_sample_links` samples desktop child and sibling identities with `GetWindow`, and `project_graph_attempt` traverses sampled edges, but ADAPTER-WOW-082 may retain already-recorded external observations instead of resampling each of them. Thus the probe-side 150-window desktop-chain census does not by itself prove all 150 were included in each worker graph. It also does not justify bypassing retained-observation consistency checks. No production change or new performance claim follows from this source trace.
