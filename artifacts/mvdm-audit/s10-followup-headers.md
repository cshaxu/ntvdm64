## Semantics of decisions

- **Scoped exclusion candidate** means only the cited physical header role is not used by the observed NT x86 CPU40 product profile; it does not authorize removing the file or dropping an alternate build, guest capability, or owner. The coordinator must reconcile the existing ledger with the cited evidence and current selections.
- **Pending** means the exact role, selected dispatch, original dependencies, or applicability is not completely established. It is deliberately not a full or partial compatibility claim. Evidence gathered by basename in the older crosswalk must be revalidated against the exact path.
- The existing captured dependency index is not a complete index for every build. Zero exact hits or textual includes cannot alone establish exclusion, especially for generated C, transitive includes, alternate profiles or assembly. No runtime, guest, desktop, Ninja or failure-injection tests were run in this follow-up. Existing fixture/profile observations have only the bounds in their reports.

## Explicit follow-up boundaries

- `gispsvga.h` / `gisp_sas.h`: cached inclusion and disabled command-line macro do not prove final transitive preprocessing; S13 must establish effective macro state and ROM/display provider. Do not call these selected implementations full.
- `hfx.h` / `winfiles.h`, `ms_windo.h` / `host_msw.h` / `msw_keyb.h` / `msw_snd.h`: preserve the historical HFX and SoftWindows distinction and the separate current DOS/WOW owners; S17 decides applicability using full dependency closure. Selected non-HFX services are not automatically equivalents.
- The generated C-VID/CPU access headers (`acc_efi.h`, `j_c_lang.h`, related generator structures) cannot be retired on absence of direct textual includes; S11/S13 must establish generated inputs, consumers, layout and execution. The generated access matrix is not an empty file.
- `dpmi.h` has same-basename headers in different directories. Textual matches in the host tree do not prove that this particular `base/inc` file is resolved by the selected compiler.
- Disassembler, HUNTER, licensing, profiling and old host UI headers belong to S17 profile/scope adjudication. Do not mistake an excluded current production profile for proof that historical tools or licensing code are equivalent or independently distributable.
- Disk geometry, ROM maps, optical media, legacy hardware and video state remain S13/S17 capability obligations even if particular declarations are excluded for this one product profile. Preserve actual media, device lifecycle, callbacks and negative tests as applicable.
