# Excluded branch annotation cleanup

The owner requires removed conditional bodies to use `#error` instead of comment placeholders and no longer requires divergence comments on those placeholders. The existing S12 conversion already placed 2,568 registered `#error` directives in 329 files. The current per-file guard counts match every entry of `s12-excluded-branch-errors.jsonl`; original branch conditions and those error directives remain unchanged. Other original or project guards are not treated as removed-body markers. Entire removed functions without an enclosing conditional are not converted into unconditional errors.

This change removes 42 divergence comments from retained `#line` directives in eight host mirror C files. The directive values and physical line counts remain intact. Seven MVDM host files are registered as MVDM-HOST-DIV-546; the non-MVDM `clres.c` is OPENNT-HOST-138. The existing historical deletion records remain in the external ledger. Comments documenting other actual code changes are outside this removal.

Cached x86 worker and WOW32 builds succeeded. The nine affected objects, including both `clres.c` variants, have byte-identical SHA-256 hashes before and after; see `excluded-branch-annotation-objects.json`. Explicit NTVDM and WOW32 relinks have identical `.text` and `.data` to the previously published candidate. Their `.rdata` differs only in bytes belonging to the PE debug-directory timestamp, at section offsets 0x12a9c and 0xa504 respectively; package resource identifiers also differ until packaging. Those section comparisons do not claim whole-image byte identity. In accordance with the owner's instruction, existing passing runtime tests and the published ten-image release are retained rather than rerun or replaced. No guest source or image was changed.
