# Selected C-VID generated video routines

Base `626f77507`. Seventeen previously pending `SEVID` sources are classified
partial, not fully restored. The [observer](cvidc-generated-image-observer.py)
checks their exact bytes against both original editions and the frozen DOS16
and WOW32 inventory, selected Ninja edges, archive membership and valid
dependency blocks. The [observation](cvidc-generated-image-observations.json)
binds 33 mapped function bodies per object to the released NTVDM code, masking
only COFF relocation words. It also lists 377 generated names present in the
original `evidfunc.c` source. Textual mentions are not a proof of each pointer
being selected at runtime, and masked relocation targets are not proven here.

| Sources | Original role and outstanding behavior |
| --- | --- |
| `sevid001`, `sevid002` | String reads and generated writes/moves. Resolve mode selection, address direction, boundaries, latches and reset. |
| `sevid006`, `008`, `009`, `011`, `013`, `015` | Unchained planar fill, copy and move variants. Validate plane masks, latches, aliases, source/destination ranges and reset. |
| `sevid017`–`020` | Chain-2 and mode-X writes, fills and moves. Validate selected mode, width, direction, plane behavior and wrap. |
| `sevid022`, `023`, `026`, `028`, `029` | Chain-4 writes and copies. Validate selected mode, plane/latch results, boundaries and retirement. |

Each file retains 100% original source text. Executable behavior coverage is
unmeasurable from image identity or source mentions; the per-file disposition
retains that explicit limit. Prior bounded vector and pixel fixtures are not
relabelled as proof of these 561 bodies. Guest and product images are unchanged.
