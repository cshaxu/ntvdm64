# DEM IOCTL drive-type selected-object probe

Original DOS `dos/v86/doskrnl/dos/ioctl.asm` bounds ordinary IOCTL subfunctions at 0x11 and invokes `SVC_DEMIOCTL` for selected drive operations. `demdisp.c` binds this to `demIOCTL`, whose original table maps subfunctions 8 and 9 to `demIoctlChangeable`. That routine asks for the physical drive type, falls back to `GetDriveTypeOem` when unknown, and maps the result to DOS AX/DX/CF. The host owns the real drive state; DEM translates the result; the guest dispatch owns ordinary subfunction validation. This source trace does not prove an installed guest was built from these sources. The release `demIOCTL` bounds check is conditional on `DBG`; this observation does not establish that an ordinary guest can supply an out-of-range index or that any unvalidated direct caller is reachable.

Current and OpenNT `demioctl.c` SHA-256: `6F480BF758D071B1FD2F76A137F892B77D1EA8D2D8FFB4690D395AEDF5F733FA`. An x86 fixture linked selected `build/.ninja/msvc-x86-release/worker/obj/dem/demioctl.obj`, SHA-256 `8F7C68C94E3556613EC42CF513E64E2EB20DDC4EF6E6F3AAD22109FEB33E9B54`, directly to `demIoctlChangeable`. Fixture SHA-256 `D3A47B8815027B9B1BDA6AFA42652AEAC9E5CE855A36480CAC6189558EFCFDB4`. MinGW i686 GCC with `-Wl,--gc-sections` reported `Warning: corrupt .drectve at end of def file`, but succeeded.

Seven controlled drive-type cases returned 0 from the fixture: removable and fixed results for operation 8; fixed, remote and CD-ROM results for operation 9; unknown physical type with removable fallback; and unknown with no-root fallback. The latter gave AX 15/CF 1, and fallback was called once in each unknown case. For operation 9, fixed returned DX 0x800 and remote/CD-ROM returned 0x1000. CPU registers and **both** drive-type sources were test seams, not real devices; no guest, SVC table, error translation, raw BOP, media geometry, access, or installed release were tested. No actual volume was opened or modified, no guest or ledger changed. Previous provenance and media limits are separately documented in `shard-2/parallel-review-next.md`.
