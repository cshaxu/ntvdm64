# Shard 3 partial host functions: grouped recovery handoff

`shard3-partial-host-inventory.py` snapshots **every shard-3 partial `.c` row at revision `3452abace`** with exact path, ledger SHA, frozen original/current hashes, divergence IDs, owner, evidence and remaining limits into `shard3-partial-host-inventory.json`. At capture there are 81 files in five dependency cohorts. Group labels are coarse worklist navigation, not evidence that every file has been dynamically tested; S11–S17 stage details and actual ownership come from `recovery-worklist.md`. Re-read ledger and replay before use. Headers, ASM, guest files and other shards are not counted by this census.
