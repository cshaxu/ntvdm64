These are S10 audit handoffs, not implemented repairs. The bounded fixtures below execute real selected original objects or exact extracted original bodies; simulated host boundaries, retained image identities and guest-execution limitations are explicit. Existing stage assignments are those in `recovery-worklist.md`. No guest changes are needed or authorized.
