# Original USER interaction source roles

Three original WOW32 files are classified partial after independent replay of
the selected object, released-image and initial dispatch evidence:

- [Accelerators](shard-1/wow-accelerator-review.md): actual guest calls,
  task identity during cleanup and allocation failure remain open.
- [Button conversion](shard-1/wow-button-image-review.md): guest message
  round trips, argument lifetime, window destruction and reentry remain open.
- [Language conversion](shard-1/wow-language-image-review.md): guest pointer
  mapping, DBCS, locale, failure and copyback remain open.

All three source files match the two pinned originals. Source retention is
100%; this is not a numerical estimate of functional restoration. The
[exact-delta verification](parallel-user-interaction-role-verification.json)
checks the three ledger changes and all other rows, but does not establish
runtime behavior or guest-image provenance.
