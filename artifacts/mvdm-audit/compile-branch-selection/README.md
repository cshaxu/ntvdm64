# Compile-branch selection evidence

Snapshot: `14e5638c415037c50e9099f697e496293948b0aa`; only committed source C, C++ and H files under `src` are enumerated. Original source and guest images were not modified or rebuilt. These tables are evidence, not a source-removal authorization or runtime coverage.

`branches.csv` lists each lexical `#if`, `#ifdef`, `#ifndef`, `#elif` and `#else` alternative, source hash and the per-architecture status. `selected` means at least one successful observed preprocessing context selected that alternative; it may be unselected in other contexts. `not-selected-in-observed-contexts` means the file was visited by at least one successful context of that width and none of the observed contexts selected that alternative. `unobserved` means no successful observed context visited that file. It does not mean impossible, dead, or safely removable. All statuses are limited to the commands below; failures and other configurations cannot prove exclusion.

The 1,051 successful contexts (816 x86, 235 x64) come from the current cached product build trees: x86 worker/wow32 and x64 frontend/hook/launcher/monitor/service/worker. `contexts.json.gz` retains per-context observed zero-based branch-row and file indices (file indices follow first appearance in `branches.csv`). Contexts include test or helper targets present in those build trees, not only final linked objects. Old call-boundary and x86-reference test trees were excluded after identifying stale paths and mixed compiler architecture; their absence is not a product conclusion. Generated source outside `src`, other configurations and external SDK headers are not inventoried.

Instrumentation was confined to a disposable shadow source tree: pragma markers following each conditional and file markers, with `#line` restoration of source paths and diagnostic numbers. Existing numeric `#line` directives are accounted for lexically; unusual conditionally active directives remain a limitation. Recorded compiler output is actual MSVC preprocessing, not macro-name inference. A full comparison of normalized preprocessing output is in `equivalence-all.json`: 1,047 of 1,051 contexts matched immediately. Four source units with no conditional directives emitted their temporary shadow path via `__FILE__`; restoring their original filename in the shadow and rerunning yielded four matches, recorded in `probe-equivalence.json`. Normalization discards blank lines and the inserted marker pragmas only. These comparisons do not prove matching object code or all configurations.

`non-c-branches.csv` is a separate lexical inventory of assembler and resource conditional candidates; all are `unobserved`, including guest files. The simple assembler scanner does not establish complete parsing of every dialect or prove actual assembler selection. Guest `.rc` and assembler sources were not compiled. The attached Python files are the one-off audit scripts as executed from the repository root; they reference this workspace and installed MSVC/Ninja paths and are not a supported general-purpose build tool. `check_probe.py` records the four reruns after the shadow-only filename fix.
