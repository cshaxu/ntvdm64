# Selected interface, resource and callback roles

The [redirector input review](shard-2/vdmredir-host-roles-review.md),
[host interface review](shard-2/dos-host-platform-headers-review.md),
[EGA review](shard-2/dos-video-profile-headers-review.md) and
[callback source review](shard-2/wcall32-release-review.md) establish seven
selected original file roles. The redirector version-resource payload also
matches between cache and release, as recorded by the [resource observer](shard-0/vdmredir-resource-observer.py).
The callback review binds four representative original bodies to released code.

All seven are partial. Header inclusion is not full ABI proof; version
resource identity is not network behavior; and callback bodies do not prove
registration, nesting, failure handling or object lifetime. The
[checkpoint](selected-interface-callback-role-verification.json) verifies
the exact ledger changes without changing product or guest code.
