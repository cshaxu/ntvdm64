# S12 excluded-branch errors

The previously registered branch-body placeholders in MVDM host and non-MVDM are now `#error` directives inside their existing conditional shells. Their original divergence numbers and reasons are retained. The conversion covers 2,568 markers in 329 files (281 MVDM host and 48 non-MVDM); `s12-excluded-branch-errors.jsonl` records pre-conversion and final per-file SHA-256 and marker counts. Conversion preserves line counts in these 329 files. No guest file was changed.

The first product build exposed a false exclusion in `softpc.new/base/inc/timeval.h`: selected units reach both the non-NTVDM and NTVDM alternatives. DIV-537 had removed both original declarations. DIV-543 restores the complete file content from the parent of commit `4a08da6f5`, byte-identical after normalizing line endings; that file is not counted among the converted guards. The first build failed at its diagnostic as intended; the follow-up build after restoration passed x86 and x64.

A real-header preprocessor control includes `wingdip.h` with DBCS absent and succeeds; defining DBCS fails with the retained OPENNT-HOST-132 diagnostic. This proves the representative guard in both directions, not every possible external build configuration. The guard deliberately rejects any unsupported configuration that selects a deleted body.

The cached x86 and x64 product builds passed after the `timeval.h` correction. The newly staged candidate's ten `.text` sections match the Full-tested release. Complete ten-file comparison also matches after normalizing only the package GUID resource, PE file-header and debug-directory timestamps, and PE checksum; the raw hashes do differ. The existing published Full-tested package was retained instead of replacing it with an otherwise identical new package identity. The earlier Full suite passed its selected gates, with the external DOS4GW/NESticle fixture explicitly skipped. The 329 ledger entries were rehashed successfully after conversion.
