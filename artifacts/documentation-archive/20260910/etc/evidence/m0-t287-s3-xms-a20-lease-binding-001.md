# M0 T287 S3 — XMS A20 lease binding evidence

## Result

S3 is closed on both supported host architectures. The exact OpenNT `xmsa20.c`
and the reached `xmsumb.c` initialization path retain their source ordering,
while no persistent guest alias or native host pointer crosses the XMS boundary.

## Source-shaped binding

- `xmsInitUMB` still obtains its state location from `AX:BX`, then invokes
  `xmsEnableA20Wrapping` in the original order.
- `xmsA20` still dispatches the original enable, disable and query cases and
  preserves its AX/BL result ordering.
- `sas_enable_20_bit_wrapping`, `sas_disable_20_bit_wrapping` and
  `sas_twenty_bit_wrapping_enabled` are same-shaped SoftPC declarations in
  `adapter-mvdm-host-out/softpc`; they use only typed A20 mechanics exposed by
  `adapter-bochs`.
- The material modern binding is private to the matching mirror:
  `mvdm-host-overlay/xms.486/xms_a20_state.[ch]` stores only the numeric
  16:16 location and takes a new, exact one-byte session lease for each write.
  It never stores a `GetVDMAddr` pointer.
- Mirror edits are registered as `MVDM-HOST-DIV-010` in both relevant READMEs.
  No `52:xx` ingress/route is enabled by this work.

## Verification

The formal `/MT` Ninja graph generated by
`tools/build/New-T287S3XmsA20Ninja.ps1` compiled and linked the fixture on
both architectures:

- `build/M0-T287/S3/x86/bin/t287-s3-xms-a20-lease-fixture.exe`: exit `0`.
- `build/M0-T287/S3/x64/bin/t287-s3-xms-a20-lease-fixture.exe`: exit `0`.

The fixture proves source A20 enable/disable/query register results, a valid
state-byte write, an invalid 16:16 location that cannot alter the prior byte,
and lease expiry that prevents a stale write. It composes Bochs as static
libraries so unused product-device objects are not forced into the focused
fixture link.

## Explicit remaining boundary

`i386/xmsmem86.c` remains an exact audit source, not a product input. S4 owns
the same-shaped extended-memory reservation/copy binding for `xmsblock.c` and
its suballocator path; it must use the existing session mapping manager and
cannot convert XMS numeric addresses to host pointers.
