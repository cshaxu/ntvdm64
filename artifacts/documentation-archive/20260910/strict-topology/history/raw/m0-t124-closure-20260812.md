# M0 T124 closure — 2026-08-12

## Result

T124 source/test-closes the thin CLI-to-Bochs process boundary. `ntdos64-run`
accepts optional `--bochs <bundle>\\ntdos64-bochs.exe` only with an explicit
DOS engine and forwards it only to `ntdos64-bochs-engine`; raw Bochs never sees
BYOB options.

The shim admits exactly its fixed runner ABI, derives the bundle root from the
fixed executable name, and validates a tiny fixed-order
`ntdos64-bochs-engine-bundle-v1.txt` manifest. The manifest binds the engine,
BIOS ROM, VGA ROM and option ROM by SHA-256. The shim copies verified ROM bytes
to a private run directory, writes only the frozen T121 first-profile
`bochsrc`, preserves the runner child environment/stdin policy, and starts the
native executable with exactly `-q -f bochsrc`.

## Evidence

The focused MinGW build at
`artifacts/build/current/t124-bochs-engine` compiled `ntdos64-run`,
`ntdos64-bochs-engine`, `bochs-engine-probe`, and `runner-engine-probe`.

`ctest -R "ntdos64-(run|bochs-engine)-policy"` passed on 2026-08-12. The fake
native parser proved the exact native argv, fixed generated configuration,
copied ROM contents, inherited BYOB environment and EOF stdin. The same test
also proves shim-ABI trailing directives reject with exit 2 and a missing fixed
ROM rejects before parser launch with exit 3.

## Limitation and transfer

This is source/test evidence only. It does not run the retained T121 Bochs
image, claim that Bochs initialized, or make a guest-runtime claim. The
repository's authored source/CMake/test tree is currently untracked bootstrap
content; no broad user-owned source tree was staged for this documentation
closure. T125 owns the separately admitted immutable real-bundle assembly and
one bounded native-engine preflight.
