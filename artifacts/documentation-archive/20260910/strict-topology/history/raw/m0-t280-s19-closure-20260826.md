# M0 T280 S19 closure — DEM guest lease contract audit

The original `demsrch.c` guest-address surface is fully classified. Transient
DTA/FCB accesses are bounded synchronous guest-memory lease candidates;
pathname inputs require a source-proven bounded-string policy. The audit also
found the essential cross-owner blocker: `demgset.c` stores `GetVDMAddr`
native pointers in long-lived DEM globals later consumed by `demsrch.c`.

Therefore no raw `GetVDMAddr` shim is admitted. The successor must first
replace these retained pointers with guest-address descriptors and fresh
per-dereference leases. This preserves original OpenNT source roles while
respecting the single session mapping-manager implementation and its
`guest_memory` instance.
