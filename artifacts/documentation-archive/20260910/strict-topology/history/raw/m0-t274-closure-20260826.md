# M0 T274 canonical OpenNT source-supply closure

## Result

M0 T274 is closed as a source-supply package. It establishes a reproducible,
source-selected, hash-verified OpenNT input set for later adapter and product
composition work. It does not claim host compilation, linking, provider
enablement, guest execution, or replacement of unavailable historical APIs.

## Closed subtasks

- S1 selected one provenance/source disposition for all 3,671 non-guest MVDM
  union rows, including edition-selection evidence.
- S2 recovered the minimal exact declaration-only `opennt-platform-abi`
  mirror and recorded all direct include dispositions.
- S3 directly recovered all 676 carried DOS/V86 guest files byte-identically.
- S4 directly recovered the local WOW16/bin86 carry (54 files) and manifested
  87 pre-existing WOW16 output products in place; no source-cardinality claim
  was made beyond that carry.
- S5 recovered 1,050 selected MVDM host topology/header/resource inputs over
  23 original package roots.
- S6 recovered the remaining 639 selected host inputs: 612 C/C++/assembly
  provider bodies plus 27 other forms.

## Verification

- The S5/S6 manifest union contains 1,689 distinct `opennt-mvdm-host` paths,
  matching the complete selected-host universe.
- SHA-256 verification against every retained selected source hash reports
  zero mismatches.
- Source selections remain 1,685 dual-identical inputs, three OpenNT-4.5-only
  inputs and one OpenNT-only input. No competing generation was silently
  copied into a parallel root.
- Documentation inventory generation and documentation-governance verification
  pass.

## Deliberate limitations and handoff

The host root is an exact dormant source mirror. No original body was modified
to force a build, no adapter was enabled, and guest output was not linked into
the host graph. The first queue candidate, Historical interface adapter
recovery, must establish caller/ABI/failure/reuse evidence before selecting any
original provider for compilation or execution. The later dual-architecture
composition package owns formal host graphs and runtime claims.
