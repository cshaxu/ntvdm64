# M0 T101 closure — 2026-08-12

T101 read-only correlated the current post-BOP prefetch stop with Bochs 2.6
source. `0xAF6AF` is inside the native VGA aperture, whose direct-access
policy intentionally refuses CPU instruction fetches. It is not an
out-of-bounds-memory result and does not authorize VGA, RAM mapping, a Bochs
patch, or an adapter workaround.

The trace lacks the first control transfer into that aperture, so it cannot
attribute the symptom to the preceding BOP or normal close. T102 is therefore
the narrowly bounded default-off CPU transfer-observation design/closure,
with no behavior change or guest retry until that contract is reviewed.
