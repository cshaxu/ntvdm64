- Original-source examination and bounded Direct/Readonly observations converge on a complete guest COMMAND/NTDOS transient-lifecycle domain.  The source-built COMMAND image remains valid resident transient code through the bounded early interval, then transfers to an already zero-filled dynamically allocated target.  Direct and Readonly observations were byte-identical for this boundary.
- The original NTDOS `$ALLOC` and `$DEALLOC` paths manipulate MCB metadata and do not clear payload; original COMMAND explicitly depends on preserved transient bytes.  Therefore zero-filled transient memory is not explained by an intended allocator-clearing rule.

No current BOP provider defect is evidenced by those records.

The retained Status packet links the individual P evidence records and remains the compact current-baseline record for these facts.
