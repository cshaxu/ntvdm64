# M0 T345 — Host capability expansion closure

T345 closed its selected ordinary host-capability cohort as the complete
original DEM filesystem/handle, directory/drive/volume and search/FCB package.
The package remains source-shaped: original DEM code owns dispatch and DOS
result translation; existing adapter-mvdm-host-out and session components only
provide same-shaped public Win32 and opaque identity/guest-location bindings.

No generic host capability dispatcher, virtual drive/filesystem, readonly
policy, raw-media provider or replacement BOP implementation was created.
Named pipes/Redirector, raw media, serial/printer, fullscreen presentation,
registry/console forms and child lifecycle retain their explicit owners.

The paired CPU40 x86/x64 formal product targets link the original DEM library.
The only observed build-environment correction was loading `VsDevCmd` before a
target needing `rc.exe`; it changes no product source or ABI.
