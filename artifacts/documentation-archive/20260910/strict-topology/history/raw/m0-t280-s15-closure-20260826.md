# M0 T280 S15 closure — DEM host-identity facade

`adapter-softpc` now owns the sole source-facing host-identity facade for the
reached `demsrch.c` find-list pointer contract. It consumes the existing
thread-bound session and its `host_resource` mapping-manager instance; it does
not create a mapper, store a native pointer in guest state, or touch
guest-memory leases.

The focused x86/x64 Ninja fixture proves no-session rejection, identity
publication/resolution/release, isolation and disposal invalidation. The
original DEM mirror is intentionally still unedited. The successor may make
only the source-local, registered `demsrch.c` storage and validation
divergences, then must compile the original body and prove its failure paths.
