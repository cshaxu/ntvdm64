# M0 T153 closure — 2026-08-12

T153 closes a holistic source-derived provider contract for the missing x86
fast-I/O composition. The design preserves the original FASTREAD call ABI and
the guest continuation while using the already bounded, finite readonly
namespace and generic bulk transaction for actual bytes. FASTWRITE remains
explicitly unavailable.

The design has no Bochs change or ABI expansion. T154 is the narrowly bounded
adapter-only implementation/test package; a runtime observation requires a
separate later S after its static closure.
