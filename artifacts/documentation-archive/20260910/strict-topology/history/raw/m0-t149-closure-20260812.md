T149 closes the benchmark/provenance and extended-observation package.

benchmark timer. The one T149 S2 ten-million-budget invocation reaches the
same late `0BC1:FFFF` prefetch-limit cycle 309,782 times:

`prefetch-limit -> #GP/INT 0Dh -> original BOP 02 -> handled IRET -> same prefetch-limit`.

The outer watchdog ended the process before completion metadata was written;
therefore the record proves reachability and repetition, not a clean completed
budget or continuous guest execution. No BOP, adapter, Bochs device, firmware
or guest semantic change was made. The next package is a source-only return
frame/continuation audit.
