# M0 T150 closure — 2026-08-12

T150 closes the source-only INT 0Dh/BOP `02h` return-frame audit. Original
OpenNT source establishes `unexp_int -> BOP 02 -> guest FIRET`; the original
machine handler performs PIC/BDA side effects but no control-flow mutation.
Together with T149's repeated trace, this proves the cycle is a replay of the
already-created #GP frame, not an adapter BOP service error or a missing BOP
`02h` continuation.

The registered prefetch field is not an instruction decoder or branch history.
No implementation, runtime retry, device, firmware, guest or provider change
is admitted. Follow-on work is limited to static command-image/load provenance
at the application-relative tail address before any new diagnostic is proposed.
