# M0 T280 S14 closure — DEM find-list host-resource binding audit

The original `demsrch.c` find-list contract is now fully classified before
any mirror body is edited.  `FFindId` remains original numeric search data.
The persisted `PFFINDLIST` is an opaque host identity and must be represented
only by a surrogate from the existing session `host_resource` mapping-manager
instance.  DTA and FCB access remains a separate, bounded
`guest_memory`-lease operation.

The audit establishes publication, reverse lookup, stale-token behavior,
release-before-free ordering, and session-disposal tombstoning.  The present
source tree already has the required bounded imported-call session binding;
`adapter-win32`'s reached `NtVdmControl` facade uses it.  The missing boundary
is the equivalent `adapter-softpc` host-identity facade.  Editing the mirror
before that facade would couple it directly to project implementation,
contrary to the same-shaped recovery boundary.

The successor must add one adapter-softpc same-shaped host-identity facade
over the existing thread-scoped session binding. Only then may `demsrch.c`
receive the registered, source-local divergence. No provider, BOP route,
guest trace, raw pointer persistence, or new mapper is enabled by this
closure.
