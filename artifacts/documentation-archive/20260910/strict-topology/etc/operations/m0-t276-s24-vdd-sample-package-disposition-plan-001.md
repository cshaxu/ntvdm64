# M0 T276 S24: W9 `vdd` final expected-integration plan

## Objective

Give all 47 selected `vdd` paths a final expected-integration conclusion in
the global T276 tracker. This root consists of historical VDD samples and
sample guest halves; it is not an original MVDM VDD product runtime.

## Decision method

1. Reproduce each sample's original `sources` selection and its guest/host
   split.
2. Retain the source as byte-exact mirror evidence.
3. Classify samples that are not selected by an actual product composition as
   `not-host-runtime`; do not promote a sample DLL, assembly program or
   declaration to an adapter-vdd implementation merely because it contains a
   VDD API example.
4. Record `adapter-vdd` only as the boundary for a future separately audited
   product VDD package; it is not a reason to link a sample.

## Mapping rule

No VDD sample gets a private mapper. If a later owner explicitly reuses a
sample contract, guest addresses must use the session guest-memory mapping
manager and native endpoint identity the session host-resource manager.

## Exit evidence

The global final tracker has 47 non-`unresolved` `vdd/*` rows, all source
paths remain mirror evidence, and the verifier proves no sample body is
mistaken for current host-runtime input.
