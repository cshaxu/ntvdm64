# M0 T281 S5 — original host-control package disposition plan

## Purpose

Use the completed T276/S12 audit as input, not as a substitute for source
recovery. Consolidate the full original `softpc.new/host/src` package into
whole-owner recovery groups so follow-on code work does not grow by BOP leaf.

## Required outcome

For every one of the 56 source files, record exactly one of:

- `eligible-next`: can enter a bounded original static composition group using
  already-existing same-shaped adapter declarations;
- `adapter-prerequisite`: original body remains the target, but a named,
  source-proven existing or new adapter interface must first close;
- `specialist-owner`: belongs to VDD, debugger, Redirector, WOW, monitor or
  presentation/package work after its own complete owner package is admitted;
- `bochs-replacement`: original device/executor implementation is not linked
  because Bochs owns that machine behavior.

## Constraints

This S does not compile, enable, or replace a host source body. It must never
merge Bochs device/executor code with MVDM control logic, and must retain the
original source interface as the basis for every proposed adapter.
