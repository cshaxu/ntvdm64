# M0 T276 S21: W7 `vdmredir` package disposition plan

## Objective

Audit all selected `vdmredir` paths as one original Redirector owner package.
Record protocol/provider/build roles and reached DEM, COMMAND, session and
Win32 boundaries before enabling a Redirector body.

## Non-goals

No source move/edit, Redirector implementation, formal build edge, Ninja run
or guest execution. The audit does not authorize an independently invented
file-redirector service.

## Acceptance

All 25 selected paths have one reproducible non-enabled disposition and every
external family is assigned to its original owner or the smallest named adapter.
