# M0 T369 — Original DOS EXEC and parent return

## Purpose

T368 closed the original COMMAND owner route through the guest EXEC handoff
and established that the current fixed product's later `54:01` wait is not a
license to invent another COMMAND provider.  T369 recovers the next complete
owner package: original guest DOS `.COM`/MZ execution and its parent-return
path after a demonstrated COMMAND handoff.

The task preserves the original guest `$Exec`, JFN/SFT, PSP, arena,
environment, INT 21h termination and COMMAND continuation contracts.  It
does not create a host executable loader, synthesize a PSP/child, or use a
single BOP trace hit to select work.

## S plan

### S1 — Revalidated original EXEC/parent-return owner ledger

Re-read the selected immutable guest sources and current formal host route.
Establish the exact `$Exec` definition/callers, file/JFN/SFT transfer,
COM/MZ divergence, PSP/arena/environment setup, child termination and parent
COMMAND recovery.  Mark every host crossing, source-defined failure and
existing adapter/mapping-manager seam.  Select the earliest whole cohort that
is not already source/link closed.  No product run.

### S2 — Current source-shaped execution observation cohort

Recover only the source-selected cohort from S1.  The current selected cohort
is the existing console-owning observation container: rebuild it from its
current source so its SystemRoot identity agrees with the current
executable-relative package layout, then bind it to the formal product without
changing guest, COMMAND, DEM or machine semantics.  If S1 instead exposes a
missing original guest or host body, use that original source and existing
same-shaped adapters only.  No synthetic loader, guest-media edit, individual
BOP substitute, or parent-state invention is allowed.

### S3 — Formal execution-boundary closure

Rebuild and inspect the selected CPU40/x86 product.  Prove each selected
original host component and adapter is a final input; run focused
source-shaped checks for the cohort.  No fixed product run.

### S4 — One fixed original workload observation

Only after S1--S3 alter the selected boundary or establish a new covered
cohort, make one non-debug fixed-container observation using immutable
original media and a declared original workload.  Record `$Exec`, a
source-defined earlier terminal, or an exact later owner.  No retry and no
trace-selected repair.

## Completion boundary

T369 may prove an original DOS execution/parent-return cohort or transfer at
an exact earlier source owner.  It cannot claim native-child, WOW, Redirector,
graphics, multi-session or x64 guest execution.
