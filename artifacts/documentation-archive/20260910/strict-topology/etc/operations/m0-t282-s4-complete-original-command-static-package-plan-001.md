# M0 T282 S4 — complete original COMMAND static package

Build the complete original eleven-unit `dos/command` `sources` list as one
static library under independent MSVC x86 and x64 Ninja graphs. The graph may
select only the exact original declaration carriers and existing same-shaped
adapter headers; it must exclude BOP ingress, provider bodies, executable
entrypoints and all Bochs sources.

This is a source-composition closure, not COMMAND runtime recovery. Any
remaining callable historical dependency stays unresolved at archive time and
is recorded with its existing session, adapter or specialist owner. A new
adapter, an original-body change or any route requires a later explicit S.
